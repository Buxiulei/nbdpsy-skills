# 拆解手册（方法论详版 + 素材单模板 + 坑典）

> 本手册由两次实战沉淀：2026-08-07 小红书正念笔记拆解、2026-08-11 视频号「皮质醇」四条对标拆解
> （完整范例在 NBDpsy 主仓 `文档/2026-08-07-拆解素材单-*.md` 与 `文档/2026-08-11-拆解素材单-视频号-*.md`）。

## 一、数据判型速查

先把四个互动指标摆成比值，内容类型自己会说话：

| 信号 | 判型 | 说明 | 实例 |
|---|---|---|---|
| 收藏/点赞 ≥ 50% | **工具收藏型** | 被当"工具"收着反复看，结构必有可回看框架 | 正念笔记 54%（普通科普 20-30%） |
| 转发/点赞 ≥ 3× | **转发利他型** | 观众替朋友收的，内容单元完成"发给那个人"的动作 | 皮质醇片 10.5×（视频号分发靠社交链，转发即命脉） |
| 评论 ≥ 点赞的 30% | **讨论争议型** | 正文有立场或钩子留了口子 | — |
| 点赞独大、其余低 | **共鸣速食型** | 看完就走，学钩子不学结构 | — |

配套动作：
- **二抓增速**：间隔 ≥6h 再抓一次，增速比存量更能说明"正在爆"还是"长尾老爆款"（皮质醇片 6.5h 转发 +491 → 实时热片，蹭它的形式要快）；
- **发布时间档**：换算到北京时间记录（视频号 createtime 是 Unix 秒），周一晚 20-21 点这类档位本身是可学项；
- **小号识别**：几十赞的号，形式再好也在素材单里写明「学形式不学数据」。

## 二、文字稿还原的三条路

| 内容形态 | 判定 | 还原方式 |
|---|---|---|
| 有口播 | ASR 出中文/外文 segments 且置信度正常 | `dissect_video.py` 转写稿直接用，按 [start-end] 逐句引 |
| 纯音乐+字幕层 | `dissect_video.py` 报「疑无口播」 | 文字稿=字幕稿：对帧看板逐帧抄录字幕，按出现时间做成表（时间/字幕/功能三列） |
| 图文 | — | `fetch_xhs_note.py` 或网页抓取，正文全文引用（blockquote），一字不改 |

**字幕稿要连功能一起拆**：爆款字幕往往是微型落地页。皮质醇片全片仅 4 句：
「鼓起你的腮帮子」（**行动**）→「这能刺激迷走神经缓解焦虑」（**原理**）→「还能预防面部松弛✨」（**加赠**，破圈器官）→「我随时随地都在做😊」（**人设**）。

## 三、形式拆解清单

逐项过，每项都可能是它爆的真因：

- **场景清单与切换节奏**：数场景、量每场景秒数（皮质醇片：8 个生活场景 × 2-3s 快切，同一动作重复）；
- **字幕层结构**：常驻标题（POV 句式？）/ 递进气泡 / 免责小字，三层各干什么；
- **双钩子判定**：封面文案句式 vs 正片常驻标题句式是否两套（封面「一个动作排出皮质醇」利益句式钩点击，正片「那个为了…而一直鼓腮帮子的人」POV 句式钩代入）；
- **循环体判定**：结尾是否无收尾直接回开头（完播率×循环播放双吃；皮质醇片 18-19s 一轮）；
- **音频形态**：口播 / 纯 BGM / 现场同期声，各自的字幕依赖度完全不同；
- **信任杠杆**：出镜者身份暗示（白人面孔=「外网前沿」、白大褂=权威、猫 meme=卸病耻感）——判断我们有没有更硬的对应物（北大咨询师实名 > 匿名搬运）；
- **制作成本估算**：它做这条花了多少（搬运+翻 4 句话贴字 ≈ 零成本），决定我们复刻的产线选型。

## 四、趋势语境查证（第 5 步的操作细节）

- WebSearch 关键词：`<核心概念> 辟谣`、`<核心概念> 医生`、`<赛道词> 走红`；
- 拿到的语境写进素材单「零、先看这个」节：红利（题材正热）与雷（辟谣浪潮=监管收紧前兆）都要写；
- **专业机构铁律**：机制描述必须站得住——「帮神经系统踩刹车」可以，「排出/清除皮质醇」不行。拿不准的表述宁可降级成现象描述。

## 六、坑典（每条都有出处，别再踩）

1. **账号名误读成数据**（2026-08-11）：缩略看板里「3.27蕊」被读成 3.27 万赞，实际是账号名、该片仅 39 赞。
   → 互动数只认 API 返回或全分辨率单帧（`ffmpeg -ss <秒> -i <文件> -frames:v 1 -q:v 3 full.jpg`）。
2. **商品笔记结构陷阱**（2026-08-07）：正文是「痛点→重构→卖本子」的卖货漏斗，照学落点会跑偏。
   → 先查 URL `noteAttributes=goods` / 评论区是否全是产品评价，是则只学前 80%。
3. **ASR 幻觉**（2026-08-11）：31.7s 的纯音乐片被 whisper 转出 30-55s 的空段句号——凭空多出 23s。
   → 信 `dissect_video.py` 的幻觉守卫；「疑无口播」时一律走字幕稿路径。
4. **ASR 繁体漂移**（2026-08-11，text-to-video 线同源）：initial_prompt 不带「简体中文」引导会输出繁体、下游匹配全落空；但 prompt ⛔ 含正文原句（开头会被当 prompt 延续吞掉）。
5. **封面 CDN 过期极快**（2026-08-11）：视频号 coverUrl 带 token，实测最短抓到时只剩 ~2h 就失效（到期时刻在 `sceneInfo.expiredTime`，sph_meta.json 已带出）。→ 抓到当场落盘归档，别存 URL。
6. **录屏是复合载体**（2026-08-11）：一条录屏含 2 条对标+工作群聊天画面。
   → 先按内容切条（帧看板定边界）再逐条拆；群聊帧不入库不外发；服务器上的录屏拆完请示删除。
7. **「没查到」≠「没有」**：任何来源缺失都标「待补」，缺失值静默变零会长出方向全反的结论。
8. **视频号正片微信外必拿不到**：finder-preview 只给元数据+封面，伪装微信 UA 也无效。别浪费时间试第三方解析站，直接走录屏流程。
9. **小红书 extract 两个坑**（2026-08-11 实测）：①裸 `/explore/<id>` 链 400 拒——**必须用分享按钮生成的链接**（xhslink.cn 短链或带 `xsec_token` 完整链），手工精简 URL 等于自废；②**24h 结果缓存**——二抓增速不带 `--refresh` 会拿到第一次的旧数（`from_cache=true` 时 note.md 已标注），且上次抓的评论会跟着缓存回来。
10. **互动数解析 None ≠ 0**：`sph_meta` 解析不了的计数输出 null 并保留 `*Fmt` 原始串；`fetch_xhs_note` 对服务端给 null 的计数在 note.md 渲染成「未知」——下游别把 null/「未知」当零参与判型（见红线「没查到≠没有」）。
