# 长文审查清单（心理科普 pillar）

> 审查对象：nbdpsy-seo-artical-creator 产出的 pillar 长文 Markdown（含 frontmatter）。
> 立场：预设有问题，逐条找证据；不确定按 FAIL。

## 确定性检查（先跑，JSON 输出与 exit code 原样记入报告）

路径说明：`../nbdpsy-seo-artical-creator/` 指安装后与 nbdpsy-content-reviewer 同级的兄弟 skill 目录；命令在本 skill 目录下执行，或换算为绝对路径。

| 命令 | 预期 | exit 语义 |
|------|------|-----------|
| `python3 ../nbdpsy-seo-artical-creator/scripts/count_hanzi.py <文件>` | 纯汉字 4000–6000 | JSON 输出；区间外 exit 2 |
| `python3 ../nbdpsy-seo-artical-creator/scripts/check_links.py <文件>` | dead 为空 | JSON 输出；有 dead 链接 exit 1（`suspect` 不算 dead，但须逐条人工点开定性后写入报告） |
| `python3 ../nbdpsy-seo-artical-creator/scripts/lint_markdown.py <文件> --citations <citations 条数>` | ok=true，无违规 | JSON 输出；bold-flanking（加粗渲染兼容性）或 citation-marker（文内引用覆盖率）任一违规 exit 1（`--citations` 取 frontmatter `citations` 数组条数） |

**渲染可见层抽查**（文章已发布、拿到线上 URL 时必做，不能只查 Markdown 源文件——源文件语义正确不代表渲染正确，这正是本次生产事故的漏检点）：抓取线上渲染页，剔除 `<script>` 与所有 HTML 标签后统计残留的可见 `**`，必须为 0：

```bash
curl -s https://www.nbdpsy.com/blog/<slug> | python3 -c "import sys,re;h=sys.stdin.read();h=re.sub(r'<script[\s\S]*?</script>','',h);print(re.sub(r'<[^>]+>','',h).count('**'))"
```

输出非 0 = 渲染层加粗失败，FAIL。

## 判断性检查（逐条 PASS/FAIL + 证据 + 位置）

1. **带出处统计 ≥3 个，且文内每个数字能在参考文献找到对应源**。逐个数字反查：正文出现的每一处统计（百分比/倍数/样本量），都要在参考文献区找到对应条目，且该条目内容确实支撑这个口径——标题像不算，要点开核对。找不到对应源的数字 = FAIL 并逐个列出。
2. **专家引语 ≥2 条，抽 1 条网络搜索核实非编造**。任选（优先选最可疑的）一条引语 WebSearch 原话或紧密转述的出处；搜不到、或搜到的原话与文内明显不符 = FAIL。凡把引语安到胡佰亿或任何 NBDpsy 咨询师名下的虚构引语，直接 FAIL。
3. **正文数字标注 `[[n]](url)` 与文末参考文献逐条对应且 URL 一致**：文末参考文献区每条至少被正文标注一次（无未标注文献），正文每个 `[[n]]` 都能落到参考文献区对应序号且 URL 一致（无孤儿标注）。**缺任何一条对应关系、或正文存在无标注的统计/引语，即 FAIL**——「正文提到来源名称」不算标注，必须是可点击的 `[[n]](url)` 数字标记。列出不对应的条目。
4. **正文不得残留写作态简称标记 `【引: ...】`**。自 2026-07-26 老板定案的「引用职责分离」起，写作 agent 文内只写简称标记 `【引: 作者/机构 年份, 文献简称】`，由**引用落地步**统一替换成 `[[n]](url)` 并生成参考文献区与 `citations`。**该标记是中间态，绝不进成品**：送审稿里残留一处即 FAIL——说明引用落地步没跑或没跑完，这批句子实际处于**无出处**状态。逐处列出残留位置，退回生产端跑完引用落地步再送审，**审查端不代为补链接**。

   **检查范围：只作用于剥掉 frontmatter 与围栏代码块的正文**（与生产端 `cite_scan.py` 同源，2026-07-26 对齐）。两类命中**不算残留**：
   - **frontmatter 里的说明性字面量**（例如范文头部注释里那句"写作态长什么样"）；
   - **围栏代码块 ` ``` ` 内的示例**——文章讲写作规范时会举例展示标记形态，那是内容不是残留。
   例外：若标记出现在 `title` / `excerpt` / `meta_description` / `faq` 这类会外露给读者的字段值里，仍按残留 FAIL（人工扫一眼 frontmatter 即可判定）。检查命令（输出必须为 `0`）：

   ```bash
   # 剥掉首部 frontmatter 与围栏代码块，只数正文；半角/全角冒号变体都算残留
   python3 -c "import sys,re;t=open(sys.argv[1],encoding='utf-8').read();b=re.sub(r'^---\r?\n.*?\r?\n---\r?\n','',t,count=1,flags=re.S);b=re.sub(r'\`\`\`.*?\`\`\`','',b,flags=re.S);print(len(re.findall(r'【引[:：]',b)))" <文件>
   ```

   只有 `grep` 可用时的等价做法：`grep -nE '【引[:：]' <文件>` 看命中行号，**落在首尾两条 `---` 之间（frontmatter）或一对 ` ``` ` 之间（代码块）的不算残留**，正文内命中一处即 FAIL。

5. **引用落地报告里标注「引用阶段新增、未经第 2 步查证轮」的条目，逐条重点复核**（2026-07-26 引用职责分离后新增的复核口径）。这批条目是引用 agent 在落地阶段自己联网补进来的，**没走过第 2 步「逐条打开网页核实」那道关**，是全篇编造风险最高的一批。对**每一条**（不是抽一条）按判据 2 的做法 WebSearch 核实：原话/统计口径与文内说法一致、URL 可达且内容确实支撑该说法；搜不到、或口径与文内不符 = FAIL 并逐条列出。若引用落地报告未随稿提供 → 先向生产端索取；确实拿不到时**不得默认 PASS**，改为在参考文献区随机抽 2 条按同法核实，并在审查报告里注明「无引用落地报告，改用抽样」。
6. **TL;DR 在文首，80–120 字**。数一遍字数，超界或缺失 = FAIL。
7. **FAQ 5–8 条在文末**。数条数，位置不在文末或条数超界 = FAIL。
8. **≥1 张对比表**（Markdown 表格，真对比——两列以上、有信息增量，不是排版凑数）。
9. **站内内链 2–4 处，且 slug 真实存在**。逐个内链核对目标 `/blog/{slug}` 真的是已上线/已入库文章（对照站点或 drafts 目录），编造的 slug = FAIL。
10. **危机声明在文末**：必须含全国统一心理援助热线 **12356** 与北京心理危机研究与干预中心热线 **010-82951332** 两个号码（参考口径：`本文不构成医疗建议；如处于心理危机请拨打全国统一心理援助热线 12356 或北京心理危机研究与干预中心热线 010-82951332（24小时）；紧急情况拨打 110/120`）。缺任一号码或不在文末 = FAIL。
    - **危机声明号码核对：以本条为唯一真源**，发现 4001619995/希望24 或 12356 配「24小时」字样一律 FAIL（12356 官方口径为每日≥18小时，只有 010-82951332 官网明写 24 小时）。
11. **全篇无「治疗/诊断/治愈/医院/医生」自我描述**。禁止用这五个词描述 NBDpsy 自身服务（合规口径=「咨询/干预/评估/陪伴」）；学术名词与对研究文献的转述（如"心理治疗研究显示…"、PTSD、CBT）可保留——逐处出现位置判定属哪种，拿不准 = FAIL。
12. **署名与 E-E-A-T 一致**：作者为胡佰亿（或用户明确指定的其他真人），frontmatter 与文内署名一致，不得虚构作者头衔/资历。
    - **约定**：若 frontmatter 无 `author` 字段但 `review_status` 注明「发布脚本兜底署名（默认胡佰亿）」等待发布流程时，该项按约定标注 PASS（备注约定依据），不按"不确定=FAIL"硬判。

13. **阅读连贯性：正文里不许有「写给写手的话」**（2026-08-02 线上事故新增）。作业卡与 brief 里对写作者下指令的措辞被原样抄进成品，读者读到的是布置任务的口吻。
    - grep 这些命中即 FAIL：`要说精确` / `必须给出` / `必须给一个` / `这里必须给`；
    - 内部术语同样 FAIL：`姊妹篇` / `姊妹文` / `本批` / `独占概念` / `主轴理论` / `反证条目`；
    - ⚠️ **只判措辞，不判内容**——反证的精确化表述（「它反对的不是 A，而是 B」）是必须保留的资产，**要求改写引导语，绝不要求删内容**。

14. **阅读连贯性：不许有「导航节」打断主线**（同上）。为「相关阅读 / 系列导航」单开 H2 章节 = FAIL（实例：`## 事前紧张、当场脑空白、事后复盘：三篇姊妹文` 下辖 5 段，读者正读机制被切进一页导航）。
    - ⛔ **把它整块缩成一段 `> **延伸阅读**：A、B、C` 引用块，同样判 FAIL**（2026-08-02 运营追加：**「导航节」需要符合逻辑的、连贯地嵌入长文**）。缩小的导航块还是导航块，读者照样被切出论证。
    - ✅ **唯一合规写法：拆开，各自嵌进论证里对应的位置**——讲到哪个话题就在那句话里顺手指路。优先找正文里天然的对位结构（分阶段/分类型/分场景的小节，常与要链的那几篇一一对应）；没有就近嵌在首次提到该话题的那句上。
    - ⛔ **三处用同一句式排比连嵌**（「…的机制另有专文：X」×3）**也判 FAIL**——那是把导航节拆散摊在正文里，仍是推荐位。
    - 判 FAIL 时**要连带确认内链没被删**（R9 仍需 2–4 处），且删掉 H2 后 H2 总数仍满足 R10。

15. **口径/边界说明必须是备注样式，不能与正文同级**（同上）。交代样本限制、口径、证据强度、反证边界的段落，若写成**普通段落**（与正文同字号同颜色）= FAIL，须改为引用块 `> **标记词**：…`。
    - 标记词必须逐字取自 `pillar-spec.md`「口径与边界说明的排版」一节列出的那几个，否则渲染端不会命中小字注脚样式，反而掉回主色强调样式（比普通段落更抢眼）。
    - 专家引语**不适用**本条——引语本就该显眼。

16. **提到站内其它文章必须给链接**（2026-08-02 运营要求）。正文出现「站内另有专文」「另有一篇专门讲」「这部分见另一篇」等说法，却没有同句或紧邻处给出 `[锚文本](/blog/{slug})` = FAIL——只提不给链接等于让读者自己去找。
    - 判 FAIL 后的正解有两条，**任选其一**：补上真实存在的链接；或**把那句话改写掉**（内链已满 4 处、站内确实无对应文章时走这条），⛔ 不要留一个没有出口的指路。
    - 自查命令：`grep -nE '另有专文|站内另有|另有一篇|专门讲|见另一篇' <文件>`，逐句确认附近有 `](/blog/`。
