# 视频审查清单（短视频成片）

> 审查对象：nbdpsy-text-to-video 工作目录（shots.json / shot-NN.mp4 / narr-NN.mp3 / narr-NN.mp3.cues.json / manifest.json / final.mp4）。
> 立场：预设有问题，逐条找证据；不确定按 FAIL。
> **铁律：判断性条目必须抽帧/抽段实际观看**——至少覆盖首镜、中间一镜、末镜三处（用 ffmpeg 抽帧或直接播放片段取证）；未看片得出的结论视为审查无效。

**严重度四级**（与 checklist-note.md 同一套口径）：
`FAIL`=判定不通过 ｜ `blocker`=命中即 FAIL 且要单独列出（合规/法律级）｜
`major`=判定但不算 FAIL，可改良级 ｜ `issue`=记录留痕，不据此单独判 FAIL。

## 先认形态（决定后面哪些条目要跑）

本产线有四种成片形态，**判据不完全通用**，开审前先认清是哪一种：

| 形态 | 产物特征 | 本清单里**跳过**哪些 |
|---|---|---|
| 笔记微电影（默认主线） | AI 生成画面 + 烧字幕 + 可选 BGM | — 全查 |
| 轮播放映 | 小红书轮播图逐张放映，**首版规格无字幕** | 跳过 判-1（字幕同步）、判-4（画面内无文字：这条线画面就是信息图，本来全是字） |
| 字卡短片 | 纯文字卡片逐帧渲染 | 跳过 判-3（人物一致）、判-4 |
| 播客视频 | 黑底大字幕 + 声纹波形 | 跳过 判-3、判-4；判-1 改为查页级 cues 与音频同步 |

## 确定性检查（先跑，JSON 输出与 exit code 原样记入报告）

`{SKILL_DIR}` = nbdpsy-content-reviewer 本 skill 目录；`{T2V}` = 同级的 `../nbdpsy-text-to-video`。

| # | 命令 | 预期 | exit 语义 |
|---|------|------|-----------|
| 确-1 | `python3 {SKILL_DIR}/scripts/check_video.py --workdir <dir>` | 时长/时间轴/成片完整全过 | JSON 输出；任一未过 exit 1。检查项：每镜 shot-NN.mp4 ffprobe 实测时长 ∈[4,15]±0.5s；cues 每镜单调递增且末句 ≤ 旁白实测时长+0.2s；final.mp4 总时长 ≈ Σ每镜时长 ±10%；总时长 ∈[--total-min,--total-max]（默认 30–180s，可按用户对该条视频的要求覆写） |
| 确-2 | `python3 {T2V}/scripts/check_narration.py --shots <dir>/shots.json` | 每镜口播 ≤100 汉字 | **exit 1 = 有镜超字数 = FAIL**。JSON 的 `over[]` 直接给镜号/字数/超了多少。⚠️ 同时吐 `warnings[]`（十四律软提醒），那部分**不据此判 FAIL**，拿去喂下面的判-8 |
| 确-3 | `ffmpeg -hide_banner -nostats -i <final.mp4> -af loudnorm=I=-16:TP=-1.5:LRA=11:print_format=json -f null - 2>&1 \| tail -20` | `input_i` ∈ **−16 ±1 LUFS**；`input_tp` ≤ **−1.2 dBTP** | 无 exit 码，**读数字判**。超出 = FAIL（老板 2026-08-16 实听投诉「背景音太小」的根因就是这条没人量）。口径真源：`{T2V}/references/audio-checklist.md` §一 A1/A2 |
| 确-4 | `ffprobe -v error -select_streams a:0 -show_entries stream=codec_name,channels,sample_rate -of default=nw=1 <final.mp4>` | `aac` / `channels=2` / `sample_rate=48000` | 读数字判；不符 = `major`（A3 口径：单声道手机外放更闷、采样率漂移会让某些播放器变调） |

> ⚠️ **确-3 是本清单唯一的绝对响度量具，别用耳朵替代**。相对量（BGM 压差）全对得上、绝对量整体不合格，
> 是这条产线出过的真实事故形状——每一项单看都「按规范做了」，合起来是一条手机外放听不清的片子。
> ⛔ 也别用 `volumedetect` 的 mean_volume（RMS）换算：同一条片子 RMS 与 LUFS 结论方向相反（差 7 dB 以上）。

## 判断性检查（抽帧/抽段观看，逐条 PASS/FAIL + 证据 + 时间点）

### A. 音画技术层

1. **字幕与旁白同步**：在 final.mp4 上抽 3 处句边界（首镜一处、中段一处、末镜一处），实听实看：字幕切换点与旁白该句起止的偏差 <0.5s。任一处 ≥0.5s = **FAIL**，写明时间点与实测偏差。
2. **旁白完整无截断、无异常慢放画面**：逐镜听旁白结尾是否被切字；看画面是否有为凑旁白时长而出现的异常慢放/定格拖时间。发现即 **FAIL**，写明镜号。
3. **各镜风格/人物一致**：抽看的三镜（以及任何可疑镜）画风、色调、人物形象一致，不出现"换了个人/换了个画风"的跳变。不一致 = **FAIL**。
4. **画面内无任何文字（字幕除外）**：AI 生成画面里渲染出的伪文字/乱码招牌/图内标题都算违规——产线规则是文字一律走字幕层，画面本身必须无字。发现即 **FAIL**，写明镜号与时间点。
5. **BGM 不盖旁白**：抽听的三处旁白清晰可辨。产线基准是 **BGM 比旁白低 12–18 LU（LUFS 域，默认 14）**；任一处旁白被 BGM 淹没 = **FAIL**。
   ⚠️ 这条查的是**相对量**，与确-3 的**绝对量**是两件事，⛔ 不能互相替代——「BGM 压得对」和「整片够响」可以同时成立/同时不成立。
   ⚠️ 反向也要判：BGM 小到**听不见**同样是 FAIL（2026-08-16 老板实听的就是这一侧）。

### B. 合规层（blocker 级）

6. **片尾危机声明在**：结尾以字幕或画面呈现心理援助信息，必须含 **12356**（全国统一心理援助热线）。抽看末镜取证；缺失 = **blocker**。
   ⛔ 12356 **不得标注「24 小时」**（官方口径是每日 ≥18 小时）；唯一可标 24 小时的是 010-82951332。标错 = **blocker**。
7. **AI 标识状态在交付说明中声明**：交付说明（或报告本条）必须写明成片是否已叠加"AI 生成"标识（manifest 的 `ai_label` 是否生效、画面上是否可见）。叠加与否由发布者决定，但**状态必须如实声明**——未声明 = **FAIL**。

### C. 口播文字稿层（2026-08-17 补，此前**整层空白**）

> 📌 **为什么补这一层**：`{T2V}/references/narration-spec.md` 8/16 立了十四律 + 结构骨架 + 字数闸门，
> 但本清单当时只查成片层（字幕/画面/BGM/合规），**一条都没纳入**——做对抗审查的人根本不知道要查这些，
> 于是那些规范在审查环节等于不存在。取材：`<workdir>/shots.json` 的 `narration_text`（轮播线看分页口播稿）。

8. **十四律软提醒逐条过目**：把确-2 吐的 `warnings[]` 逐条看一遍，**逐条给判**。
   ⚠️ **这些是软提醒，不是自动 FAIL**——脚本只会正则命中，判在人。给判时按下表：

   | 命中 | 判 FAIL 的情形 | 该放行的情形（⛔ 别误判） |
   |---|---|---|
   | 第三律·书面连接词（不但/而且/既能/又能/综上/因此/其中） | 念出来像文件、不像人说话 | 「因此」在口语里也说得出口的语境 |
   | 第三律·「该」 | 作代词（该机构/该研究/该患者） | 作动词或助动词（该睡了/不该这样/该怎么办/应该/活该） |
   | 第五律·破折号 `——` | 一律改逗号/句号/冒号（TTS 当停顿念、字幕层已不显示） | 无 |
   | 第八律·完整引语 `「…」` | ≥2 字的完整引语（触发 TTS 角色扮演） | 单字引号（`「不」`），§三 实测不触发 |

   同一律命中 ≥3 处且确实都是书面腔 = **FAIL**；零散一两处 = `major`。
9. **结构骨架三段齐全**（narration-spec §八）：
   - **钩子**：第一句（最迟第二句）是全片最反直觉的那句。判据：听完说「啊？」才算数，**说「哦」就是没钩住** = **FAIL**。
   - **讲清**：中段道理由**场景**携带，不自己下场念论点。⛔ 「期待被摆正，比方法本身更要紧」这类论点行 = **FAIL**（老板判过「太糟糕」）；⭕ 「它是一个月的功课，不是当场的开关」这类落在观众能想象的东西上的 = PASS。
   - **收尾**：结尾十秒有一句观众会**原样转述给朋友**的话。答不出「观众会转述哪一句」= **FAIL**。
10. **临床逻辑单向 + 限定句在**（第四律 / 第十一律，**blocker 级**）：
    - 「X 常出现在 Y 人群」≠「有 X 就是 Y」；「这些反应有个名字，叫 Y」这种句式 = 暗示确诊 = **blocker**。
    - 反向事实与研究限定（「组间无差别」「心率没变化」「这是一个月的效果不是当场的开关」）**必须在**。为压时长删限定 = **blocker**（广告法口径的疗效暗示）。
    - ⚠️ 共情句顶替边界句不算数：「你不是一个人」是安慰不是边界（第十二律）。
11. **口播与画面逐项对齐**（第十四律）：口播说「两个数字」而图上有三条 = **FAIL**。抽看的三镜逐一对数字、数量词、列表长度。⚠️ 改图或改稿任一侧之后都要重对，这是双向的。
12. **指涉介质无关**（第九律）：出现「上一页/下一页/左边这张」= **FAIL**（视频不能回看）；「前面说的」是安全说法。
13. **专有名词未被口语化降级**（第十三律）：「澳大利亚新西兰复苏委员会」不能说成「复苏指南的那个机构」= `major`（权威感是科普的信用资产，口语化只准发生在句式上，不准发生在名词上）。

## 报告要求

- 确-1~确-4 的**原始输出与 exit code 原样记入**，⛔ 别只写「都过了」。确-3 必须写出实测的 `input_i` / `input_tp` **数值**。
- 判-1~判-13 逐条 PASS/FAIL/major/issue + 证据（镜号、时间点、原句）。
- blocker 单独列一节，前置在报告最上面。
- ⛔ **未看片、未跑命令得出的结论视为审查无效**——本仓的判据是「绿必须是被验证过的绿」。
