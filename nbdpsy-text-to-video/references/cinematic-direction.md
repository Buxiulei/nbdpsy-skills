# 电影感短视频方法论（1–3 分钟 · 即梦 Seedance）

**这份文档回答一个问题**：怎么把一段心理科普文字，做成一条**有电影感、有艺术感**的
1–3 分钟竖屏短视频，而不是一条"会动的插画 + 配音"。

适用范围：`nbdpsy-text-to-video` 的全部片子。写分镜、写提示词、审片之前**先读这份**。

## 零、第一条铁律：**「电影感」不能写进提示词**

公开指南把 `电影感 / cinematic / 氛围感 / 唯美` 这类词单列为一类失败源
（**feel-suffix slop**），原因很实在：**抽象评价词让模型不知道该强调哪个元素**，
把它拆成物理元素才稳定。

| 你想要的感觉 | ⛔ 别写 | ✅ 写造成它的物理原因 |
|---|---|---|
| 电影感 | "电影感画面" | 景别 + 运镜 + 光源方向 + 色调 |
| 高级/唯美 | "唯美treatment" | 具体颜色、材质、构图、光的行为 |
| 有张力 | "很有张力" | 谁先动、谁让出空间、画面占比、沉默几秒 |
| 情绪浓 | "情绪爆发" | 一个可拍的抑制动作（攥紧、屏息、别开眼） |
| 高质量 | "8K / 大师作品 / 获奖" | **删掉**——画质是参数不是提示词 |

还有两类要避开：

- **否定式的规矩按版本分**（官方 2.5 手册修正了此前认知）：
  - 2.0 时代的社区经验是「否定会召唤，别写否定」；
  - **2.5 官方公式自带「禁止项」模块且明确推荐**——官方案例大量使用
    `禁止生成字幕、强制静音去除自带 BGM、禁止大幅肢体动作、禁止五官崩坏、
    禁止背景出现长相相同的克隆人`，且 2.5 专门优化了负向响应（发布亮点之一就是
    解决"随机字幕和无关 BGM 意外出现"）。
  - **我们的用法**：禁止项**集中写在【全局补充】**（官方位置），别散在每个分镜里；
    写**具体行为**（"禁止眼泪提前滴落"）而不是抽象品质（"不要难看"）。
- **标签堆砌**：从生图提示词搬过来的逗号关键词流。视频提示词要写成**拍摄通告**：
  一句话说一个元素——主体、动作、镜头、光、声音。

## 一、开工前：先做「导演读解」（内部规划，不进提示词）

动笔写分镜前，先把这几件事在心里（或 workdir 的 `direction.md` 里）想清楚。
**这一步不产出提示词，只产出判断**——但它决定成片是有内容还是只有画面。

### 先分车道

| 车道 | 什么时候用 | 我们的典型内容 |
|---|---|---|
| **叙事** | 有人在追求、抵抗、选择、隐瞒、反应、改变 | 「她想开口却咽回去」「被批评时表面笑着」 |
| **非叙事** | 纯说明、纯氛围、纯展示，没有人物能动性 | 数据可视化、纯空镜氛围片 |

**心理科普 90% 是叙事车道**——因为我们讲的是"人在某个处境里的真实反应"。
⛔ 不要为了显得有戏，硬给一段纯说明加上"内心挣扎"。

### 叙事车道的六个必填（缺一个就会拍成空镜合集）

1. **这一段挣到了什么**：介绍 / 加深 / 转折 / 揭示 / 决定 / 收束——一段只做一件；
2. **转折点**：这一段结束时，什么和开始时不一样了（哪怕只是观众的理解变了）；
3. **视角**：观众通过谁的经验看这件事；
4. **她想要什么 / 在躲什么**：焦点人物的真实目标（往往和她说的话相反）；
5. **一个可见的抑制动作**：把冲动"压住"的那个小动作——**这是全片最值钱的一格**。
   例：脸上笑着但**桌下攥住衣角**；想说话但**嘴唇张开又抿住**；
6. **拒绝哪个套路**：这个题材最容易的偷懒拍法，本片明确不用。
   例：讲创伤不用"抱头痛哭 + 弦乐涌起"，改用"她照常上班、谁也不提"。

> 第 5 和第 6 是把片子从"科普配图"抬到"作品"的分界线。

## 一之二、全片视觉设计（导演阐述——比逐镜分镜更高一层）

逐 beat 的导演读解（上一节）管"这一段拍什么"；本节管**全片看起来是一部作品而不是
镜头合集**。写分镜前先定三条弧线，写进 workdir 的 `direction.md`：

### 1. 色彩弧线（颜色就是叙事）

大师级作品的颜色是随情绪走的，不是一套色板铺到底。我们的三色板（雾霾蓝灰/暖米白/
鼠尾草绿）不变，**变的是配比与光**：

```
CPTSD 片示例：
开场（困境）  蓝灰主导、暖色只从门缝/屏幕漏一点 —— 冷包围暖
中段（看见）  蓝灰与暖米白拉锯 —— 每认出一个场景，暖多一分
收尾（和解）  晨光暖米白铺满、鼠尾草绿点缀 —— 暖包围冷
```

**检验**：把 9 个 beat 的首帧排成一排看缩略图，颜色应该讲出和旁白同一个故事。

### 2. 光线弧线（光源方向 = 时间 = 情绪）

深夜顶光/屏幕冷光 → 清晨低角度侧光 → 晨光满溢——**光的角度和色温单独排一条弧线**，
在每镜提示词里落实（"门缝暖光在她身后"/"晨光斜照进来"不是装饰词，是弧线上的坐标）。

### 3. 视觉母题（一个意象贯穿全片）

选一个具体物件/构图在全片出现 ≥3 次、每次含义递进。例：**热茶**——开场捧着（自我安抚）、
中段凉在桌上没人喝（顾不上自己）、收尾冒着热气（重新照顾自己）。母题让观众"感觉到
结构"却说不出为什么——这就是作品感的来源。

## 二之二、关键镜多条选优（coverage——真实片场从不只拍一条）

「抽卡是常态」是被动说法；主动版本是**导演的 coverage**：重要的戏拍多条，剪辑台上选。

| 镜头 | 建议条数 | 为什么 |
|---|---|---|
| **钩子段（前 3 秒所在段）** | **3 条** | 前 3 秒决定完播率，是全片 ROI 最高的积分投入 |
| 收尾段（情绪落点） | 2 条 | 留白的分寸靠选不靠赌 |
| 中段常规叙事 | 1 条，坏了再补 | 观众在这里已经进入内容，宽容度高 |

写法：同段 prompt 微调 1–2 处（换运镜/换构图）各提交一次（不同 client_ref），
**是变体不是重试**——目的是有得选，不是修故障。预算按「基础积分 × 1.5」打，
比全片均匀抽卡便宜且效果好。

### 前 3 秒军规（平台现实，与电影美学并存）

- 第 1 秒必须有**已经在发生的动作或反差**（她已经垮在门上，而不是走向门）；
- 钩子句前 3 个字要压住话题（「这些应激——」）；
- ⛔ 开场禁用：淡入、空镜起手、logo、任何"铺垫"——铺垫是完播率杀手。
  电影可以慢热，**竖屏短视频的"慢"只能放在中后段**（观众 10 秒后才给你慢的权利）。

## 六之二、声音叙事（声音不是配菜，是另一条剪辑线）

我们现在的声音是三层平铺（旁白+BGM+环境音）。导演级至少要会三招：

1. **静默是最贵的音效**。全片最重的一句话（如「不是你的错」）前，**BGM 和环境音全部
   收掉 0.5–1s**，只留旁白——观众的耳朵会替你把这句话放大三倍。官方舞会案例的
   "世界剥离后耳鸣感"就是这一招的极致版；
2. **BGM 要有弧线**，不是一条平铺到尾：开场极轻（-18dB 相对旁白）→ 中段常规（-12dB）→
   金句处收空 → 尾声回来渐弱收尾。当前 compose 只支持全局 bgm_gap_db，
   分段音量自动化在待办（见八之二）；
3. **声音先入（J-cut）**：下一场景的环境音提前 0.5s 进来（晨光镜的鸟鸣在深夜镜结尾
   就响起）——场景切换会顺滑一倍。生成侧做不了，合成侧 ffmpeg 可做，同在待办。

## 二、分镜设计：三个维度一起动

### 2.1 景别节奏（最容易被忽略的一维）

每个 beat 至少有一次**景别跳跃**，否则画面会"平"。基本节奏：

```
交代 → 情绪 → 细节
全景/中景     面部特写     手部/物件空镜
```

- **全景/中景**：交代人在哪、和谁在一起、环境什么状态；
- **面部特写**：情绪落点，一段里最多用一次，用多了就不值钱；
- **手部/物件特写**：最有力的抑制动作载体（攥紧、停在半空、反复摩挲）；
- **空镜**：给情绪留白，也是段落之间的呼吸（滑落的包、走针的闹钟、凉掉的茶）。

⛔ 连续两个同景别镜头相接 = 视觉上像没切。

### 2.2 运镜（一镜一个动作，不叠）

官方运镜词表：**推 / 拉 / 摇 / 移 / 跟 / 环绕 / 升降 / 希区柯克变焦**。

规矩三条：

1. **一个镜头只给一个运镜动作**，且写明起点与终点（"从盔甲缓摇到晨光中的人"）；
2. **情绪镜用固定或极缓推**——运镜越花，情绪越轻；
3. ⛔ 同一镜里不要既"固定"又"环绕"（指令冲突，实测会出鬼畜）。

### 2.3 节奏（秒数怎么定）

**我们的产线是旁白驱动**：`beat 时长 = 旁白实测 + 0.3s`，由 `sync_durations.py` 写回，
**不许手填**（手填是画面被异常放慢的头号事故源）。

在 beat 内部分镜：

| 镜头类型 | 建议时长 |
|---|---|
| 交代镜（全景/中景） | 3–5s |
| 情绪镜（面部特写） | 3–4s |
| 细节镜（手部/物件） | 2–3s |
| 空镜（呼吸） | 2–3s |

> ⚠️ **秒数精度按版本分**（2026-08-06 官方 2.5 手册修正了此前认知）：
> - **seedance2.5：时间戳控制是官方头牌新功能**——"可精确到具体秒数下达指令，控制画面中的
>   动作演变与场景转场，实现剧本级的精准还原"。官方案例全用 `[00:00 - 00:07]` 格式，
>   **放心按秒写**（仍用整数秒，别写 0.1 位小数）；
> - 2.0 家族：对精确秒数支持不稳定，写整数段当节奏引导。
> 各段之和 ≤ `duration` 两代都要守。

## 三、提示词：官方四段式

```
【风格】___风格，___比例，___氛围（用物理描述，不用"电影感"）
【角色】全片同一人的固定描述（脸型/发型/服装），写明"不变"
【时间轴】
0-4秒：[景别] + [画面内容] + [人物动作] + [运镜]
4-8秒：硬切到 [新场景]。[画面] + [动作] + [运镜]
...
【声音】环境音 + 音效（⛔ 我们的旁白走后期 TTS，这里明确禁止对白/人声/配乐）
【参考】@图片1 ___用途，@图片2 ___用途，@视频1 ___用途
【要求】镜头之间硬切不要转场特效；画面无任何文字与字幕
```

### 三条硬规矩

1. **每张素材必须被 `@图片N` 明确引用并说明用途**。传了不引用 = 白传还占配额；
   引用不说用途（只写"参考@图片1"）= 身份/场景/运镜互相污染；
2. **顺序即语义**：数组第 N 张就是 `@图片N`。我们的脚本保证保序不去重，
   server 也承诺不动顺序——但**你写 prompt 时的编号必须和传图顺序对上**；
3. **长度取舍**：短提示词（30–100 字）指令遵循更好，300+ 字开始衰减；
   但带多素材的分镜型实际需要 800–1500 字。
   **解法是减少单条的镜头数（一条装 2–3 个分镜段），而不是压缩每段的描述精度。**

### 素材角色分工表

| 位置 | 放什么 | 提示词里怎么引 |
|---|---|---|
| `@图片1` | **角色卡**（正/侧/背 + 表情 + 手势） | `@图片1 的人物作为主体，保持面部与发型一致` |
| `@图片2` | 场景/环境 | `场景参考 @图片2 的空间与光线` |
| `@图片3+` | 道具、分镜关键帧、风格样张 | 逐一标注用途 |
| `@视频1` | **运镜参考**（想要的镜头调度） | `参考 @视频1 的运镜与节奏，不要复制其内容` |
| `@音频1` | **节奏卡点** | `画面切换卡 @音频1 的节奏，只取节奏不取内容` |

> 视频/音频参考是**文字描述做不到的事**——"缓慢推近"人人会写，但"像这段一样推"只能靠喂参考。

## 三之二、分镜怎么写：Mx-Shell 的四件套（**本节最重要**）

来源：`jnMetaCode/ai-shortfilm-prompts`——《丧尸清道夫》作者 Mx-Shell 的开源方法论
（该片被好莱坞导演 PJ Ace 公开找人，称"这些年看过最好的短片之一"）。
他的一句话总结值得抄在墙上：

> **像写分镜脚本一样写提示词，而不是像写文学描述。**

### 他的 5 段结构（顺序不能乱）

```
1. 核心主题       ← 一行风格标签，给 AI 定调
2. 人物与基础设定 ← 面部 / 服装 / 场景，三行
3. 氛围与画质     ← 模拟真实摄影机 + 镜头
4. 运镜规则       ← 单镜头 / 角度 / 呼吸感
5. 分镜（时间轴） ← 按秒或按镜头展开
```

对照我们在用的官方四段式：**这两套不冲突，是同一件事的粗细两档**。
官方公式给的是骨架，Mx-Shell 给的是每根骨头上该长什么肉。我们的做法：
**外层用官方四段式（服务端契约认它），内层的【时间轴】按 Mx-Shell 的四件套写。**

### 分镜两种写法，按场景选

**写法 A · 按秒切片**（单镜头一镜到底：情绪推进、动作展开）

每段三件套：**动作 + 镜头 + 特效**（可选加「声音」「面部」）：

```
0-3秒 · 凝视
动作：她略微低头，目光落在杯口，脊背绷着。右手缓慢收紧。
镜头：极缓向前推进，捕捉呼吸带来的微幅起伏。
特效：窗外光斑在她脸侧缓慢移动。
```

**写法 B · 按镜头切片**（多镜头剪辑——**这就是《丧尸清道夫》的写法，也是我们该用的**）

每个分镜四件套：**景别 + 构图 + 运镜手法 + 画面内容**：

```
分镜一：
景别：中景，拍摄人物腰部以上。
构图：人物背影作为前景居中，背景左侧是玄关门，右侧是鞋柜。
运镜手法：镜头缓慢推近。
画面内容：她背对镜头进门，整个人靠上门板垮下来，包滑落到地面。
         片刻后她闭眼长呼一口气，肩膀彻底松掉。

分镜二：
景别：特写，拍摄面部。
构图：面部占画面三分之二，右侧留白给门缝漏进的暖光。
运镜手法：极缓推近。
画面内容：她闭着眼，眉心先松开又皱起，是社交结束后的空白与疲惫。
```

**为什么四件套比我们原来的写法好**：我们原来一句话混着写（"中景硬切到深夜玄关，她背靠门板
垮下来，镜头缓慢推近"），模型要自己拆解哪部分是构图、哪部分是内容。**拆成四行，每行只回答
一个问题，模型的遵循度明显更高**——这也是他 200+ 镜头实战出来的结论。

### 三个反直觉但有效的原则（他反复强调）

**① 不要给参考图，除非画质够高**

> "我的所有假面骑士的战衣造型都是靠描述让 AI 自由发挥的。"

垫图最大的副作用：AI 会复现参考图的**画风**（包括 CG 感、动漫感），而不是参考它的**设计**。

⚠️ **这条与"角色卡"的做法直接冲突**（见第四节），也与另一份公开 skill 的主张冲突。
我们的处境是**插画风 + 需要跨镜人物一致**，与他的"真人特摄风 + 单镜头"不同，所以
**不照搬，但要实测**：同一段落跑「带角色卡」与「纯文字描述」两版，比人物稳定度。
在有实测结论之前，本条记为「未定」，不要当成定论用。

**② 描述瑕疵 = 描述真实**

> "过于完美，就假。适当地保留缺陷不是坏事。"

他的质感来源是这类词：`战损痕迹`、`各处磨损掉漆`、`关节油污`、`保留轻微面部瑕疵`。

**我们的插画风怎么用**：不写"完美的构图/精致的画面"，改写具体的不完美——
`针织衫袖口起球`、`马克杯有一道旧茶渍`、`窗玻璃上有指印`、`绿植有两片叶子发黄`。
**这些细节让画面从"素材图"变成"某个人真实的家"**。

**③ 抽卡是常态，结尾要留白**

200+ 个镜头，每个少则两三次、多则 20+ 次才挑出能用的。**不要指望一次成型**——
这条直接影响预算规划（见第五节的成本估算，按 2–3 倍抽卡率算）。

结尾别堆特效：

> "没有台词。没有爆炸。没有光芒万丈。只有身穿不完整战衣的人站在原地。"

我们的收尾镜（晨光里的窗边）正是这个路子，保持住。

### 摄影机锚点（段 3 的技巧，我们可以直接用）

他的原理：**AI 训练数据里大量电影摄影描述都和真实机型绑定，给一个具体机型 = 给一个明确的
视觉风格锚点**。他的常用组合：

| 风格 | 摄影机 + 镜头 |
|---|---|
| 史诗 / 大场面 | IMAX 胶片摄影机 + Panavision C 系列（35mm，f4） |
| 暗调赛博 / 写实硬核 | 索尼威尼斯 + 佳能 K-35 |
| 港片 / 武侠 | 柯达 35mm 复古胶片，跳过漂白 |
| 商业人像 | Canon EF 85mm f/1.2 |

**我们是插画风，不用真实机型**，但同一个原理可以迁移到插画语汇：
`绘本水彩质感`、`赛璐璐平涂`、`细腻线稿加淡彩`、`纸质纹理可见`——
**给一个具体的画种，比说"高质量插画"有效得多**。

### 「呼吸感」——他几乎每条视频都写

```
呼吸感：手持拍摄，全程保持极其轻微的、如呼吸般的镜头浮动，增强临场感。
```

目的是**避免 CG 感的僵直镜头**。我们的固定镜头（情绪特写、空镜）尤其该加这一句，
否则容易出"PPT 静帧"的观感。

## 三之三、官方 2.5 公式与新武器（2026-08-06 官方手册，一手）

手册原件：`NBDpsy/文档/2026-08-06-即梦Seedance2.5官方手册-提取文本.txt`（1142 段全文）。
本节只收**改变我们做法**的部分。

### 官方 2.5 完整公式（比 2.0 四段式多了「全局补充」）

```
完整提示词 = 【素材描述】+【一句话概述】+【具体情节描述】+【全局补充（结尾）】

素材描述：素材编号（按上传顺序）+ 具体用途（人物/音色/动作/场景）
一句话概述：主体 + 地点 + 事件 + 题材/风格 + 特殊运镜
具体情节描述：分时间轴写；每段 = 正向描述（画面+运镜+动作+台词+音效）
                                + 反向描述（不要字幕、不要 bgm）
全局补充：结尾再次强调贯穿全片的元素（机位/场景特征/声音氛围/光影），
          以及全局禁止项（字幕、bgm 在此处再强调一遍）
```

**30 秒以上的长视频用三模块变体**（官方案例全按这个）：

```
【多模态参考层】 基于上传的[素材]，严格保持 @图1 的人物面孔一致，严格锁定人物站位…
【全局设定】     基础环境与质感 + 视觉风格 + 镜头语言 + 人物造型 + 表演核心 + 禁止项
【时间戳剧本分镜】[00:00-00:07] 镜头一：【标题】
                 动作/物理指令：……
                 潜台词：……
```

### 「潜台词」——官方案例每镜都写，我们此前完全没有

每个时间切片除了物理指令，还要一行**潜台词**：向 AI 解释这组物理指令的深层表达。
官方案例：

> 动作/物理指令：极端微距特写。画面是一片带露水的发光芭蕉叶……
> **潜台词：极度的静谧与唯美。用微观视角拉近观众与角色的距离。**

**并入我们的分镜四件套后，每镜五行**：

```
分镜二：
景别：特写，拍摄面部。
构图：面部占画面三分之二，右侧留白给门缝漏进的暖光。
运镜手法：极缓推近。
画面内容：她闭着眼，眉心先松开又皱起。
潜台词：社交结束后的空白与疲惫——不是难过，是被抽干。
```

### 人物八维公式（官方，动画人物同样适用）

```
人物 = [年龄/种族] + [肤色/皮肤质感] + [面部细节特征] + [眼神/灵魂]
     + [发型/发色] + [服装/服装质感] + [体型/情绪/气质] + [其他要求]
```

要点：**[眼神/灵魂] 单独一维**（"眼神涣散、目光低垂没有焦点，透着深深的疲惫"）——
这正是我们「抑制动作」哲学的面部版。我们的人物锁按此扩写，不再只有"圆脸+发型+针织衫"。

### 九种转场（官方词表 + 固定咒语）——艺术感的核心工具箱

此前我们只会写"硬切"。官方给了九种，每种有**固定咒语**：
`需要在切镜处使用"XX"转场（禁止生硬切镜、禁止物体凭空出现）……要求必须自然切换场景。`

| 转场 | 是什么 | 适合我们的场景 |
|---|---|---|
| **自然镜头切换** | 软性硬切：强调"镜头呼吸感与时长协调，留出足够的切换时间" | **绝大多数常规叙事的默认选择**（比裸硬切少突兀感） |
| 淡入淡出 | 画面渐黑/渐白再浮现 | 时间流逝、段落彻底结束（beat 组之间） |
| 硬切 | 直接切 | 场景清单式快切（应激场景列举） |
| 白闪/黑闪 | 强光/全黑一闪 | 情绪重音（心跳、被批评的瞬间） |
| 遮罩 | 物体遮挡镜头变黑后拉开已换场景 | 门框/背影/枕头遮挡换场景 |
| **相似物** | 前后镜形状/颜色相似无缝变形 | **圆月→杯中茶、手机光→晨光**（诗意换场首选） |
| 动作甩镜 | 猛甩产生模糊后接入 B 场景 | 情绪爆点（我们用得少，太烈） |
| 动态接力 | 人物动作跨场景延续 | 躺下→在另一场景醒来 |
| **拉近/拉远** | 瞳孔/细节放大成新场景全貌 | **瞳孔里展开回忆场景**（创伤闪回的天然语法） |
| 水墨 | 墨滴晕染换场 | 不合我们画风，不用 |
| 擦除 | 推拉门式覆盖 | 复古感，不用 |

**「相似物」和「拉近/拉远」是我们最该用的两种**——心理科普讲"此刻的反应连着过去的经历"，
瞳孔套娃转场（现在→童年场景）就是这句话的镜头语言。

**拿不准用哪种时可以让模型自己挑**（官方推荐的写法）：
`请从 [自然镜头切换 / 遮罩转场 / 相似物转场] 等转场方式中，根据本片风格选择最合适的一种。`


### 官方治愈系样板：《奶奶的菜谱》（离我们调性最近的案例，四个启示）

官方案例里唯一的温情治愈片（毛毡风动画，24s/720帧）：女孩照亡奶的手写菜谱做菜、
生疏→闪回幼年奶奶握着她的手→做成、尝一口眼眶泛红、结尾看向旧照片。手册原文在
提取文本 680 段附近，值得整段细读。启示：

1. **【全局约束声明】置顶而非收尾**——风格锁（"全片严格采用动画毛毡风，禁止任何画面
   出现风格偏移"）+ 字幕禁令 + 素材映射放在 prompt 最前面。与「全局补充在结尾」不矛盾：
   **约束放头、氛围收尾，重要禁令两头都放**；
2. **叠化回忆闪回是官方语法**：`画面叠化为暖黄回忆闪回——幼年的她被奶奶从背后握着小手
   一起翻炒……叠化拉回现实`。这是"此刻连着过去"的第二种镜头语言（第一种是瞳孔套娃），
   **更温和，适合我们大多数场景**；
3. **音效可以点位到帧**：`第 60 帧远处挂钟"滴答"声`、`第 180 帧锅铲碰撞声`——
   环境音不只是氛围铺底，可以当**节拍器**精确埋点。我们按秒写就够（`第 14 秒抽纸声`），
   但要知道精度上限在帧；
4. **片尾金句字幕可以由模型直出**：`除结尾淡入的指定字幕外，全片绝对禁止生成任何其他
   字幕`——结尾「有些味道，藏着一个人」是模型渲染的。我们的字幕全走 ffmpeg 后期没错，
   但**片尾情绪金句**（如「不是你脆弱」）可以试试让模型自己淡入，比后期贴字更有片感；
   台词也能控制到「仅发声，无字幕」。

### 官方抽卡数值（写进预算估算）

| 项 | 效果较好 | 可尝试但稳定性下降 |
|---|---|---|
| 参考图张数 | **1–5 张** | 6–8 张 |
| 主体图数量 | 1–8 主体 | 9–12 |
| 音视频参考时长 | 5–10s | 更长 |
| 视频编辑输入 | 20s 以内 | 更长 |

⚠️ 上限 30 张是**能传**，官方建议常用 **1–5 张**——多图槽用来放"角色 2–3 视图 + 场景 1–2 张"
正好落在甜区，别把 30 张当目标。

### 素材硬规格（传前自检，超了白跑）

图片：单张 <30MB，宽高比 (0.4, 2.5)，边长 300–6000px，请求体总 <64MB；
视频参考：单个 <200MB，2–30s，总时长 ≤30s，FPS 24–60，分辨率 480p–4k；
音频参考：单个 <15MB，2–30s，总时长 ≤30s，wav/mp3。

### 网页版专属能力（CLI/API 没有，创作时要知道）

| 能力 | 说明 | 对我们的意义 |
|---|---|---|
| **超长视频模式** | **单次直出 30–180 秒**；prompt 即全片剧本（官方案例一条装 9–10 段分镜） | 1–3 分钟片可一次生成——但只在网页端；API 路仍走分段拼接 |
| 视频延长 | 30s 内底片可套娃延长至 60s；提示词只对新增段生效 | **「分段式导演控制」**：官方推荐"走一步看一步"——先生成 10–12s 确认方向，满意再延长下一段（官方案例 12s→+5s→+13s 三步接力到 30s）。**每步都是确认点，不用一次赌 30 秒**。延长切镜处用转场公式：[转场类型指引]+[基础约束]+[切镜逻辑]；必带词：向后延长/延续/续写 |
| 智能/高级/视频编辑 | 框选+提示词改局部，全片保持一致 | 返工神器：坏一处不用整段重抽 |
| 白模控制 | Maya/Blender 插件导出 camera 路线喂参考 | 工业级运镜（对我们过重，记录备查） |
| 多宫格分镜图 | 线稿/火柴人分镜图当剧情参考 | **skill 可以先出一张线稿分镜图再喂它**（待实测） |
| 绿幕/BGM分离/音色克隆 | 后期向能力 | 备查 |

这些已写进 server 需求（哪些能经 CLI 升级拿到、哪些永远是网页版，等 server 回执）。

## 四、人物一致性：角色卡 vs 纯描述（**未定，待实测**）

行业里最常见的失败是「**人物一动就变脸，镜头推进后五官崩掉**」。

**三种主张，三方打架**（如实列，别当已有定论）：

| 来源 | 主张 | 理由 |
|---|---|---|
| 中文教程（角色卡流） | 三视图角色卡（正/侧/背 + 表情 + 手势） | 给足信息，模型不用猜 |
| `Emily2040` skill | **单张独立标准像**，别用多视图素材 | 多视图会让模型把"拼版"本身当画面 |
| **Mx-Shell（丧尸清道夫）** | **干脆不垫图，纯文字描述** | 垫图会复现参考图的**画风**（CG 感/动漫感），而非它的**设计** |

**官方 2.5 手册直接裁决了这个悬案**（素材建议表原文）：

> 1–5 主体，「单视图」「多视图」均可；超过 5 主体，「单视图」效果较稳定；
> 如需输入多视角，**建议拆分为多张不同视图输入，而非输入一张包含多视角的图**
> （效果稳定性：**多图多视图 > 单图多视图**）。

**定案**：⛔ 不做"一张图里拼正/侧/背"的三视图角色卡（单图多视图是最差选项）。
我们的做法：**角色出 2–3 张独立单视图**（正面标准像 / 侧面 / 一个关键表情），
分别作为 `@图片1 @图片2 @图片3` 传入，提示词里逐张说明视角用途 + 强身份锁
（"全片同一人：圆脸、齐肩微卷黑发、燕麦色宽松针织衫，服装发型不变"）。
Mx-Shell 的"干脆不垫图"保留为备选：若实测发现垫图把画风带偏（插画变 CG），退回纯描述。

## 五、1–3 分钟怎么组织（分段策略）

即梦单次最长 **30 秒**（seedance2.5）。1–3 分钟必然是多段拼接，**分段点的选择就是剪辑**。

### 分段三原则

1. **切在旁白边界**，不切在句子中间——`cut_assemble.py` 按 `narr-NN.mp3` 实测时长切；
2. **镜头密度按官方案例定**（比 server 早前建议的 2–3 段更宽）：30s 一条装 **4–5 镜**
   （官方魔法森林/机甲/舞会案例全是这个密度）；网页端超长模式（30–180s）一条 prompt
   可装 **9–10 段**（官方 75s 案例 10 段、90s 案例 9 段）。⛔ 别超过官方案例密度——
   镜头再多，每镜分到的描述精度就撑不住了；
3. **一段 = 一个场景单元**。同一段内的镜头共享空间与光线，跨段才换场景——
   这样段间的风格差异刚好落在观众预期的"换场"上，不会被看成穿帮。

### 三种片长的骨架

| 片长 | 段数 | 结构 |
|---|---|---|
| 60s | 3 段 | 钩子（10s）→ 展开（35s）→ 收束+合规（15s） |
| 90s | 4 段 | 钩子 → 展开 A → 展开 B → 收束 |
| 3min | 6–7 段 | 钩子 → 三段展开（各一个分论点）→ 转折 → 收束 → 尾声 |

**越长越要给呼吸**：3 分钟片里每段结尾留一个 2–3 秒空镜，否则观众会累。

## 六、声音设计（我们的特殊约束）

我们的旁白走**豆包克隆音色 TTS**（全片同一把声音），BGM 走后期 ffmpeg 混音。所以：

- 提示词的【声音】段**只要环境音**：关门声、抽纸声、键盘、闹钟、鸟鸣、室内静默；
- **明确禁止**：对白、人声、配乐——否则会和我们的旁白打架。
  ⚠️ 注意这是**我们的选择而非模型限制**：2.5 能生成完整对白叙事（官方 75s 案例里
  录音机的女孩台词、男主低声回答都是模型直出）。哪天要做「人物开口说话」的片子，
  这条路是通的——但音色/情绪不可控，与克隆音色旁白混用会撕裂，须整片二选一；
- 生成片自带的音轨在 `cut_assemble.py` 里被 `-an` 丢弃。
  **若哪天要保留环境音**，改那一处，并在 compose 层做旁白/环境音的响度平衡。

## 七、对抗审查清单（出片后逐条过，交 content-reviewer）

**画面**

- [ ] 人物在所有镜头里是同一个人（脸型/发型/服装）
- [ ] 没有连续两个同景别镜头相接
- [ ] 每个 beat 至少有一次景别跳跃
- [ ] 画面里**没有任何文字**（模型经常偷偷加字，这是最高频返工点）
- [ ] 手部没有畸变（特写手部时尤其查）
- [ ] 镜头切换是硬切，没有意外的渐变/特效转场

**内容**

- [ ] 每个分镜段有可辨认的"转折"，不是同一状态的重复
- [ ] 至少有一个**可见的抑制动作**（这是我们要的艺术性落点）
- [ ] 没有落进第一节列的套路拍法

**合规（心理科普红线）**

- [ ] 不出现诊断式判断、疗效承诺、病程叙事
- [ ] 不出现任何联系方式（微信/二维码/外链）
- [ ] 片尾有「本视频为心理科普不构成诊断」+ 心理援助热线 12356
- [ ] 成片带「AI 生成」角标（`build_manifest.py` 默认写入，别关）

**技术**

- [ ] 字幕与旁白真同步（`narr-NN.mp3.cues.json` 存在）
- [ ] 每段画面长度 ≥ 对应旁白长度（不足会被 `cut_assemble` 告警）
- [ ] 成片总长与规划一致

## 八、已知的坑（实测与回执确认）

| 坑 | 表现 | 规避 |
|---|---|---|
| 秒数写太精确 | 硬卡 0.1 秒精度，结果异常 | 写整数段，当节奏引导 |
| 一条塞太多镜头 | 后面的镜头被忽略 | 一条装 2–3 段 |
| 提示词 300+ 字 | 指令遵循衰减 | 减镜头数，别减描述精度 |
| 素材传了不引用 | 白传还占配额 | 每张都写 `@图片N ___用途` |
| 引用不说用途 | 身份/场景/运镜互相污染 | 指明"参考它的什么" |
| 内容与时长不匹配 | 15 秒脚本只够 4 秒 | 一个分镜段 3–8 秒，按此估 |
| 写实真人脸 | 平台直接拦截 | 我们是插画风，天然规避 |
| 2.5 没有 1080p | 想要高清却选了 2.5 | 要 1080p 只能 `seedance2.0_vip`（代价：时长上限 15s） |
| 活动/组件类平台入口 | 编辑页入口被平台收走 | 与视频无关，见小红书 skill |
