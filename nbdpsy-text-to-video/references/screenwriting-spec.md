# 微电影编剧规格（科普故事化演绎 · 30s–3min 竖屏）

> **方法论骨架源自 shanyin-screenwriting-master**（MIT License，© 2026 Shanyin-ai，
> github.com/Shanyin-ai/shanyin-screenwriting-master），经 NBDpsy **双层结构**（真论据 + 虚构故事）
> 与**全自动产线**适配改写。原版的人机对话纪律、长片/剧集全部内容已舍弃，见 §11。

**这份文档回答一个问题**：老板给一句话种子（一个科普点 / 话题 / 新闻 / 观点 / 标题），
怎么把它变成一条**有悬念、有反常、有故事**的 30s–3min 竖屏微电影剧本，
而**科学内核一个字都不许编**。

**与既有文档的分工**（别重造，交接点写死）：

| 环节 | 归谁管 |
|---|---|
| 讲什么故事（概念 / 结构 / 剧本 / 台词） | **本文件** |
| 怎么拍出来（分镜五行 / 提示词 / 转场 / 物理一致性 / 色彩光线弧线） | `cinematic-direction.md`，**冲突以它为准** |
| 旁白逐字稿怎么写与审校（六律 / DeepSeek 三轮 / TTS 引语坑） | `narration-spec.md` |
| 脚本怎么跑（十步产线 / 字段契约 / 积分排队） | `SKILL.md` |

术语沿用 `cinematic-direction.md`：**beat** = 一条旁白单元；**segment** = 一次即梦生成（≤30s，
段内含 4–5 个分镜）；**分镜** = segment 内的一个镜头，按五行写（景别 / 构图 / 运镜手法 / 画面内容 / 潜台词）。

## 一、定位与双层结构铁律（本文件最高优先级，与任何创作诉求冲突时它赢）

**一句话定位**：**论据是真的，故事是编的，两层必须让观众分得清。**

### 1.1 论据层（内核）——三条硬约束

1. **必须有可查证出处**：同行评议文献 / 教科书级共识 / 权威机构（WHO、NIMH、中华医学会等）公开材料。
   出处在剧本定稿前就写进内容定稿卡（§2.3），不是拍完再补。
2. **⛔ 三禁**：禁编造数据（"研究表明 73% 的人……"——除非你手上真有那篇）、禁虚构研究与机构、
   禁把演绎结果当事实陈述（"所以她的杏仁核就永久变大了"）。
3. **不确定就降级说法**，别赌：`常见于` 可以，`就是` 不行；`可能与……有关` 可以，`导致` 不行。
   查不到就换种子（§2.4），⛔ 不许"先写着，出处后面找"。

### 1.2 故事层（外壳）——可以全虚构，就是要虚构才有戏

1. 人物、姓名、职业、情节、场景、对白 **全部可以是编的**，而且**应该**编——真实案例既有伦理风险
   又没有戏剧性，编出来的才能把机制推到极端。
2. **⛔ 虚构人物不得使用任何真实来访者信息**：不取材于任何咨询记录、私信、线索表、评论区求助；
   即使做了"改编脱敏"也不行——判据是**这个人物的任何一个细节能不能被当事人自己认出来**，
   能就重写。素材来源只能是公开科普材料 + 纯想象。
3. **成片必须带"演绎创作"标注位**（落地位置见 §1.4，终审钩子见 §10.4）。

### 1.3 红线：观众不能把虚构桥段当成心理学结论记走

这是本文件存在的理由。故事越精彩、隐喻越具象，观众越容易把**画面**当成**机制**记住。

**判据**（写完每一段问自己）：如果观众只记住了这一段的画面，
他会不会转述成一句**错误的心理学结论**？会 → 必须消歧。

**三种消歧手段，按力度从轻到重**：

| 手段 | 怎么做 | 什么时候用 |
|---|---|---|
| **旁白点破** | 在隐喻出现后的**下一条 beat** 用人话说明它是比喻：「当然没有真的闹钟。是身体里的皮质醇在早上升高，把人推醒。」 | **隐喻具象化产物必用**（§3-A-3） |
| **句式限定** | 论据句一律单向：`X 常出现在 Y 身上` ⭕；`有 X 就是 Y` ⛔（沿用 `narration-spec.md` 第四律） | 所有涉及症状/诊断的句子 |
| **结构隔离** | 故事段与解释段在**不同 beat**，不混在一句话里；解释段的画面用空镜/物件，不用剧情画面 | 论据本身反直觉、容易被误读时 |

**对错例句（同一个论据：皮质醇晨峰 = 醒来后 30–45 分钟皮质醇达到日内高峰）**

- ⛔ 「她每天六点被一只看不见的手拽起来——这就是 CPTSD 的身体记忆。」
  （错在：把虚构的"手"直接等同于一个临床概念，观众记走的是一个不存在的机制）
- ⛔ 「有人在她体内拧了一个闹钟，医生说这叫皮质醇。」
  （错在：借"医生说"给虚构桥段背书，比不说更糟）
- ⭕ 画面段：她在六点睁眼，天没亮，闹钟还有一小时才响，她躺着不动，手指在被子上蜷了一下。
  解释段（下一条 beat）：「不是她想早醒。醒来前后那一阵，身体里的皮质醇本来就会往上冲一次——
  它管的是'起床'，不管你昨晚几点睡。」
  （对在：画面只呈现**现象**，机制由旁白单独说，且说法可查证、不越界）

### 1.4 "演绎创作"标注怎么落地（⚠️ 有一个会静默失效的坑）

**主位 · 全片常驻角标（推荐，复用既有通道零改代码）**：在 `shots.json` 的 `video` 对象里显式写
`"ai_label": "AI生成·情节演绎"`。`build_manifest.py` 尊重显式值（未给才用默认 `"AI 生成"`），
`compose_video.py` 把它 drawtext 到**右上角**（`fontsize = max(20, 高×0.03)`，右对齐自动避让）。
⚠️ **控制在 8 个字符内**——720×1280 下 8 字约占宽 42%，再长会压到画面；首片出来目视核一次。

**次位 · 收尾旁白一句人话**：最后一条 beat 的旁白末句带上，例：「故事是编的。这些反应是真的。」
——既是消歧也是记忆点，比生硬的免责声明有效。

⛔ **绝不要只把声明写进某条 beat 的 `subtitle`**：`compose_video.py` 的字幕优先级是
**`cues` > `narration_text` > `subtitle`**（已核实现，第 399–417 行）——只要该 beat 有旁白 + cues，
`subtitle` **完全不渲染**，声明会静默消失且没有任何告警。

## 二、从一句话种子到定稿内容

**顺序不可颠倒**：**先把"讲什么"钉死，再想"怎么编"。** 反过来做，必然为了故事好看去弯曲论据。

### 2.1 五种种子，各自的第一问

| 种子形态 | 例 | 第一问（先回答它再往下） |
|---|---|---|
| **科普点**（一个机制/现象） | 「皮质醇晨峰」 | 这个机制在**日常生活**里长什么样？观众在哪一刻会遇到它？ |
| **话题**（一个大词） | 「内耗」 | 它背后是**哪一个**可查证的机制？（内耗至少能拆成反刍思维、决策疲劳、自我批评三条，只取一条） |
| **新闻**（一个事件） | 「某地推行四天工作制」 | 事件本身不是论据。事件里**哪个心理学变量**被改变了？ |
| **观点**（一个主张） | 「休息不是奖励」 | 这句话的**可证伪版本**是什么？找到那句才有论据可查 |
| **标题**（一句钩子） | 「你以为的懒，其实是……」 | 省略号后面**到底**是什么？答不上来就是没内容，退回去要 |

### 2.2 种子扩写引导（当种子太模糊，用这五把钳子夹出具体处境）

原版的"选题路径"在这里的用法是**内部工具**——不展示给用户，直接产出方案：

- **从主题夹**：抽象命题 → 具体的不得不做的选择。「关于孤独」不是故事，
  「一个人发烧到 39 度，翻遍通讯录 200 个人，最后自己打车去医院」才是。
- **从人物夹**：矛盾性格本身就是冲突种子。「一个专门教别人沟通的培训师，回家和母亲一句话说不上」。
- **从空间夹**：空间即规则。问：这个空间里谁在上谁在下？什么是稀缺的？什么行为在这里被禁止？
  「工位」「合租房的客厅」「除夕的餐桌」「凌晨的便利店」各自带着一整套规则。
- **从关系夹**：两个人的 Want 互相矛盾且不可能同时实现。「她要他别再问了，他要她说点什么」。
  另一用法：**共调节设定**——自救类议题让第二个人零台词示范（先自己做，不劝不教），比完全
  独自自救更贴近真实求助路径，也天然给"找人陪伴/求助"留了行为出口（PK 中对手案的最佳设计，
  已获合规评委点名移植；代价=多一张角色卡+双人同框一致性成本，30-60s 档慎用）。
- **从碰撞夹**：给两个不相关的东西 → 直接进 §3-A 的五种组合法。

### 2.3 内容定稿卡（**三条内定稿**，写不满就是没查够，⛔ 不许带着空格进 §3）

```
【核心论据】一句话，可证伪，不含比喻：
  例：醒来后 30–45 分钟，皮质醇会出现一个日内高峰（cortisol awakening response）。

【出处】文献/教科书/权威机构 + 可定位信息：
  例：Clow et al., "The cortisol awakening response: more than a measure of HPA axis function",
      Neurosci Biobehav Rev 2010；WHO/教科书级共识可写"XX 教科书 第X章 共识"。

【边界条件】这条论据**不**成立或不适用的地方（这一行决定片子会不会被骂）：
  例：CAR 幅度个体差异大；与"早醒"不是一回事；不能用来判断任何人有没有病。

【深一环机制】（可选第 4 行）比核心论据再深一层的那个环节，供解释 beat 需要更准的因果时取用：
  例：过度换气的手麻不是"缺氧"也不只是"血偏碱"——碱中毒使钙与白蛋白结合增加、游离钙下降，
  神经才易放电（血清总钙可正常）。写口语版时降到能懂为止，⛔ 别为省事把机制降级成空话。
```

⚠️ **边界条件必须进片子，但优先进片尾合规卡（合成层静帧），不占叙事 beat**——首次 PK 实测：
把鉴别诊断+就医提醒排成结尾两个连续"松"beat，片子最后 1/5 变成告知书，评委原话「观众带走的
最后一口气是免责声明，不是画面」。叙事里最多留一句口语化的边界（如「这不代表你有病」），
清单式内容全推片尾卡。省掉边界条件，片子就从科普变成了暗示确诊。

⚠️ **危险民间做法必须主动辟谣，不许沉默回避**（同场 PK 合规评委裁定）：若该议题存在流传广的
错误自救法（如过度换气的「纸袋捂口鼻」），**片尾合规卡必须用否定句式点名辟谣**——沉默不等于
消解，观众会带着既有错误认知来看片。辟谣只进片尾卡，⛔ 不进旁白、不占叙事 beat、不演示错误动作。

### 2.4 查证不过关的三种处置（择一，⛔ 不许硬写）

1. **换说法**：论据太强 → 降级成"可能与……有关"，能过就继续。
2. **换角度**：这个点查不实，但同一话题下另有扎实的点 → 换那个点，故事重新想。
3. **退种子**：整条线都查不到可信来源 → 明确交回，说明"这个种子不适合做科普演绎"。
   这不是失败，是唯一正确的结果。

## 三、故事概念生成 · 两条路径

拿到定稿卡后，**两条路各出 1 个方案，然后选优**（§10 的 S3）。不要只走一条。

### 3.0 走哪条路（判据表）

| 定稿卡的论据长什么样 | 走哪条 | 为什么 |
|---|---|---|
| 是一条**机制/规律**，能推演后果（皮质醇晨峰、负强化维持回避、高警觉） | **What-If** | 机制本身就能翻译成"世界规则"，推演有柴烧 |
| 是一个**大家都体验过的现象**，缺的只是新角度（拖延、失眠、假期综合征） | **How-to-Tell** | 内容不新，卖的是形式 |
| 来自**新闻/热点** | **How-to-Tell** | 事件观众已知，硬做 What-If 会像蹭 |
| 是一条**反直觉的研究结论** | **What-If** | 结论本身就是一条可以取反的规则 |
| 是一个**观点/主张** | 先试着翻成规则；翻得动 → What-If，翻不动 → How-to-Tell | |

## Part A · What-If：假设一条反常识规则，展示它的后果

**本质**：用一条虚构规则，让观众看见现实中他们视而不见的东西。不是天马行空，是**放大镜**。

### A-1 概念嫁接

**方法**：取概念 A 的**运行机制** + 概念 B 的**应用场景** = 新规则。

- 信用分的扣分机制 + 情绪劳动 → 「每人身上挂一格社交电量，说一句客套话掉 1%，归零的人从此发不出声音」
  （指向：社交耗竭不是矫情，是有限资源被支取完）
- 游戏的强制读档 + 创伤记忆 → 「她的人生只有几个存档点，有人一用某种语气说话，她就被强制读回八岁那间厨房」
  （指向：闪回是旧记忆以现在时重演，不是"想起来了"）

⚠️ 嫁接来的机制必须**对得上论据的机制**，不能只是"听起来像"。存档点对得上闪回（非自愿、瞬间、身临其境），
但对不上"回忆往事"——差一点就错了。

### A-2 时空错置

**方法**：把一个人物 / 技术 / 制度放进它不属于的时代或场所。

- 现代 KPI 周报 + 幼儿园 → 「五岁的她每周要交一份表现汇报，红笔批注：情绪管理待改进」
  （指向：条件性关爱——爱与表现挂钩）
- 三甲医院的分诊台 + 自家客厅 → 「客厅中央支着一个分诊台，全家排队报告今天谁最难受，只有一号才能拿到关心」
  （指向：家庭里情绪资源的争夺与"谁更惨谁有理"）

力量在于：错位让观众**同时看到两个场景**，用一个的荒诞照出另一个的荒诞。

### A-3 隐喻具象化 ⚠️ **产物必须消歧（§1.3），无例外**

**方法**：抽象焦虑 A → 找到它在**行为层面的最小动作** → 把这个动作变成一条强制性的物理规则。

- 皮质醇晨峰 → 最小动作是"天没亮就睁眼" → 规则：「每天早晨六点，有一只看不见的手把她从床上拽起来，
  她再困也得站着——全城的人六点整都站在自家床边」
- 高警觉 → 最小动作是"盯着别人的脸找线索" → 规则：「每个人脸上悬着一格信号条。她能看见所有人的，
  代价是她自己那格永远显示满格」
- 情绪压抑 → 最小动作是"话到嘴边咽回去" → 规则：「咽回去的话会变成实体的小石子落进外套口袋，
  她走路一年比一年沉」

⚠️ 这三个例子**没有一个可以裸放**——每一个后面都必须跟一条解释 beat 把机制说清楚（写法见 §1.3 对错例句）。

### A-4 反转并置

**方法**：找两个**表面相似、本质对立**的事物，让它们在同一场景共存，不用一句台词点破。

- 「照顾别人」vs「照顾自己」→ 她给全组人点好了热饮，自己那杯凉在工位上一整天没动
- 「休息」vs「待机」→ 她躺在床上八小时，屏幕亮了四十次，没有一次是她想看

### A-5 规则反转

**方法**：取一条人们习以为常的规则，翻过来，推演后果。

- 「情绪会随时间平复」→ 反转：「情绪不会平复，但可以转账给别人——于是所有人的坏情绪最后都堆在
  最不会拒绝的那个人身上」
- 「求助会得到帮助」→ 反转：「每说一次'我不太好'，身边的人就后退一步」

### A-6 概念组合检验（六条全过才进结构，缺一条回炉）

- [ ] 1+1>2？组合后不比单个概念更有意思 → 放弃组合，回到单一概念
- [ ] 观众 **5 秒内**能理解这条规则吗？（讲不清 = 换概念，不是加解释）
- [ ] 组合是否指向定稿卡里的**那条论据**，而不是滑到旁边的话题去了？
- [ ] 有推演空间吗？至少能长出 **3 个递进的后果切片**
- [ ] 有翻转潜力吗？最后一格能不能反过来打观众一下？
- [ ] **消歧成本可控吗？** 如果需要三条 beat 才能解释清楚"这是比喻"，这个概念对 30s 片子就太贵了

## Part B · How-to-Tell：内容不变，彻底换一种讲法

**本质**：观众已经知道内容，所以内容不是卖点，**形式**才是。形式即内容。

### B-1 视角置换

用一个不可能的视角讲述。

- 从她房间那盏三年没关过的夜灯的视角，讲一个人的睡眠
- 从一条"已读不回"的消息的视角，讲一次社交回避
- 从体检报告上那行"窦性心动过速"的视角，讲一整年的焦虑

⭕ 产线红利：视角置换天然**不出人物正脸**，跨段人物一致性问题直接消失（见 §9-4）。

### B-2 形式模拟

借一种已有的格式重新包装。

- 用**新员工入职手册**的格式讲讨好型人格（岗位职责：让所有人都满意；试用期：终身）
- 用**搜索框自动补全**讲一个人从怀疑到求助（"是不是我太敏感" → "长期紧绷 会不会有问题" →
  "宁波 心理咨询 怎么选"）
- 用**家电说明书**讲身体的应激反应（本机出厂设定：遇险自动进入高功率模式；已知问题：无法手动关闭）

⚠️ **⛔ 别用药品说明书 / 病历 / 诊断书格式**——形式本身就在暗示确诊与用药，踩合规红线。
⚠️ 界面/文字类形式在我们的产线有**图内 no-text 铁律**卡着（§9-17），落地方式见那一节。

### B-3 时间手术

对时间动刀——加速、拉长、倒放、循环、并置。

- **同一个厨房的二十年**，机位不动：八岁的她站在门口，十八岁的她背着包，二十八岁的她回来吃饭
- 把**"被批评后的三秒"拉成九十秒**：耳朵先热、手指先动、话在喉咙口停住、然后她笑了一下说"好的"
- **正放她的白天 + 倒放她的深夜**，两条线在傍晚交汇

### B-4 尺度跳跃

在极大与极小之间跳。

- 从一根竖起来的汗毛 → 拉远到整个开放式办公室 → 拉远到整座城市的夜灯 → 切回那根汗毛
- 从她攥紧的手指 → 切到整条街的人都在攥手指 → 切回她自己那只手松开

### B-5 规则限制

给叙事本身加一条限制，创意由限制逼出来。

- 全片只有一个固定机位，对着同一张餐桌
- 全片没有一张正脸——只有背影、手、和物件
- 全片只有一句台词，落在最后一秒
- 全片只有她一个人，其他人只以声音和影子存在

⭕ 产线红利：B-5 的每一条都**同时省积分、提一致性**——固定机位省运镜抽卡，无正脸免角色卡。

### B-6 形式检验（五条）

- [ ] 形式与内容**深度契合**吗？（判据不是"看起来酷"，是"只能这么讲"）
- [ ] 形式有**递进空间**吗？一个手法从头用到尾不变化 = 观众第 20 秒就腻了
- [ ] 形式本身能**完成翻转**吗？（最好的 How-to-Tell，翻转由形式给出，不由台词给出）
- [ ] 观众 15 秒内能理解这个形式吗？
- [ ] **去掉形式**用常规方式讲，内容会不会照样成立？会 → 换形式

## 四、结构模板（五种 + 30–60s 压缩变体）

每个模板给三样：标准时间轴、30–60s 压缩变体、**适用什么论据形态**。
segment 映射沿用 `cinematic-direction.md` §5（60s=3 段 / 90s=4 段 / 3min=6–7 段；
**≤30s 可以 1 段直出**——即梦单次上限就是 30s，单段内人物一致性最好、最省积分，短片优先这么干）。

### 结构 A · 三段式（概念呈现 → 推演 → 翻转）

**适用论据形态**：一条能推演出多个后果的机制（负强化、条件性关爱、习得性无助）。最通用。

```
标准（60–90s）                          压缩（30–45s）
① 概念呈现 15–25s｜1 段                 ① 5–8s：一个动作直接呈现规则，零铺垫
   一个画面/动作让人 5 秒内懂规则         ② 15–25s：只留 2 个后果切片
② 推演 30–50s｜1–2 段                   ③ 8–12s：翻转 + 消歧一句
   3–5 个后果切片，每片 5–15s，
   必须递进（更极端 / 更荒诞 / 更日常）
③ 翻转 15–25s｜1 段
   一格画面或一句话颠覆前面的认知
```

⚠️ 推演段是观众"入戏"的过程，**⛔ 不能跳过直接翻转**；压缩变体里也至少留 2 片。

### 结构 B · 递进崩塌

**适用论据形态**：会**逐级升级**的机制（回避行为的负强化循环、耐受性、requirement 不断加码的完美主义）。

```
标准（90s–3min）                        压缩（45–60s）
① 规则建立 ~20s：看起来还挺合理         ① 10s：规则建立
② 第一次升级 ~20s：更离谱，但人适应了   ② 15s：升一级，人适应
③ 第二次升级 ~20s：荒诞了，人还在适应   ③ 20s：升到荒诞，人还在适应
④ 崩溃点 ~20s：系统崩塌——              ④ 10s：崩塌 + 余像
   或者所有人已完全适应，崩塌的是观众认知
⑤ 余像 ~10s：废墟里的日常
```

⭕ 「崩塌的不是规则、是观众的认知」这个变体在心理科普里最好用——因为现实里那些机制**确实没崩**。

### 结构 C · 双线并置

**适用论据形态**：需要**对比**才成立的论据（同一行为在两种关系里的不同后果、"看起来一样其实相反"）。
天然搭配 §3-A-4 反转并置。

```
两条线视觉平行推进（画面内前景/背景 或 交叉剪辑；⛔ 分屏在我们的产线做不了，见 §9-7）。
某一刻观众突然意识到：A 的美好建立在 B 的代价上，或 A 与 B 本是一件事的两面。
这个"意识到"就是翻转，⛔ 不要让角色说出来。
压缩（40–60s）：每条线各 2 个切片，交汇点放最后 10s。
```

### 结构 D · 循环 / Loop

**适用论据形态**：**无法自行退出**的循环（反刍思维、回避—焦虑—更回避、代际传递）。

```
起点（状态 A）→ 发展 → 看似解决 → 回到状态 A。
关键在第二次看到 A 时观众的理解已经变了：
  第一次 = 一个正常的早晨；第二次 = 一个逃不出去的牢笼。
可以在第二次循环刚开始时切黑，让观众自己反应过来"又来了"。
压缩（30–45s）：整圈只留 4 格——起点 / 发展 / 假解决 / 回到起点，每格 8–10s。
```

⚠️ **视觉指认是循环结构的承重墙**（首次 PK 制作评委点名）：第二次出现的 A **必须与第一次
同景别、同机位、同运镜复现构图，只改动作幅度/细节**——尤其在插画风+不出正脸的约束下，
两次"大口吸气"若构图不同，观众认不出这是同一个动作，循环就退化成重复。⛔ 靠旁白说
「又是这样」来指认 = 循环失效。

⚠️ 循环结构最容易被观众记成"所以没救了"。**收尾的解释 beat 必须给出退出条件**
（"循环能被打断的地方，通常不在'别想了'，在……"），否则片子在传播绝望。

### 结构 E · 倒叙揭示

**适用论据形态**：**真相一直在眼前但没人看见**的论据（躯体化、创伤的行为后遗、"症状其实是保护"）。

```
先给结果——一个奇怪的、不可理解的画面。
然后一步步倒推原因，每揭示一步画面就更合理，也更让人难受。
最后一步揭示完，回头再看第一个画面，含义完全变了。
压缩（40–60s）：结果 1 格（8s）+ 倒推 3 格（各 10s）+ 回望 1 格（8s）。
```

⭕ 与 `cinematic-direction.md` 的「拉近/拉远转场（瞳孔里展开回忆）」「叠化回忆闪回」天生一对。

## 五、写作红线与视听化写作

### 5.1 红线全量（**违反任何一条即自检 FAIL，重写**）

| # | ⛔ 禁止 | 心理科普里的典型错法 | ⭕ 正确写法 |
|---|---|---|---|
| 1 | **心理描写** | 「她意识到自己一直在讨好别人。」 | 她把想说的话咽下去，笑了一下，说"都行，你定"。然后在桌下把袖口拧成一团。 |
| 2 | **括号暗示** | 「'我没事。'（其实她已经三天没睡好了）」 | 「我没事。」她低头去够杯子，杯子是空的，她还是举起来喝了一口。 |
| 3 | **角色解释设定/术语** | 「你这是典型的高警觉状态，是杏仁核过度激活。」 | 同事只是把文件放下，她的肩已经先缩了一下。 |
| 4 | **说教 / 强行催泪 / 煽情独白** | 「请一定要好好爱自己啊，你值得被温柔以待。」 | 她把凉掉的那杯茶倒了，重新烧了一壶。 |
| 5 | **AI 腔 / 过度比喻 / 书面语** | 「她的内心仿佛一座正在崩塌的孤岛。」 | ⛔ 整句删掉。要么给动作，要么什么都别写。 |
| 6 | **拍不出来的内容** | 「三年来她始终没能真正原谅母亲。」 | 母亲打来电话，她看着屏幕响完，然后回了一条"在忙"。 |
| 7 | **术语当台词说**（本仓特有） | 「我可能有 CPTSD。」 | 术语只能出现在**解释 beat 的旁白**里，⛔ 绝不进角色的嘴 |

第 7 条是心理科普独有的：角色一开口说诊断名，片子立刻从"故事"变成"暗示确诊"，同时踩 §1.3 红线。

### 5.2 必须做到

- **台词口语化**，像真人说话。判据：配音员念出来别扭 = 重写（同 `narration-spec.md` 第三律）。
- **用动作代替解释**。检验：**把所有台词删掉，观众还能不能大致看懂发生了什么？**能 → 及格。
- **对话像冰山**，只露一角。
  - 直白（⛔）：「我很害怕你也离开我。」
  - 潜台词（⭕）：「你走的时候把那件外套带上。……外面冷。」
  - 心理科普场景（⭕）：母亲问"最近怎么样"，她说"挺好的，就是有点忙"，然后开始收拾本来就很整齐的桌子。
- **动作即潜台词**。全片最值钱的一格是**可见的抑制动作**——把冲动压住的那个小动作
  （攥紧、话到嘴边抿住、别开眼、把手从桌上收回去）。这条与 `cinematic-direction.md` §一的
  "六个必填"第 5 条是同一条，**每个 beat 至少有一个**。
- **旁白与画面分工：画面能演的，旁白不许再说一遍**（首次 PK 最大失分点，评委原话
  「看得见的事再说一遍，观众的发现被剥夺」「句句在说明画面＝带插画的解说，不是戏」）。
  旁白只说画面外的三样：**前史**（她刚才在里面说了三句话）、**机理**（解释 beat 内）、
  **反差**（画面与事实的冲突：画面是蜷紧的手，旁白是「氧气是满的」）。
  检验：逐句问「这句删了，画面是否已经交代了？」是 → 删。
- **解释段不整段停戏**：机理解释拆进动作间隙，单次 ≤2 句；⛔ 超过 5 秒纯解释+空镜卡在
  情绪上升位（首次 PK：11 秒解释段让故事在中段熄火一次）。

### 5.3 Show, Don't Tell 的科普版特例（⚠️ 唯一的豁免）

**论据层允许直说。** Show-Don't-Tell 管的是**故事层**——机制解释本来就该讲清楚，
硬要"用画面表达皮质醇曲线"只会两头不讨好。

规则：**故事段全 Show，解释段直接 Tell，两者分在不同 beat**（这也是 §1.3 的结构隔离）。
解释段的画面配空镜/物件/隐喻，⛔ 不要在解释的同时演剧情——观众听不进两件事。

### 5.4 语言精度四检（🩸 一票否决，与双层合规同级；老板亲抓的真实事故）

**适用范围＝交付物里的每一句话**：logline、概念说明、选型表、结构表、剧本、旁白、字幕——
⛔「工作文档层不算正文」是本节存在的原因：首单 PK 两句事故全部出自概念选型表，
写作红线只查了剧本正文，垃圾句原样进了交付物被老板一眼抓出。

1. **字面成立性**：把句子**按字面**读一遍，字面荒谬且不是刻意超现实设定 → 重写。
   最常见病灶＝**借代省略中心语**：
   - ⛔ 「每一口用力吸进去的气，都会从身上拿走一点东西：先是指尖，再是嘴唇」
     （真实事故。被拿走的是指尖的**知觉**，省掉中心语后字面＝器官被摘走——"指尖断掉了？"）
   - ⭕ 「越用力吸，麻得越快：先是指尖，然后嘴唇，最后连站都站不稳」
2. **禁术语截断**：专业词必须完整出现，⛔ 砍成会歧义的短形式。
   - ⛔ 「讲一场三分钟的急」（真实事故。"急性发作"截成"急"，读者第一反应是尿急/着急）
   - ⭕ 「从她那只右手开始，看完一次急性发作的三分钟」
3. **禁伪文学腔**：句式像文学、语义不成立——比 AI 腔更隐蔽，因为它"看起来写得很用力"。
   判据：这句话如果出现在正经出版物里，编辑会不会打回？拿不准就换成大白话——
   **语义准确的大白话永远好过语义破损的"文学"**。
4. **朗读检验**：出声念一遍（或逐句默读），任何一句让你顿一下、回读一次的 → 重写。
   读者不会回读，他们只会划走＋记住"这号写东西不通"。

**为什么单列一节而不是并进红线清单**：打勾式清单拦不住这类错——每一条都能"技术上通过"
（无心理描写✓无说教✓），但句子本身不成立。四检的动作不是打勾，是**逐句重读**。

## 六、开场钩子（竖屏短视频版）

**⚠️ 前 3 秒军规以 `cinematic-direction.md` §二之二为准**，这里只补编剧层怎么写：

- **第 1 秒必须已经在发生**：写"她已经垮在门上"，⛔ 不写"她走向门"。
- **⛔ 开场禁用**：淡入、空镜起手、logo、任何铺垫。铺垫是完播率杀手。
  电影可以慢热，**竖屏的"慢"只能放在第 10 秒之后**。
- **钩子句前 3 个字压住话题**：「这些应激——」「六点睁眼——」「她笑着说好的——」。
- **最有效的短片开场是一个"不太对"的日常画面**：看起来完全正常，但某个细节让人起疑
  （她在给全组人点热饮，自己那杯还是昨天那杯）。
- **概念片的开场即概念**：前 5 秒让观众理解规则，或至少产生强烈好奇。

### 开场钩子自检（写完结构大纲和剧本各过一次）

- [ ] 第一格画面本身有冲击力或悬念感吗？（不是"交代背景"）
- [ ] 观众在前 **3 秒**会不会产生一个**具体**的疑问（"她为什么……？"）？
- [ ] 钩子是**悬念式**还是**共情式**？——「命名观众已知的体感」（"吸不上气时人会拼命吸"）
  只是共情，**没有制造问题**；悬念式钩子给的是一个画面回答不了的谜（"这是谁的视角？"
  "第三句为什么没说完？"）。共情式最多做第二拍，第一拍必须是悬念（首次 PK 失分点）。
- [ ] 开场是在**交代状态的同时制造张力**，还是"先交代再开始"？后者 = 重写
- [ ] 把开场单独拿出来，它本身是不是一段值得看的内容？
- [ ] 钩子和收尾是**同一个论据**吗？（钩子挖的坑，收尾必须填）

## 七、双轨节奏（外部情节 × 内在情感）

节奏有**两条**轨道，同步很普通，**错位才高级**。

- **外部情节轨**（事件密度）：紧 = 事情接连发生、切片密集、冲突外显；松 = 日常、独处、空镜、过渡。
- **内在情感轨**（情感投入量）：重 = 失去、恐惧、被戳穿、和解；轻 = 闲聊、小幽默、安静的陪伴。

**四种组合与用法**：

| 组合 | 效果 | 心理科普里放哪 |
|---|---|---|
| 情节松 + **情感重** | 最有味道的一档 | **收尾段首选**：她安静地重新烧一壶水，什么都没发生，但观众知道什么变了 |
| 情节紧 + 情感轻 | 张力被轻盈包裹 | 推演段的快切列举（应激场景清单式） |
| 情节紧 + 情感重 | 全片顶点 | 翻转/崩塌点，⛔ 不能持续超过 15s |
| 情节松 + 情感轻 | 纯呼吸 | 高潮前后各一格空镜，3min 片必备 |

**判断方法**（逐 beat 标两个字，一眼看出问题）：给每个 beat 标 `松/中/紧` + `轻/中/重`，然后查三条：

- [ ] 有没有**连续 3 个 beat 完全同状态**？有 → 必调（观众会麻木或走神）
- [ ] 两条线是不是**全程同步**？全程同步 = 平庸，**至少制造一处错位**
- [ ] 两条线有没有**长时间同时处在低位**（观众无事可看也无感可投）或**同时高位**（疲劳，高潮不再特别）？

## 八、时长与节奏量化

### 8.1 基础公式

**中文旁白约 250 字 ≈ 1 分钟成片。**
（原版编剧方法论给的是 200–250；**我们首片实测 259 字/分钟**——362 字 / 84.0s，
MiniMax「温暖闺蜜」默认语速。按 **240–260** 规划最准。）

⚠️ **换音色/改语速这个数就变**（豆包同语速比 MiniMax 慢约 7%，见 `narration-spec.md` §三）——
换了就重新校一次，别沿用旧配额。

⚠️ **这个数字只用来决定"写多少字"，⛔ 绝不写进 `shots.json` 的 `gen` / `duration`。**
产线是**旁白驱动**：每段生成时长由 `sync_durations.py` 按 ffprobe 实测写回，
**手填是画面被异常放慢的头号事故源**（`cinematic-direction.md` §2.3）。

### 8.2 分档预算表（编剧阶段照这个配额写）

| 片长 | segment 数 | 旁白规划字数 | beat 数 | 分镜数（官方密度 4–5 镜/段） |
|---|---|---|---|---|
| **≤30s** | **1**（单段直出，一致性最好、最省积分） | 110–130 | 3–4 | 4–5 |
| **60s** | 2–3 | 230–260 | 6–8 | 9–14 |
| **90s** | 3–4 | 350–390 | 9–11 | 14–18 |
| **3min** | 6–7 | 700–780 | 18–22 | 28–35 |

**每条 beat 约 9s / 40 字**——首片实测舒适区（9 beats / 3 段 / 84.0s / 362 字，每段整齐 5 镜）。
⛔ 别超官方分镜密度：镜头再多，每镜分到的描述精度就撑不住了。

### 8.3 分段内容配比（承 `cinematic-direction.md` §5 骨架）

```
60s   钩子 10s ｜ 展开 35s ｜ 收束+合规 15s
90s   钩子    ｜ 展开 A ｜ 展开 B ｜ 收束
3min  钩子 ｜ 展开 ×3（各一个分论点）｜ 转折 ｜ 收束 ｜ 尾声
```

**越长越要给呼吸**：3min 片每段结尾留一个 2–3s 空镜，否则观众会累。

### 8.4 节奏诊断（剧本写完逐条问）

- [ ] 翻转/崩塌段的时长够吗？（太短 = 高潮被压扁，观众来不及反应）
- [ ] 概念呈现段是不是超过全片 30%？（观众等太久才进正题）
- [ ] 有没有连续超过 **20 秒**的单一情绪段落？（无论紧还是松，持续太久都会失效）
- [ ] 两个情感重段之间有呼吸空间吗？
- [ ] 全片最长的一条 beat，凭什么占那么多秒？答不上来就砍
- [ ] 旁白字数是否落在 §8.2 的配额里？超 15% → 砍内容，⛔ 别靠加快语速解决

## 九、视听语言武器库 → Seedance 提示词映射

**用法三条**（沿用原版，仍然成立）：① 形式服务内容，不是"我想用某手法"再找内容配；
② **一条片子只聚焦 1–2 种核心手法**，用到极致（塞五种 = 炫技集锦不是片子）；
③ 手法必须**递进**（升级 / 变异 / 在结尾被打破），⛔ 一种手法从头用到尾不变化。

下表第三列是**写进分镜五行时的词汇提示**，用词与 `cinematic-direction.md` 对齐
（官方运镜词表：推 / 拉 / 摇 / 移 / 跟 / 环绕 / 升降 / 希区柯克变焦；九种转场词表见该文件 §三之三）。

### 镜头语言类

| # | 手法 | 效果 / 适用 | Seedance 落地词汇（写在哪一行） |
|---|---|---|---|
| 1 | **一镜到底** | 真实感、时间不可逆；适合"跟她一起熬过这段时间" | 运镜手法行：`单镜头一镜到底，全程不切镜`；全局补充加 `禁止生硬切镜、禁止跳切`。⚠️ 段内不切镜 = 一次生成只出一镜，官方密度用不满，**只在 ≤10s 的关键段用** |
| 2 | **固定机位时间流逝** | 变与不变的对比；适合"同一个厨房的二十年" | 运镜手法行：`固定机位，摄影机全程不动`；画面内容行写清同一构图内**先后变化的三样东西**。⚠️ 单段内跨大时间跨度会漂，稳妥做法是拆两镜、用**相似物转场**串 |
| 3 | **连续推轨 / Dolly** | 空间揭示——随镜头移动不断发现新信息 | 运镜手法行用官方词 `移` 或 `推`，**必须写起点与终点**：`从桌上凉掉的茶缓慢推到窗外的天光` |
| 4 | **第一人称 POV** | 极端代入 + 信息受限；B-1 视角置换的主力 | 画面内容行：`主观视角，画面即她所见，画面内不出现她的脸`。⭕ **省参考图**：不出正脸 = 跨段人物一致性问题消失 |
| 5 | **微距 / 显微** | 熟悉变陌生；B-4 尺度跳跃的一端 | 景别行用官方原词 `极端微距特写`；画面内容行给**具体材质**：`毛衣袖口起球的线圈`、`杯壁一道旧茶渍` |

### 剪辑 / 时间类

| # | 手法 | 效果 / 适用 | Seedance 落地词汇 |
|---|---|---|---|
| 6 | **跳切蒙太奇** | 时间压缩、"日复一日"的荒诞 | 同一机位同一构图连写 3 个时间戳，画面内容只换姿态/衣服/状态；转场写 `硬切`。⚠️ **必须在同一 segment 内**——跨段人物会漂 |
| 7 | **分屏** | 对比并置 | ⛔ **生成侧做不了**（实测不稳定、易出鬼畜）。替代：改用 #12 画面内前景/背景叙事；真要分屏走 ffmpeg 后期 |
| 8 | **交叉剪辑** | 两条线的关系在切换中被暗示 | 段内两组时间戳交替 + 转场用 `自然镜头切换`。⚠️ 两组场景同段内会互相污染，**稳妥做法是两段各拍一条，剪辑层交替** |
| 9 | **倒放** | 结果先于原因；B-3 时间手术 | ⛔ prompt 层不可靠。ffmpeg 后期 `-vf reverse` 做 |
| 10 | **定格 / 时间冻结** | 强制注意某个细节，制造标点感 | ⛔ 生成层做不出干净定格。ffmpeg 抽帧 + `tpad` 延展。⚠️ 抽帧前**必须逐帧验尾**（0.4s 步进抽 3–5 帧）——Seedance 常在段尾自带白化淡出，取到白帧就是几秒空屏（见 `cinematic-direction.md` §八已知坑） |

### 画面构成类

| # | 手法 | 效果 / 适用 | Seedance 落地词汇 |
|---|---|---|---|
| 11 | **对称构图** | 秩序感、仪式感、过于完美带来的压迫感；适合展示制度化的规则 | 构图行：`严格左右对称，主体居中，两侧等量` |
| 12 | **画面内前景 / 背景叙事** | 不用剪辑的并置——同一画面两层信息；**结构 C 双线并置在我们产线的正解** | 构图行写清两层：`前景是她低头吃饭占画面下三分之一；背景景深里父母在争执，只见身形不见脸` |
| 13 | **色彩限制** | 颜色本身成为叙事元素 | 全局设定的「风格」行写死色板（我们本就三色板：雾霾蓝灰 / 暖米白 / 鼠尾草绿）。**变的是配比与光**——色彩弧线怎么排见 `cinematic-direction.md` §一之二 |

### 声音类

| # | 手法 | 效果 / 适用 | 我们的落地位置 |
|---|---|---|---|
| 14 | **画面与声音错位** | 两层信息碰撞，讽刺最强 | ⛔ 不在生成侧做（【声音】段只写环境音）。**在编剧层设计**：画面是她照常上班，旁白讲的是她夜里三点醒着 |
| 15 | **环境音放大** | 日常变得不安（键盘声、吞咽声、呼吸声） | prompt【声音】行写具体音源。⚠️ 生成片音轨被 `cut_assemble.py` 的 `-an` 丢弃——真要用得改那一处并在 compose 层做响度平衡 |
| 16 | **静默** | 最贵的音效；高密度之后突然安静 = 高潮 | 编剧层：全片最重的一句话前，BGM 与环境音收掉 0.5–1s。⚠️ **产线待办**：无旁白的静默 beat 结构上尚不支持（`cinematic-direction.md` §八之二），目前只能靠 BGM 收空实现 |

### 界面 / 媒介类

| # | 手法 | 效果 / 适用 | 我们的落地位置 |
|---|---|---|---|
| 17 | **屏幕录制** | 极致当代感；B-2 形式模拟的主力 | ⛔ **被图内 no-text 铁律直接封死**（屏幕上必有字，Seedance 渲 CJK 必乱码）。替代路径两条：① 文字全走 ffmpeg 字幕，画面只给"手指在屏幕上滑动"的特写；② 整条改做**字卡短片**形态（`card-video-spec.md`），那条产线本来就是文字驱动 |
| 18 | **伪纪录片** | 用"正经"的壳反衬荒诞 | 画面内容行：`手持轻微晃动，被摄者正对镜头`。⚠️ 我们是插画风，伪纪录片的"真实感"会和画风打架，**慎用** |
| 19 | **数据可视化** | 冷静的数字反衬巨大的人的处境 | ⛔ 图内 no-text 封死。数字一律走**字幕**承载，画面只做情绪烘托（这是写意治愈风的固有取舍） |

⚠️ **选手法前先看这一列**：19 种里有 5 种（#7 #9 #10 #17 #19）在我们的产线**生成侧做不到**。
在概念阶段就避开它们，比写完剧本再发现拍不了便宜得多。

## 十、自动化工作流（**全程无人工确认卡点**）

原版每步等用户回复"通过"的对话纪律**已全部删除**。本产线的规则是：
**内部自检硬闸一次过，不过就重写，最多 2 轮**。人工闸门只有一处，在产线尾部（§10.5）。

### 10.1 七步

```
S1 种子受理     → 判定种子形态（§2.1），提出那一个"第一问"并自答
S2 论据查证定稿 → 填满内容定稿卡三条（§2.3）；填不满走 §2.4 三种处置
S3 概念生成     → What-If 与 How-to-Tell **各出 1 案**（§3），按 §3.0 判据 + A-6/B-6 检验选优
S4 结构选型     → 按论据形态选 A–E（§4），定片长档位与 segment 数（§8.2）
S5 剧本         → 按 §5 写作红线写全片；旁白稿另走 narration-spec.md 的六律与三轮审校。
                  ⚠️ 写作时把 §5 当唯一焦点——流程表格、字段契约此刻全部放下，一句一句写；
                  写完先过 §5.4 语言精度四检再进 S6（语言是这一步的全部，不是顺带）
S5.5 外置语言审校 → **独立文字编辑 agent** 逐句审全部文本（契约见 §10.7），批注回来逐条改，
                  复检到「能直接见老板」为止（≤2 轮）。⛔ 生产者的 §5.4 自检只是预清洁，
                  **不是闸门**——2026-08-12 实测：自检四勾全打、实际只念了旁白，正文 23 处
                  字面不成立原样漏过。语言闸门只认外置编辑的复检结论
S6 内部自检硬闸 → §10.3 逐条过，FAIL 即重写，≤2 轮
S7 输出物       → §10.4 两份产物，交产线第 2 步
```

### 10.2 S3 选优判据（两案二选一时按顺序问）

1. 哪一案的概念**更贴定稿卡那条论据**（不是更贴话题）？
2. 哪一案的**消歧成本更低**？（需要三条 beat 解释的，在 30s 片里直接淘汰）
3. 哪一案在 §9 里用到的手法**生成侧做得出来**？
4. 都还行 → 选**能在 5 秒内讲清规则**的那个。

### 10.3 内部自检硬闸（**逐条打勾，任一 FAIL 即回 S5 重写；2 轮仍不过走 10.6**）

**A 双层合规（一票否决）**
- [ ] 每一句论据层陈述都能对上定稿卡的出处，无一句是为了故事顺手加的
- [ ] 无编造数据、无虚构研究/机构、无"研究表明"式空引
- [ ] 论据句式单向（`常见于` 而非 `就是`），无暗示确诊句式
- [ ] 定稿卡的**边界条件**已进片子（通常在收尾解释 beat）
- [ ] 虚构人物无任何真实来访者信息可溯源（判据：当事人能否认出自己）
- [ ] 每个隐喻具象化产物后面都有消歧（§1.3），且 `video.ai_label` 已写 `AI生成·情节演绎`（§1.4）
- [ ] "演绎创作"声明**不是只写在 `subtitle` 里**（有 cues 会静默不渲染）

**B 写作红线（§5.1 七条）**
- [ ] 无心理描写 / 无括号暗示 / 无角色解释设定 / 无说教煽情 / 无 AI 腔 / 无不可拍内容 / 术语未进角色的嘴
- [ ] 把所有台词删掉，故事仍大致看得懂
- [ ] 每个 beat 至少有一个**可见的抑制动作**

**C 结构与钩子**
- [ ] 第 1 秒已经在发生；⛔ 无淡入/空镜起手/铺垫
- [ ] 前 3 秒能让观众产生一个具体疑问
- [ ] 推演/发展段是**递进**而非同一状态的重复
- [ ] 翻转是概念自身逻辑的延伸，不是硬转
- [ ] **翻转不由台词点破（可证伪检验）**：把翻转 beat 的旁白第一句删掉，翻转是否仍然成立？
      不成立 = 翻转其实是被旁白点破的，重写画面（首次 PK：自称"翻转由概念给出"实际是
      「就是这一口」台词点破，被评委抓包——自评不可信，必须做删句检验）
- [ ] **自我承诺逐条核真**：剧本/概念说明里声称的每个形式设计（"限制在结尾被打破""构图呼应"），
      对照分镜表逐条核对确实写进去了——声称了没做到，比不声称更减分
- [ ] 钩子挖的坑，收尾填上了（同一条论据）

**D 时长核算**
- [ ] 旁白总字数落在 §8.2 档位配额内（超 15% 砍内容，⛔ 不靠语速）
- [ ] beat 数、segment 数、分镜数三者对得上，未超官方密度（4–5 镜/段）
- [ ] 每段旁白总和 ≤ 30s（seedance2.5 单次生成上限；超了 `sync_durations.py` 报 overflow 退回，
      提示"把 beat 挪到别的段，或压旁白"）。⚠️ 该脚本 `--max` **默认是 15**——v3 分段跑第 4 步
      必须显式 `--max 30`，否则 20 多秒的正常段会被误判成 overflow
- [ ] 双轨节奏无连续 3 beat 同状态，且至少一处错位（§7）

**E 可拍性（拦在写剧本时，比拦在花积分后便宜 400 分）**
- [ ] 选用的视听手法在 §9 里**不是 ⛔ 那五种**
- [ ] 每镜过一遍**物理一致性**六类（接触受力/光源/重力/因果/同场景常识/状态延续，见 `cinematic-direction.md` §2.3）
- [ ] 画面中不需要出现任何文字（no-text 铁律）
- [ ] 跨段出现的人物已规划参考图（2–3 张独立单视图），或整片走"不出正脸"策略
- [ ] 无写实真人脸诉求（平台会拦）

**F 语言精度（一票否决；判据＝S5.5 外置编辑的复检结论，⛔ 不认生产者自打的勾）**
- [ ] 已跑 S5.5 外置语言审校，「不通」级批注全部改完
- [ ] 编辑复检结论原文＝「能直接见老板」（把结论原句抄在这里，写不出原句＝没跑）
- [ ] 编辑顺带标注的「连带事故」（术语错误/矛盾指令）已处理

### 10.4 输出物契约（**字段对齐产线第 2 步的 `shots.json`**）

**产物一：`script.md`**（人读的剧本，放 `<workdir>/`）——含内容定稿卡、选定概念与结构、
全片分段剧本（标准剧本格式：`【场景X：地点 / 时间 / 视觉描述】` + 动作描写 + 台词）、
双轨节奏标注。⚠️ **script.md 从标题到附表的每一句话都过 §5.4 语言精度四检**——
它是给人读的交付物，工作表格里的病句和正文里的病句一样丢人。
⛔ **script.md 里不许出现逐条打勾的自检文本**——生产者勾选已连续四轮被复检验伪，
被验伪的自检比错误本身更失分。只写三行内《状态声明》：「本稿语言与一致性状态以
外置编辑复检结论为准（结论原句：___）；修改台账见文末。」§10.3 清单是你写作时的
**工作纪律**，不是交付物里的表演。

**产物二：`shots.json` 骨架**（v3 电影格式，`format_version: 3`）。**本环节填哪些、留哪些**：

| 字段 | 本环节填？ | 说明 |
|---|---|---|
| `video.title` | ✅ | 片名 |
| `video.ratio` | ✅ | 固定 `"9:16"` |
| `video.ai_label` | ✅ | **`"AI生成·情节演绎"`**（§1.4；⛔ 别留空、别用默认） |
| `video.format_version` | ✅ | `3` |
| `video.source_note` / `source_text` | ✅ | 种子来源 + 定稿卡出处，供终审回溯 |
| `video.style_profile` / `method` | ✅ | 风格档案 + 方法论版本 |
| `beats[].index` | ✅ | 1 起，两位序号对应 `narr-NN.mp3` |
| `beats[].narration_text` | ✅ | 口语化旁白（定稿前走 `narration-spec.md` 审校） |
| `beats[].subtitle` | ✅ | 兜底字幕；⚠️ 有 cues 时不渲染，**别把关键声明只放这里** |
| `segments[].index` / `beats[]` | ✅ | 分段与 beat 归属（决定切段边界） |
| `segments[].cut_count` | ✅ | 该段分镜数，4–5 |
| `segments[].prompt` | ✅ | 按 `cinematic-direction.md` 的官方三模块 + 分镜五行写 |
| `segments[].operation` / `model` / `ratio` | ✅ | 通常 `multimodal2video` / `seedance2.5` / `9:16` |
| `segments[].needs_images` | ✅ | 该段需要哪几张参考图及用途（第 2.5 步收图的依据） |
| `segments[].gen` / `narr_total` | ⛔ **留空** | 第 4 步 `sync_durations.py` 按 ffprobe 实测写回，**手填即事故** |
| `segments[].images` | ⛔ **留空** | 第 2.5 步收图后由 `--attach-images` 写回 |

### 10.7 外置语言审校契约（S5.5，2026-08-12 实测有效的编辑提示词范式）

**为什么外置**：生产者自检语言恒不可信——它想交差，且刚写完的句子在它眼里都是通的。
实测同一份稿：生产者自检 4/4 全绿，外置编辑抓出 23 处「不通」+38 处「别扭」。
编辑还能顺带抓到语言之外的**连带事故**（术语自相矛盾、"同构图+拉远"式互斥指令）。

**编辑 agent 提示词骨架**（照此派活，独立 agent，⛔ 不给它看本规格以外的创作上下文）：

> 你是一名以吹毛求疵著称的中文文字编辑。逐句审读这份交付物的**全部文本**（包括标题、
> 表格单元格、logline、概念说明，不只是剧本正文），只查语言，不评创意：
> ①字面成立性（尤其借代省略中心语，如「拿走一点东西：先是指尖」）；②术语截断产生歧义
> （如「一场三分钟的急」）；③伪文学腔（句式像文学但语义不通）；④任何让你顿一下、
> 需要回读的句子。输出逐条【原句】【毛病】【严重级：不通/别扭/可留】，最后给结论：
> 能不能直接见老板。零容忍标准：正经出版物编辑会打回的都算。

**修改回合规则**：「不通」级必改；「别扭」级顺手改，仅当修改会破坏论据精度时可驳回
（驳回要写理由，范式同 narration-spec 三轮审校的驳回记录）；改完送**复检**，
终态判据＝编辑结论原句「能直接见老板」。≤2 轮仍不过 → 按 §10.6 处置。

**🩸 修改连锁传播纪律（首轮闭环实测的头号返工源）**：每改一处，必须搜出该对象/状态
（人物姿态、道具、声音、口径、时间码）在稿子里的**全部其他出现处**一并顺改——实测把角色
钉成站姿却漏改下游「并肩坐」、翻案潜台词却漏翻案人物朝向，点修必生新矛盾。修改台账每项
必须带「连带改动清单」，声称零连带的要说明为什么。（这就是共享代码库「平行映射表」教训
在虚构文本里的等价物。）
