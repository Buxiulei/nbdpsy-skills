# 报告写作范式：麦肯锡式（用户拍板的硬要求）

2026-08-04 用户对报告初版的批评原话大意：「报告需要故事线串联所有信息；行文里很多你自己推翻自己
假设的地方——推翻以前的假设可以，但推理过程不需要告诉我；我要的是连贯的、有可阅读性的报告」，
并点名「学学麦肯锡、BCG」。以下范式据此定稿，**每一期报告都按这个来，不要退回数据罗列体**。

## 骨架：金字塔原理

答案先行，然后才是支撑。整份报告一条故事线贯穿，2026-07 的实例是：
**兑现（收入新高但钱是存量在付）→ 中段变松（核心章）→ 弹药供给 → 战略对表 → 下月修链**。
每期的故事线要从数据里长出来，不是套模板——先想清楚「这个月真正发生了什么」的一句话，再展开成章。

## 第 0 页：SCQA + 一页答案

- **S 现状**：这个月表面上发生了什么（通常是成绩）。
- **C 冲突**：数据揭示的张力（成绩背后的隐患，或预期与实际的落差）。
- **Q 问题**：老板会问的那一个问题（如「增长能否延续到 Q4？」）。
- **A 答案**：直接回答，视觉最重，附「前提是……」的行动指向。
- **一页答案**：三个支柱（每个=一句话+关键证据），三张并排卡片。
- 关键数字卡片行（8 个左右，本月值+环比）。

## 行动标题（最核心的一条）

每个章、节标题都是**完整的结论句**，不是主题词。检验标准：把全文标题抄出来连读，
应该就是一份完整的报告摘要。

- 坏：「收入分析」「小红书数据」
- 好：「收入创新高，但钱是存量转化在付」「小红书：推介是最能打的品类、收藏型选题首次冒头；
  发文量与封面返工两笔欠账滚入八月」

每章开头配一行「标题串读」导读（把本章各节标题串成一句话），低调样式。

## 图表纪律

- 每张图下方一行 **so what**：这张图让读者应该带走的那一个判断，不是图的描述。
  （例：北极星队列图的 so what 是「它塌了，两三个月后长期客户就断供」，而不是「达标率逐月下降」。）
- 一图一事。数据趋势用折线/柱，漏斗用横条，构成用堆叠；观察未满的数据画成区间/虚线并标注。

## 行动清单

表格化，分 P0（不做下月就会疼）/ P1（下月内启动）/ P2（有余力），四列：
**动作 | 归属 | 时限 | 检验标准**。每条动作能追溯到正文的一个发现；检验标准必须可核（数字或产物）。

## 禁令：过程叙述不入文

以下语言属于分析师工作底稿，**一个字不能出现在正文**：

- 「经复核成立 / 修正一 / 修正二 / 原判定偏重 / 需显式撤回 / 这两件事不要混着讲」
- 「我先算了 X，后来发现 Y」「时间定向核验后坐实」「对抗复核确认」
- 任何同一份报告内「先立一个说法、再推翻它」的自我辩论结构

正确做法：**结论直接陈述、证据跟在后面**。推翻上一期报告的判断是合法的业务更新，
写法是陈述新事实（「月中曾按折算预计回落；全月实际 +15.4%——七月不是平台期，而是新顶点」），
不是叙述你的心路。口径折衷、复核声明统一收进附录，各一句话。

## 其他行文纪律

- 每段第一句是该段结论（top-line sentence）。
- 数字从数据定稿照抄，禁止转换时四舍五入变位。
- 来访者一律以 customer_code 指代，不写姓名/昵称等 PII；咨询师用真名（内部报告）。
- 篇幅感：正文五章 + 摘要 + 附录，1 万字上下；宁可删细节，不可断故事线。
- 观察未满/置信度低的数字，诚实标注区间与定值时点——这不是过程叙述，是数据责任。

## 结构模板（2026-07 实例的抽象）

```
第 0 页 · 摘要（SCQA + 一页答案三支柱 + 关键数字卡片）
第 1 章 · 基本盘（钱从哪来、成色如何、谁在贡献）
第 2 章 · 增长引擎（本期核心矛盾所在的那条链，通常是最长的一章）
第 3 章 · 供给侧（内容/渠道/账号的弹药状态）
第 4 章 · 战略对表（承诺 vs 实际 + 数据地基欠账）
第 5 章 · 下月行动（P0/P1/P2 表格）
附录 · 方法与口径（复核声明、口径折衷、观察未满清单）
```

核心矛盾章不必永远是第 2 章的「转化中段」——每期把当月最要命的那条链放在核心章的位置。
