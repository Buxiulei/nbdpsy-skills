# 咨询师推介笔记规格（独立场景，不从 pillar 长文拆分）

> 依据：小红书平台规则、《广告法》§9（极限词）/§17（医疗用语）/§4（虚假宣传）、《交易导流违规管理细则》、全国统一心理援助热线 12356。
> 本场景与「长文拆小红书」共用同一套品牌基底、合规红线与出图/发布链路，仅**取材源不同**：这里取材于官网咨询师公开资料，不拆长文。
> 结构规格、禁用词替换表、全局硬闸 G1–G10 仍以 `references/xiaohongshu-spec.md` 为准，本文只补「咨询师推介」这一场景的差异部分。
>
> **本文覆盖两条路径，口径不同、别混用**：**§1–§5 = 整篇推介笔记**（4–6 页全写这一个人，照片由运营索取、走三铁律）；**§6 = 科普笔记末页追加 1 页推介**（素材是系统头像 `avatar_url`，上传即授权、不设本人认可闸门）。判据一句话：**照片从哪来**——运营手里来 → §1–§5；`avatar_url` 来 → §6。

一句话定位：把一位咨询师的**后台真实资料**，翻译成一条正在 emo、正在纠结"要不要找咨询师"的真人愿意读下去的图文笔记。卖点是**这个人可信、可托付**，不是"疗效"。

## 0. 数据源与字段口径

数据实时从官网免鉴权公开 API 拉取（`scripts/fetch_counselor.py`），**禁止手改**——价格、资质随后台变动，笔记必须与后台一致。

| 字段 | 来源 | 用途 | 口径 / 红线 |
|---|---|---|---|
| `emp_no` | list / 详情 | 咨询师唯一编码，拉详情用 | — |
| `name` / `display_name` | list | 姓名 | 以 `display_name` 为准（`name` 常为空）；`fetch_counselor.py --list` 已做好回退 |
| `title` | list / 详情 | 职称（如「CPS 注册心理师」「北大临床心理硕士」） | 按后台事实原样引用，不升格（别把「助理心理师」写成「资深专家」） |
| `is_accepting` | list / 详情 | 是否接单 | 停单的咨询师**不做推介笔记**（引来了约不上，体验最差）；只给 `is_accepting=true` 的人做 |
| `price_per_session` | list / 详情 | 正式咨询标价 | 展示格式 **「¥N / 次」**（N 直接取整数元，如 `400.0`→「¥400 / 次」） |
| `communication_price` | list / 详情 | 预沟通价 | 展示格式 **「预沟通 ¥N」**；为 `0` 时写 **「预沟通免费」** |
| `specialties` / `profile_sections.specialties` | list / 详情 | 擅长方向 | 只用后台已有条目，**绝不新增擅长领域** |
| `profile_sections` | 详情 | 结构化详细介绍（experience/methods/philosophy/training/testimonials…） | 亮点段的唯一素材库，**引用其原意、不编造** |
| `experience_years` | list / 详情 | 从业年限 | 有则用，无则不提，不估算 |
| `schools` | list | 流派 / 取向 | 有则用（如「精神动力」「CBT」），无则不提 |
| `avatar_url` | 详情 | 咨询师系统头像 | **相对路径**（`/static/avatars/xxx.jpg`），要拼 `https://database.nbdpsy.com` 才能下载；`fetch_counselor.py --emp <emp_no> --avatar-out <路径>` 直接落本地。**可作为「科普笔记末页推介页」的合成素材**——咨询师上传头像到系统即已授权我们使用（2026-07-25 老板定案，见 §6）。⚠️ 整篇推介笔记的 P1 封面**另说**：那条路径用的是运营额外索取的照片，仍走 §2 照片三铁律 |
| `video_intro_url` / `audio_intro_url` | 详情 | 音视频介绍 | 仅参考，**不作为发布素材** |
| 🔴 `contracted_price` | 详情响应里**曾**出现 | —— | **签约价属用户隐私口径**。`fetch_counselor.py` 已在返回前显式删除该字段；任何情况下**绝不落盘、绝不进笔记、绝不换算展示**。对外价格只有 `price_per_session` 与 `communication_price` 两个。 |

🔴 **价格必须展示（2026-08-08 运营定案，推翻 2026-07-24 的「默认不展示」旧口径）**：
**我们在小红书做价格透明**——推介笔记的简历图与介绍文案**都要写价格**，不再问「这篇要不要展示」，默认就写。
- 展示哪两个数：`price_per_session`（正式咨询单次价）与 `communication_price`（预沟通价，为 0 时写「预沟通免费」）。
- **数字只能取 `fetch_counselor.py` 的实时值**，⛔ 绝不手填、绝不沿用旧稿——价格会变（实例：李宇 2026-08-08 调到 600，六个号的旧笔记全部要改）。**每次生成前重新拉一次。**
- ⛔ **`contracted_price`（签约价）仍是绝对红线**：那是用户隐私口径，`fetch_counselor.py` 已在返回前删除该字段。「价格透明」指的是**对外挂牌价透明**，不是把签约价也放出去——两件事别混。
- 标题里仍**不写价格**（标题是钩子，不是价目表），价格写在正文与末页。
- ⚠️ **价格一变，存量笔记要跟着改**：改价后须全矩阵搜同一咨询师的推介笔记逐篇更新（正文＋末页图），流程见 §改价维护。

## 1. 发布标题（三要素：姓名 + 能力 + 来访画像，2026-07-27 老板定案）

> **为什么新增**：此前本规格**只有封面大字的写法、没有发布标题的规格**——发布标题是空白地带，
> agent 只能凭感觉起题，信息密度自然上不去。2026-07-27 老板定案（证据见 1.3 站内数据）：
> 老板原话「推介笔记我就感觉信息密度太低了。**标题要出现咨询师的名字，以及他的能力、来访画像**。
> 标题和文本内容可以参考 NBDpsy 主号的笔记：**心理咨询师-李宇，陪你整合创伤与秩序**」。

**结构定死**（写进 `post-NN.md` frontmatter 的 `title:` —— `count_xhs.py` 数的就是这一行）：

```text
心理咨询师-{姓名}，{陪你/带你 + 能力动词短语（嵌来访画像的困扰词）}
```

### 1.1 三要素（缺一不可，缺任一 = 返工）

| 要素 | 怎么写 | 红线 |
|---|---|---|
| **姓名** | 前缀「心理咨询师-」＋**直呼其名**（「心理咨询师-李宇」） | **绝不加「老师」「X 老师」**（红线速记第 0 条）；后台属实的复合身份可写「心理咨询师/催眠师-〇〇」，但**不升格**（后台是「助理心理师」就不写「资深专家」） |
| **能力** | 他真正擅长做的事，**动词短语**（「整合创伤与秩序」「找回身体感受」） | ⛔ **不要抽象理念词**（「从理解出发」「重构自我」这类——站内数据表现明显差，见 1.3/1.4）；每个词都要能在 `fetch_counselor.py --emp` 输出里**指到出处**，不硬蹭、不升格 |
| **来访画像** | **以困扰词形式嵌在能力短语里**（「创伤」「身体感受」就是画像——搜这些词的人就是目标来访），或用「陪你」的「你」把困扰具体化 | 20 字装不下三要素分立时，**画像嵌进能力短语**是标准解法（李宇篇即此形态）；⛔ 不要写成人群标签堆砌（「适合职场人/学生党/宝妈」） |

### 1.2 硬约束

- **≤20 字**（`count_xhs.py` 的 `TITLE_MAX`，口径＝剔 emoji 后按字符数计）。
  「心理咨询师-李宇，陪你整合创伤与秩序」＝ **18 字**，是贴着上限的**满格示范**——
  **满格是目标不是风险**：还剩字数就把画像写得更具体，别留白。
- 能力短语的每一个词**必须能在 `fetch_counselor.py --emp` 的后台资料里指到出处**（同 §3 亮点口径：不硬蹭、不升格、不编造擅长领域）。
- 句式默认「**陪你 / 带你**」（也可「和你一起…」），保持**陈述**：⛔ 标题里禁「立即预约」「私信我」「限时」这类 CTA 词（投流拒审词，`check_compliance.py` 也扫）。
- 极限词（「最专业」「最懂你」）/ 医疗词（治疗/治愈/诊断）照禁；标题**不含价格**、不含站外导流。
- 自检：`count_xhs.py` 会校 20 字硬限；**不要传 `--title-keyword`**（那是科普笔记的长尾词规则，见 1.5）。

**关键对照（这组最硬）**：**李宇（04-29，1982 views / 12 粉）vs 赵野（04-28，187 views / 0 粉）**——

两条次级规律：
1. 带「**陪你 + 能力短语**」的（李宇 1982 / 胡琬琰 1698）**显著高于纯名字**的（李冠阳 677 / 于施文 454 / 赵野 187）。
2. 「**具体困扰词**」（创伤、身体感受）**优于「抽象理念短语**」（徐瑞恒「从理解出发，找到自由」407 / 刘琼「探索潜意识，重构自我」380）——理念词读者搜不到、也对不上号。

⚠️ **混杂因素要认**：这 7 篇发布时间不同（04→07 月）、账号粉丝在持续增长、题材与咨询师本人知名度也不同，
不是严格对照实验；且**涨粉维度有一条反向信号**——纯名字的李冠阳 7 粉高于三要素齐全的胡琬琰 3 粉，
样本量太小不足以推翻 views 上的规律，但记在这儿，免得日后有人拿这一列反打。
**但李宇 vs 赵野这组前后一天、同号的对照足够硬**，且两条次级规律与之同向，
故按此定规格。后续有新数据（尤其是反例）就回来修这一节，不要拿单篇波动推翻。

### 1.4 正例 / 反例

**✅ 正例**（站内原题，三要素齐全）：
- `心理咨询师-李宇，陪你整合创伤与秩序`（18 字｜姓名 ✓ 能力「整合…秩序」✓ 画像「创伤」✓ → 1982 views）
- `心理咨询师-胡琬琰，陪你找回身体感受`（18 字｜画像「身体感受」嵌在能力短语里 → 1698 views）

**❌ 反例一 · 纯名字（＝赵野形态）**：`心理咨询师-赵野`、`心理咨询师 | 李冠阳`
—— 只有姓名，能力与画像双缺；数据 187 / 677（分别是全表最低位与中下位）。**这种标题直接返工。**

**❌ 反例二 · 抽象理念词（＝徐瑞恒/刘琼形态）**：`心理咨询师-徐瑞恒：从理解出发，找到自由`、
`心理咨询师-刘琼，探索潜意识，重构自我`
—— 形式上像三要素，但「从理解出发」「重构自我」**不是来访会搜的困扰词**，画像其实缺位；
数据 407 / 380，明显低于同结构的具体困扰词篇。**改法**：把理念词换成后台资料里真实覆盖的困扰词
（如刘琼若后台确有相应方向 → 「陪你看懂反复出现的关系模式」之类，仍以 `--emp` 出处为准）。

**❌ 反例三 · 硬蹭**：后台资料里根本没有创伤方向，却写「陪你整合创伤」——数据再好也不能这么写，
违反 §0/§3「亮点每一句都能在 `--emp` 输出找到出处」。

### 1.5 与科普笔记标题规则的区别（别拿科普规则误判推介）

`xiaohongshu-spec.md` §1「标题」的 **「目标长尾词必须完整落在前 10 字内」对推介笔记不适用**：
推介笔记的**前 10 字天然是「心理咨询师-{姓名}」**，那是**人名搜索入口**（读者是冲这个人来的，
或从主页/评论区认识后回搜姓名），**本身就是对的**，不是"钩子占了关键词的位置"。
议题长尾词（CPTSD / 依恋修复…）在推介场景**落在正文与标签行**，不跟标题前段抢位。
因此自检时 **`count_xhs.py` 不传 `--title-keyword`**（传了必然误报），审查端也**不得**用这条科普规则判推介笔记 FAIL。

### 1.6 标题定了之后，三处必须同源

同一句能力+画像要贯穿到底，别写成三张皮：

1. **frontmatter `title:`** —— 本节的三要素结构（发布标题）。
2. **P1 封面副题第二行** —— 能力/画像钩子（≤14 字，**可直接取标题里的能力短语**，见 §4「P1 · 照片封面」）。
3. **正文 ① 开头人物直入** —— 第一段就把标题这句**展开讲**（标题写「整合创伤与秩序」，开头就说清这是什么困扰、他怎么工作，见 §3）。

## 2. 照片三铁律（真人照片入图的强制前提）

> **适用范围：本节只管「整篇推介笔记」这条路径**——素材是**运营额外向咨询师索取的照片**，
> 授权范围逐次确认、成图须本人过目认可。**科普笔记末页的推介页是另一条独立路径**：素材是
> **咨询师自己上传到系统的头像**（上传即授权），不设本人认可闸门，口径见 **§6**，别把两套
> 规则混用。判据一句话：**照片从哪来**——运营手里来 → 走本节；`avatar_url` 来 → 走 §6。

推介笔记的 P1 封面**可以**放咨询师本人真实照片（比品牌插画更可信）。**照片只上封面这一页——内页（简历卡等）一律不再放照片（2026-07-24 定案：封面已见真人，内页重复出现显得堆砌）**。真人肖像的合规与失真风险远高于插画，故设三条铁律，任一不满足就**不出图、不发布**：

1. **授权先行**：出图前必须由运营向咨询师本人确认「**已同意将该照片用于小红书宣传**」，并把这句确认回给你。**未拿到确认 = 停等**，不得先斩后奏。授权对象是「这张照片 + 小红书这个用途」，不是泛泛的"同意露脸"。
2. **AI 直出为默认、本人认可为发布闸（2026-07-24 定案）**：默认把授权照片上传图床后作为 `anchor_url` 交给后端 gpt-image-2 **直出带照片的 P1 封面**（模型会重绘人物——实测还原度很高、版式融合自然，但输出不是原像素）。因此**成图必须经咨询师本人过目认可后才可发布**——运营流程本就让咨询师自审推介内容，把「看成图」并入该环节即可；本人未认可一律不发。咨询师在意像素级真实、或对重绘效果不满意时，改走**备选保真路线**：`scripts/compose_photo.py` 本地几何合成（等比裁剪/圆角/品牌描边，照片不进模型），配 §4 附录的留白底图模板。
3. **照片不入库、用完即弃**：真人照片文件**不提交进 git**（已被 `.gitignore` 之外的产物目录约束，落 `{note_dir}/photo/` 临时用）；交付后提醒运营**自行保管原图**、本地合成产物用完可删。台账里也不留照片。

> 这三条不是流程摆设：一张未经授权或被 AI 改脸的咨询师照片流出，对一个靠信任吃饭的心理工作室是可以上门维权的事故。宁可这篇不配真人照（退回纯插画封面），也不碰这三条红线。

## 3. 文案骨架（正文 400–800 字，「人物直入」三部分）

> **2026-07-24 定案，来自黄安麟篇实战反馈**：推介笔记是**介绍一个人**，不是科普文。此前照搬科普三段式（痛点场景铺垫 →「选咨询师其实是先认识一个人」类导语 → 干货），把介绍一个人写成了栏目文——**整段删掉**。推介骨架改为「**人物直入**」三部分：开头直接把这位咨询师最硬的资质/画像摆出来，主体把擅长议题逐条展开讲透并埋长尾词，结尾说怎么开始。

**发布标题另有规格，见 §1**（`心理咨询师-{姓名}，{陪你+能力动词短语（嵌画像困扰词）}`，≤20 字）——本节正文 ① 开头必须与标题**同源展开**。

不再套 xiaohongshu-spec 的科普三段式。**排版仍按 `xiaohongshu-spec.md` §1.6「发布排版规范（手机端实际渲染）」重排**——每段 2–3 行留空行、强调靠独立成行不靠加粗（小红书正文不渲染 Markdown）、emoji 温和克制、资质分点用 `·`。**唯一例外：§1.6「F · 危机声明的排版位置」条对本场景不适用**（本场景不含危机声明，见下）。

| 段 | 占比 | 写什么 | 硬要求 |
|---|---|---|---|

## 5. 完整流程（每步有验证闸门）

1. **fetch** — `python3 scripts/fetch_counselor.py --list` 选人（或直接 `--emp <emp_no>` 拉详情）。确认 `is_accepting=true`；确认输出里**没有** `contracted_price`。
2. **照片与授权确认（停等闸门）** — 询问运营：这篇**封面**要不要放真人照片（照片只上封面，内页不放）？要 → 索取照片 + **回传"咨询师本人已同意用于小红书宣传"的确认**；拿不到确认或运营选纯插画 → P1 退回纯插画封面（整篇无真人照）。**未确认不进出图。**
3. **文案** — 先按 **§1 定发布标题**（frontmatter `title:`＝`心理咨询师-{姓名}，{陪你+能力动词短语（嵌画像困扰词）}`，≤20 字，能力短语在 `--emp` 输出有出处），再按 §3「人物直入」三部分写 `post-NN.md`（正文 400–800 字 + 可见标签含长尾词 + `### P1…PN` 轮播 + 页面文字 + 提示词）；开头与标题**同源展开**、擅长议题逐条展开并嵌长尾词、受训流派写明、亮点逐条对齐 `--emp` 输出。
4. **合规校验 + 字数页数自检** — `python3 scripts/check_compliance.py {note_dir}/post-NN.md --no-crisis` 每篇 `ok=true`（`--no-crisis` 跳过危机声明在位检查——本场景不含 12356 声明；极限词/医疗违禁/站外导流照扫）；`python3 scripts/count_xhs.py {note_dir}/post-NN.md --body-min 400 --body-max 800 --page-min 4 --page-max 6` 每篇 `ok=true`（**不传 `--title-keyword`**——那是科普笔记的"长尾词落前 10 字"规则，对推介笔记不适用，见 §1.5；标题 20 字硬限脚本自动校）。额外核：**标题三要素齐全**（姓名/能力动词短语/画像困扰词，§1）——脚本查不出来，人工过一眼；**价格必须在位**且为 `fetch_counselor.py` 实时值（缺价格或价格与后台不符 = 返工）、亮点与长尾词无一句/一词超出后台资料。
5. **出图** — 内页（简历卡 / 风格卡 / 预约页）按 SKILL「出图」章节常规产出，**绝不带照片 anchor**；**P1 封面页**：先把授权照片上图床拿直链（`python3 scripts/publish_note.py --upload-images <照片>` 取 urls[0]；7 天过期、目录不可猜，提醒运营照片会短存服务器图床），再 `python3 scripts/gen_images.py --note <post-NN.md> --pages 1 --anchor-url <照片直链>` 单出封面。
6. **本人认可（硬闸）** — 把封面成图发给咨询师本人过目，**明确认可后才可进入发布**；不满意可调提示词重出，或改走备选保真路线（compose_photo 本地合成）。**实操通道**：封面成图用 `python3 scripts/publish_note.py --upload-images <P1成图.png>` 上图床，把返回的 url 发运营转给咨询师本人过目——链接点开即看、无需来回传文件（7 天过期，过期重传）。⚠️ **务必区分两种链接**：第 5 步为出图上传的**授权照片原图**图床链接**只作 anchor_url 喂后端生图用，绝不当查看链接转发扩散**（那是咨询师真人肖像原图，隐私红线）；转给本人过目的只能是**已重绘/合成的成图**链接。
7. **图审** — 逐图核对：图内中文无错字、全套风格一致、**照片只出现在 P1 封面（内页出现人物照片＝返工）**、**封面副题两行齐（职称行 + 能力/画像钩子行，且钩子与发布标题同源）**、**封面资质编号行逐字等于事实包该人的注册号项**（有则放无则不放、**两项都无则整行不出现且不算缺**；分隔符是「·」不是「／」；**注册号逐位比对、且 ⛔ 从中间断成两行**；字号 ≥21px、≤3 行；**学历在副题第一行、⛔ 重复到编号行**；⛔ 未挤占 hero 与副题（引导句 11 张同字号同行数）、⛔ 头像未被缩小（仍 36%）、⛔ detail 未超 2 处；副题第一行的「北大」仍在）、简历卡信息点 ≥8 且与后台资料逐条一致、**P3 风格卡信息点 6–10 且每条落成具体格子**、**PN 末页有预约流程 + 画像 3–4 条「如果你正在…」**、封面人物与照片观感一致（最终以咨询师本人认可为准）。
8. **发布 / 交付** — 沿用 SKILL 的路线 A（`publish_note.py` 自动发布，**发布前确认账号与篇目**）/ 路线 B（人工发布）；提醒运营真人照片自行保管、不入库。

## §改价维护：咨询师调价后，存量推介笔记怎么跟

**为什么要有这一节**（2026-08-08 实战）：李宇价格调到 600，全矩阵**六个号各有一篇**他的推介笔记（标题还各不相同，说明来自不同批次），旧价格全在挂着。**价格透明的前提是价格得是真的**——挂着过期价格比不挂更糟。

**流程（顺序不能反）**：

1. **先下架止损**：`note_ops.py --set-visibility --account <A> --note-id <N> --privacy 1`（1＝仅自己可见）。
   ⚠️ **先下架再改**，别让旧价格在改的这段时间里继续曝光。
2. **全矩阵找齐**：`--ledger <每个号>` 搜该咨询师姓名——**别只改你记得的那一两篇**。不同批次做的版本标题可能完全不同（李宇那六篇：「安放童年创伤」「整合创伤与秩序」「看懂童年创伤的影响」「EMDR博士聊PTSD」各不相同）。
3. **重新拉实时资料**：`fetch_counselor.py --emp <emp_no>` 取新的 `price_per_session` / `communication_price`。
4. **改正文 + 重出末页图**：价格在正文与末页两处，两处都要改；末页图要重出（改稿不改图＝图文不符）。
5. **改完再转回公开**：`--privacy 0`。
6. ⚠️ **本地没有原稿的老笔记**：早期批次的稿件可能没入库（李宇那六篇里有四篇本地找不到原稿）。这时候**别硬找**——直接用当前规格 + 最新资料**重做一版**替换，比考古更快也更规范。

⚠️ **速率**：一篇要 下架 + 改文 + 换图 + 转公开 ≈ 4 次会话，六篇就是 24 次。**串行慢跑**，别并发（并发会被排队拖成假失败，见 SKILL.md 风控段）。
