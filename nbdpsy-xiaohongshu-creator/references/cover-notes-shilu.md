# 三条字卡短片的封面（按 illustration-spec §2-b 封面版式工程）

> 🔴 **只当例句读，⛔ 不许照抄参数**：本快照里的字号口径（hero ≈ **画布宽** 10% / support 4.5% / detail 3%）是**已作废的旧口径**；现行唯一真源见 illustration-spec §2-b 系数制（hero ≈ **画面高** 13%、副题 ×0.34、小字 ×0.22）。照抄这里的分母会让字号小一半。留它是因为**被否原话与选句思路**仍然有效——那才是这份快照的价值。
> 另：上文按「三条成品封面」编 P1/P2/P3，文末附表按 v1…v7 编版本。引用一律写「例句库 v{N}」（＝附表那套，与 illustration-spec §2-b 例句库同编号）。

系统声明（出图前先行）：
- 版式：**通栏大字压顶**（三条均有 ≤8 字 hero）
- 字号档位：hero ≈ 画布宽 10%、support ≈ 4.5%、detail ≈ 3%；hero:support ≥ 2.5:1
- 焦点归属：hero 独占最大字号+最粗字重+唯一强调色赭红 #A34B3A 三项；四周留 ≥1 hero 字高隔离带
- 留白配比：hero 压上 1/3；底部 15% 不放任何文字；上下各 11% 为 3:4 牺牲带（出 2:3 后裁中央 3:4）
- 背景层：图文 v2 风格档案——暖米白 #E8D8C4 纸质肌理底、莫兰迪低饱和（雾霾蓝灰 #A8B5C4 / 鼠尾草绿 #C9D6CE）、柔光颗粒
- 锚点：**刘琼真人头像直链**（内容为其论文拆解，封面须带作者真人头像——2026-08-14 老板定为长期规范：拆解对应咨询师长文时封面必须出现其真人头像元素，提升活人感）
- 头像元素（**2026-08-14 老板令：头像放大成主要元素**）：真实照片圆形头像框（鼠尾草绿细描边）**直径约画面宽 36%**、居中偏左置于中下部主视觉位，+ 身份行「刘琼 · 论文作者」；主题小插画退为**陪衬**（缩到画面宽 22% 以内、置右下、不与头像争）；hero 文字层级不变

层级标注（选句判据：读者说「啊？」不说「哦」）：
- 封面1 [hero]这不是鸡汤（5字·打翻「对自己好=鸡汤」共识）[support]对自己好一点，六周后生活质量实测改善 [support]连按时吃药这种事，都变容易了 [detail]NBDpsy 心理科普（修订：副题必须给出结果，回答「然后呢」——2026-08-14 老板反馈）
- 封面2 [hero]酸，说明练到了（6字·打翻「别扭=方法不对」）[support]对自己说好话觉得肉麻？那不是矫情 [support]三句话练习，出自六周团体课程 [detail]NBDpsy 心理科普
- 封面3 [hero]不是围圈哭诉（6字·打翻大众对心理团体的刻板画面，零服务承诺）[support]心理团体的六周：讲解、冥想、分享 [support]听见别人的难，才知道不是只有我这样 [detail]NBDpsy 心理咨询（三轮修订留痕：v1「摄像头 可以不开」=研究特殊安排放大成通用规范，事实越界被否；v2「一节没落」=答案碎片不自明、无好奇缺口被否——hero 三问：意思自明吗/传达什么/凭什么点进去；v3 辅句改共同人性方向=老板点出「了解他人的苦痛，知道自己不是唯一的」，长文第 94 行有直接论证「不是只有我这样…这句话的分量是不同的」——2026-08-14）

## 附：同批封面 hero 连错七版（2026-08-13~14 打回实录）

同一批封面被老板打回 **7 次**才过，每次错法都不同，逐条当 ⛔ 例句用：

| 版本 | 做法 | 被否原话 / 原因 |
|---|---|---|
| v1 | 直接拿视频第 0 帧当封面 | 「你居然都没有做封面！！！」——**截帧不是封面** |
| v2 | 自创深色 HTML 封面 | 「完全不符合我们 skill 里对于封面制作的规范」——**绕开 §2-b 自己发明版式** |
| v3 | 按 §2-b 出，hero=「摄像头 可以不开」 | 「这个是团体治疗的规范吗」——**把研究里特殊人群的特殊安排放大成通用规范，事实越界** |
| v4 | hero=「一节没落」 | 三问全答不上（意思自明吗／要传达什么／凭什么点进去）——**答案碎片不自明、无好奇缺口** |
| v5 | 加刘琼真人头像（画面宽 22%） | 「头像可以放得更大一些，成为主要元素」——**署名长文拆解的头像不是配饰** |
| v6 | 头像放大到 36% | 「封面里表述太少，看不懂到底要说啥」——**信息量不足** |
| v7 | 补足信息，hero=「敢不敢承认疼」 | 「说得都不吸引人」→ 改口后又「看不懂」——**术语腔／文艺腔当钩子** |
| 终稿 | 递进式三行（两个圆点＋虚线 → 赭红箭头结论行），**无序号** | 中间还被否一次：「递进式，还用 123 这样的，就很奇怪了」 |

**这七版暴露的结构性缺口**：hero 选句判据当时只有「读者说『啊？』不说『哦』」一条，缺三样——

1. **事实边界**：研究里的特殊安排 ≠ 服务通用规范（v3 栽在这）；
2. **自明性**：脱离正文能不能独立读懂（v4/v7 栽在这）；
3. **信息量下限**：封面要能让人看懂「这篇要说啥」（v6 栽在这）。

另两条同批定下的规则：**副题必须回答「然后呢」**（给出结果／利益点）；**装饰性序号**（01/02/03、圆形数字徽章）在递进式版式里**是负分**。

> 对照读：上文封面 3 的「三轮修订留痕」是这张表 v3→终稿 那一段的现场版；
> 头像放大到画面宽 36%、身份行「刘琼 · 论文作者」的写法即 v5→v6 的落地形态。
