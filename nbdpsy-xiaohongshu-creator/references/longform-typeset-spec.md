# 长文拆解 · 路线② 文字版（2026-07-28 老板定案）

> 老板原话：「博客长文的第二种拆解方式，直接把文本内容精细排版，去掉引用部分，整理成口语化表达，
> 做成竖版图文笔记发布。小红书主体文本内容，就写引言，简短介绍，SEO 钩子标签。」

一篇官网长文有两条上小红书的路。本文件只讲**路线②**；路线①（信息图轮播）的规格在
`illustration-spec.md` + `xiaohongshu-spec.md`，两条路的判据、正文写法、出图方式、审查口径**都不一样**，
别混着用。

---

## 1. 两条路线怎么选（先判这一步，判错整批返工）

| | **路线① 信息图轮播**（默认） | **路线② 文字版**（本文件） |
|---|---|---|
| 一篇长文产出 | 拆成 **5–8 条**独立笔记 | **1 条**（长文整篇搬过去） |
| 图里是什么 | AI 画的知识卡（图文双通道） | **长文正文本身**，精细排版 |
| 怎么出图 | `gen_images.py` 喂 AI 生图 | `typeset_longimage.py` 排版渲染（**不过 AI**） |
| 页数 | 6–9 页（人定） | **由字数决定**（脚本算），实测 **≈240 字/页**（1700 字→8 页，3300 字→13 页） |
| 小红书正文 | ~300 字三段式（痛点→干货→轻引导） | **引言 + 简短介绍 + 标签**（短，见 §5） |
| 每页信息密度 | 密度五字段管着（200–400 字/页可调） | **不适用**——文字版没有"信息点"概念，见 §6 |
| 读者行为 | 划 6–9 张，收藏 | 点开文字版**读完**，收藏 |

**选型判据（按顺序问，先中先得）**：

1. **运营点名了走哪条** → 照做（「做成文字版」「按那个文字版做」= 路线②；「拆几条」「出轮播」= 路线①）。
2. **长文的价值在"完整论证链"上吗？** —— 有六个层级/五个阶段/一套完整对照表，**拆开每一块都不成立**
   → 路线②。硬拆成 6 条 = 每条都是残缺的半截知识。
3. **长文里有 ≥1 个必须整体呈现的表格 / 分级清单** → 路线②（AI 生图画不出四行三列还字字不错的对照表）。
4. **长文能切出 5–8 个互不重叠的痛点场景** → 路线①（这是默认，绝大多数科普长文走这条）。
5. **都不明显** → 路线①，并把「本篇更适合文字版」写进 `00-overview.md` 让运营拍板。

⚠️ **两条路不混用**：同一篇长文要么① 要么②。运营既要轮播又要文字版 = 当成两个批次分别走，
产物落两个目录（`{slug}/` 与 `{slug}-longform/`），别在一个批次里塞两套图。

## 2. 文本改造四道工序（**顺序不能换**）

源长文 → ①去引用 → ②口语化 → ③排版标记 → ④配首页信息 → 交给脚本。

### 工序① 去引用（老板明确点名的那一步）

**去掉的是"给搜索引擎与 AI 引擎看的那套引用机器"，不是"学术出处"**——这条判错会把内容做成
「一堆没出处的心理学断言」，那是本产线的红线之一（铁律 1：不新增未验证事实）。

| 处理 | 对象 | 例 |
|---|---|---|
| ❌ **删掉** | 编号引用标记 `[[1]]` `[[2]](url)` | `…核心策略之一[[3]](https://…)。` → `…核心策略之一。` |
| ❌ **删掉** | 文末「参考文献 / References」整节 | 整节删除 |
| ❌ **删掉** | 正文里的裸链接、`详见 xxx.com` | 站外链接在小红书本来就是红线 |
| ❌ **删掉** | 「本文参考了 N 篇文献」这类元叙述 | — |
| ✅ **保留** | **行内作者 + 年份** | `Marsha Linehan（1993）提出…` **保留原样** |
| ✅ **保留** | 术语英文原名 | `有效化（Validation）`、`共同调节（co-regulation）` |
| ✅ **保留** | 「大量研究显示 / 发展心理学认为」这类概括 | 原文有就留，**不许自己新加** |

> **为什么保留作者年份**：参考样本逐张核过——`Linehan（1993）`、`Fruzzetti 与 Fruzzetti（2003）`
> 全都在图上。它们既是可信度来源，也是这套排版的质感来源；删掉之后内容会显得像"个人观点"。
> **删的是跳转链接，不是出处本身。**

### 工序② 口语化

长文是写给搜索引擎和"坐下来读"的人的；文字版是写给躺着刷手机的人的。改写口径：

- **拆长句**：一句超过 40 字就断开。书面连接词（「因此」「与此同时」「基于上述」）换成
  「所以」「而」「这就是为什么」，或者直接断句。
- **换人称**：「个体」「儿童」→「一个人」「孩子」；「患者」→ 不用（医疗词，见红线）。
- **去学术腔**：「呈显著负相关」→「越…越…」；「本研究表明」→「研究发现」。
- ⛔ **不许改结论、不许加新事实、不许把"相关"说成"导致"**——口语化只动**表达**，不动**内容**。
  改完必须能逐句回溯到源长文。
- **保留原文的分级/编号骨架**（「第三级」「第五级」），那是读者的路标。

**长度控制（这一步顺手做掉，不是单独一道工序）**：成图**实测 ≈240 字/页**（9:16 画布）。

| 改写后字数 | 页数 | 判断 |
|---|---|---|
| 1500–3500 字 | 7–14 页 | ✅ **目标区间**（参考样本 2206 / 2890 字） |
| >3500 字 | 15 页+ | **拆成系列篇**（上/中/下 或 一/二/三/四），见 **§7**。⛔ 别硬砍成一条 |

**超长优先拆系列，不优先砍**（2026-07-28 老板定案）：一篇 6000 字的 pillar 长文砍到 3000 字，
砍掉的都是运营辛苦查证过的内容；拆成三条系列篇，读者追更、笔记数量还翻倍。

确实需要瘦身时（比如 4000 字拆两条后每条仍显肿），按这个顺序砍：FAQ 节 →
「什么时候需要专业支持」压成一个清单 → 方法论免责声明合并同类项（「这是横断相关不能读成因果」
这类，全文留 1–2 处即可，**不要全删**——那是这个号的可信度）→ 次要研究举证
（同一结论有三项研究支撑时留最有说服力的一项）。
⛔ **砍章节，不砍单句里的限定词**：「相关」不许砍成「导致」、「部分研究提示」不许砍成「研究证明」。

### 工序③ 排版标记（决定成图长什么样）

改写后的正文按脚本的 markdown 契约打标记（§3）。三条实操要点：

- **段落要短**：3–5 行一段（渲染后约 60–110 字），段间空行。**大段密文是这条路线的头号丑因**。
- **金句独立成段并加粗**（`**这样**`）→ 渲染成红色强调句带下划线，一页最多 1–2 处，多了就廉价。
- **对照关系用表格**，别用「A 是…；B 是…」的流水句——表格是这条路线相对轮播图的核心优势。
  表头 ≤6 字（长表头会在窄列里折行，观感差）。

### 工序④ 配首页信息

- `title`：**首页大标题**，就是长文标题（可微调更口语），**≤22 字**，太长会占掉半页。
- 「全文 N 字｜阅读需 M 分钟」由脚本自动算并渲染，不用手写（不想要就传 `--no-meta`）。
- `xhs_id`：页脚水印小红书号。**不确定就别传**——传错号比没有更糟。

## 3. 输入契约（`typeset_longimage.py` 认的 markdown）

```markdown
---
title: 当感受被真正「看见」：什么是有效化（Validation）？
theme: clean          # clean=白底红黑黑体 / paper=淡蓝纸纹衬线
xhs_id: 49398056290   # 可选，页脚水印；不确定就删掉这行
---

正文段落，直接写，不需要缩进标记。

## 二级标题（左侧色条 + 粗体）

### 三级标题（细色条 + 字距拉开）

- 列表项，渲染成 ○ 前缀
- 第二项

**独立成段的加粗句** → 红色强调句 + 下划线

| 场景 | 无效化 | 有效化 |
| --- | --- | --- |
| 你哭了 | 「这有什么好哭的？」 | 「我看到你现在很难过。」 |
```

支持：`##` `###`、段落、`-` 列表、表格、`**行内加粗**`、`` `代码` ``。
**不支持**（写了会被当普通文字）：图片、引用块 `>`、多级嵌套列表、水平线。

⚠️ **引号统一用中文全角**（`「」` 或 `""`）——直角引号 `"` 在成图上难看且与样本不符。

## 4. 出图

```bash
python3 {SKILL_DIR}/scripts/typeset_longimage.py --md {note_dir}/body.md \
    --out {note_dir}/images --style {note_dir}/_shared/style-typeset.json
```

| 参数 | 说明 |
|---|---|
| `--style <json>` | **运营「文字版」那套风格档案，每批必传**（= 开跑前 `style_profile.py --get --kind typeset` 落盘的那份，**整份直接喂，脚本自己剥外层**）。其 `typeset` 段覆盖主题默认值，`null` 的字段不覆盖。⚠️ 他还没有这套（`profile: null`）→ **整个参数别传**，按内置默认出图；喂一份 `null` 进来会直接报错 |
| `--theme clean\|paper` | 覆盖 frontmatter 的主题。⛔ **别每批写死**——它优先级**高于风格档案**（CLI > 档案 > frontmatter > 默认 `clean`），写死会把档案里的 `paper` 盖掉；只有运营临时点名换主题的那一批才传 |
| `--title` / `--xhs-id` | 覆盖 frontmatter |
| `--no-meta` | 不渲染「全文N字｜阅读需M分钟」行 |
| `--max-pages N` | 页数上限（默认 30），超限报错而不是闷头出 40 张 |
| `--html-only` | 只产 HTML 不截图（本机没装 playwright 时的降级出口）。⚠️ **不跑任何闸门**，挂了 `--counselor` 时不能拿它验收 |
| `--counselor EMP_NO` | 末页追加一页咨询师推介（可选）。**口径见 §8，别只按本表传** |
| `--counselor-headline` | 推介卡主标题（三要素，结合本文主题）。不传→机械兜底 + warning |
| `--counselor-blurb` | 针对性推介文案。不传→退回官网通用介绍 + warning |

⚠️ 挂了 `--counselor` 时**总页数 = 正文页数 + 1**（推介页是最后一张）。

输出 `P01.png…PNN.png`（**1080×1920 = 9:16 手机全屏**）+ `_typeset.html` + 一份 JSON（`pages` / `chars` / `files`）。

**分页行为（脚本保证，不用人管）**：

- ✅ **正文允许跨页断句**——一段的后半截落到下一页是**正常的**（参考样本就是这样），别去凑整。
- ✅ **绝不从半行中间横切**：切点只落在行盒底边。
- ✅ **标题不孤行**：标题要么整体进下一页，要么至少带一行正文。
- ✅ **表格不腰斩**：整表放不下就整体挪到下一页。
- 页底留白是切点约束的**正常结果**，不是 bug；中间页留白超过半页才需要回头看是不是有个超大表格。
- **最后一页留白很大是正常的**（内容不足一页），不用为了填满硬加字。

**两套主题怎么选**：

| | `clean`（白底红黑黑体） | `paper`（淡蓝纸纹衬线） |
|---|---|---|
| 观感 | 干净、锐利、专业 | 安静、纸感、慢 |
| 适合 | 有表格 / 有分级清单 / 概念辨析 | 叙事性、体验性、疗愈向 |
| 段落 | 不缩进，靠空行分段 | 首行缩进两字，段间距小 |
| 表格 | 好看 | 能用，但不是它的强项 |

**主题跟运营的风格档案走**：档案里写了偏好就用档案的（**靠 `--style` 生效，不传就没生效**）；
没写就按上表按内容选，并在 `00-overview.md` 里说明选了哪套、为什么。
⛔ **同一个号别一会儿 clean 一会儿 paper**——调性会散。

## 5. 小红书正文（路线②专用，**不是** 300 字三段式）

老板定案：**「就写引言，简短介绍，SEO 钩子标签」**。因为内容全在图里，正文的唯一任务是
**把人骗进图里**，不是自己讲一遍。

结构（**总量 120–200 字**，比路线①的 300 字短得多）：

```
① 引言（2–3 句，场景钩子）
   ——读者对号入座的那个具体处境，跟路线①的开头同一个写法，但更短。

② 简短介绍（2–3 句）
   ——这篇文字版讲了什么、读完能拿到什么。可以带一句「全文 2890 字，慢慢看」。

③ 危机声明（一行，照旧不可省）

④ 可见标签行 #标签1 #标签2 …（5–10 个）
```

- **标题**：口径与路线① **完全一致**——≤20 字，前 10 字内出现目标长尾词
  （见 `xiaohongshu-spec.md` §1）。**这条不因走路线②而放松**：标题仍是唯一搜索入口。
- **SEO 钩子标签**：5–10 个，必含目标长尾词。文字版里的正文**不被平台索引**（图里的字搜不到），
  所以路线② 的标签比路线① **更重要**——它和标题是这条笔记全部的可搜索面。
- ⛔ **正文里别复述图里的干货**：读者会觉得"看完正文就够了"而不点图，完读率与收藏率一起掉。
- ⛔ **emoji**：图里 **0 个**（参考样本零 emoji，加了就毁调性）；正文里 **3–6 个**温和款
  （比路线①的 8–14 少——正文短，密度不能按同一比例套）。
- 三段式骨架的 **G1 最低出口律照旧适用**：正文或文字版末尾至少给一个今天能做的小动作。

## 6. 与既有规格的关系（**审查端按这一节判，别拿路线①的尺子量路线②**）

| 既有规格 | 路线② 适用性 |
|---|---|
| 密度五字段（`信息密度档位`/`每页文字量`/…） | **不适用**。`00-overview.md` 里这五个字段写 `路线②（文字版，密度由排版决定）`，审查端见到这行**跳过密度判据**。硬拿 200–400 字/页去量文字版 = 100% 假 FAIL |
| 风格档案 `profile.visual.palette` / `character_card` | **部分适用**：文字版没有插画、没有人物卡，**只有主题选择**跟档案走。留痕行**照写不误** |
| 页数 6–9 | **不适用**，页数由字数决定。`count_xhs.py` 的 `--page-min/--page-max` 对路线② **不要跑** |
| 正文 300 字 / `count_xhs.py` 字数区间 210–450 | **不适用**，路线② 是 120–200 字（§5）。跑 `count_xhs.py` 会报 `ok_body=false`，**这是预期结果**，只核 `title_chars ≤20` |
| 合规扫描 `check_compliance.py` | **完全适用，一条不降**。极限词 / 医疗词 / 站外导流 / 危机声明照扫。⚠️ 文字版正文是整篇长文，**违禁词命中面比 300 字正文大得多**，必须扫**正文 md 本身**而不只是发布文案 |
| 三条铁律（不新增未验证事实 / 合规红线 / 双轨发布） | **完全适用** |
| 红线三层（法律执业级 F1·G5、平台封号级） | **完全适用，不可覆盖** |

## 7. 系列篇（长文 >3500 字走这条，2026-07-28 老板定案）

> 老板原话：「一个长文可以根据字数拆成好几篇 2000 字左右短文，分上中下，或者一二三四，系列篇。」

参考样本 B 本身就是系列篇的第二篇——它的首句是「上一篇我们聊到了「无效化环境」」。
**系列不是把长文切开发三次，是三条各自成立、又互相牵引的笔记。**

### 7.1 拆

```bash
python3 {SKILL_DIR}/scripts/split_longform.py --md {note_dir}/body.md --target 2000
```

| 参数 | 说明 |
|---|---|
| `--target N` | 每篇目标字数，默认 2000。**口径与图上「全文N字」一致**（含标点） |
| `--parts N` | 强制篇数（不给则按 target 自动定，篇数不会多过章节数） |
| `--out DIR` | 输出目录，默认与 `--md` 同级 |

产出 `body-01.md … body-NN.md`，各自带好 frontmatter（含 `series_index` / `series_total`）。

**切点永远落在 H2 边界上**——字数只用来决定"在哪几个 H2 上切"，绝不从章节中间劈。
一个章节被劈成两半，读者两篇都读不懂。分组用动态规划求全局最优均衡，各篇尽量一样厚；
剩下的不均来自章节本身的原子性（章节不可再切），**不是脚本没做好**。
报告里 `warnings` 提示某篇明显超目标时，办法是**回头把那个超长 H2 拆成两个 H2**，再重跑。

### 7.2 编号与标题

| 篇数 | 标记 |
|---|---|
| 2 篇 | 上 / 下 |
| 3 篇 | 上 / 中 / 下 |
| ≥4 篇 | 一 / 二 / 三 / 四… |

标题 = `{原标题}（上）`。⚠️ **20 字硬限含标记**——原标题 18 字加上「（上）」就超了，
脚本会在 `warnings` 里报，**必须回头改短原标题**，不能放着不管。

首页副信息行自动变成「全文1726字｜阅读需5分钟｜系列 2/2」，读者一眼知道这是第几篇、共几篇。

### 7.3 承接段与预告段（**脚本不写，你写**）

`split_longform.py` 在第 2 篇起的开头、和最后一篇之前的每篇结尾，各埋一个 `<!-- TODO -->` 占位：

- **承接段**（每篇开头，第 1 篇除外）：一两句话说清上一篇讲到哪儿了，再引出这一篇。
  照抄参考样本的写法：「上一篇我们聊到了「无效化环境」——…今天这篇要聊聊「无效化」的另一面。」
- **预告段**（每篇结尾，最后一篇除外）：一句话说下一篇讲什么，给个往下追的理由。

⛔ **`typeset_longimage.py` 遇到未填的 TODO 直接报错退出**，出不了图——这是硬闸门，
因为没有承接段的系列篇，读者根本不知道自己捡到的是第几篇。

### 7.4 发布

- **每篇是独立笔记**：各有各的标题、正文（§5 那套引言 + 简短介绍 + 标签）、危机声明、5–10 个标签。
- **加一个系列标签**贯穿全系列（如 `#不敢拒绝别人`），读者点标签能追齐；这个标签**每篇都要有**。
- **正文里点名系列位置**：开头一句「这是「XXX」系列的第 2 篇」，末尾一句「下一篇聊…」。
  评论区置顶下一篇链接是运营动作，**不写进正文**（站外导流红线只管站外，站内笔记链接安全，
  但正文塞链接观感差）。
- **发布节奏**：**隔 1–2 天发一篇**，别同一天发完。同日连发会互相抢流量，
  且系列的价值本来就在"追更"。运营另有安排就听运营的。

## 8. 末页咨询师推介（可选；**针对性推介**，2026-07-28 老板定案）

> 老板原话：「末页推介卡标题改成咨询师介绍里的那种标题，**谁，做什么，解决什么问题**」
> 「这就算一个针对性的推介了，**需要结合文本内容**来写推介标题与内容」
> 「需要说明**为啥这个咨询师能陪来访解决这类问题，他怎么擅长了**」

### 8.0 定位：这一页不是名片，是**桥**

读者刚读完七八页讲某个具体困扰的文字版，翻到最后一页。这一页要回答的是**这一个问题**：

> **「刚才这篇讲的问题，为什么是这个人能陪我一起看？」**

所以这一页 = **「本文的问题」×「这位咨询师的对口能力」的桥接**。
标题与文案**都必须扣着本文主题写**，一篇一版，**不能跨篇复用**。

⛔ **通用介绍 = 没按要求做，直接返工**。以下三种都算通用介绍：

| 反模式 | 长什么样 | 为什么不行 |
|---|---|---|
| **不传参数** | 直接 `--counselor EMP…` 就完事 | 退回官网 `introduction` 通用文案 + 机械兜底标题，脚本会 warning。**warning 不是提示，是返工信号** |
| **抄官网 introduction** | 把「专攻复杂性创伤循证干预，擅长 EMDR…」原样贴进 `--counselor-blurb` | 那是给官网访客看的自我介绍，跟本文讲什么毫无关系——等于没写 |
| **换汤不换药** | 每篇都用他那条站内表现最好的通用标题 | 见 8.2 反例：好标题 ≠ 对这篇好 |

**桥怎么搭（三步，缺一步桥就断）**：

1. **读本文**——这篇文字版讲的是**谁的什么困扰**？把那个困扰词拎出来（本文示例 = 「不敢拒绝 / 讨好」）。
2. **读 `fetch_counselor.py --emp` 输出**——他的 `methods` / `philosophy` / `specialties` 里，
   **哪一条正对着这个困扰**？找到**具体的落点**（方法名、风格标签、擅长条目），不是"他很专业"。
3. **把两头接上**——标题写困扰词，文案说清"他的哪个做法，怎么对得上本文说的那件事"。
   接不上就**别硬接**（见 8.5 选人判据）。

### 8.1 命令行

```bash
python3 {SKILL_DIR}/scripts/typeset_longimage.py --md body.md --out images \
    --style {note_dir}/_shared/style-typeset.json \
    --counselor EMP20260114002 \
    --counselor-headline "心理咨询师-李宇，陪你练习开口拒绝" \
    --counselor-blurb "（按 8.3 写的三段针对性文案）"
```

| 参数 | 不传会怎样 |
|---|---|
| `--counselor EMP_NO` | 不追加推介页（这一页本就是可选的） |
| `--counselor-headline` | **退回机械兜底**「心理咨询师-{姓名}，陪你面对{第一条擅长方向}」+ **warning**。合规但平淡，且跟本文主题无关 |
| `--counselor-blurb` | **退回官网 `introduction`** + **warning**。那是通用自我介绍，不是针对性推介 |

⚠️ **两条 warning 出现任意一条 = 这一页没做到位**，回去补参数重出，别把带 warning 的产物交出去。

⚠️ **`--html-only` 不能用来验收这一页**：它提前退出，**不产出 warnings、也不跑推介卡溢出检查**
（输出 JSON 里压根没有 `warnings` 字段）。挂了 `--counselor` 就必须走完整出图，
别拿那条降级路径上的 `ok:true` 打勾。

成图内容：系统头像 + **标题**（`--counselor-headline`）+ 职称 + 专长药丸 + **推介文案**（`--counselor-blurb`）
+ 品牌行。**不含危机声明**（G6，见 8.6）。
⚠️ **专长药丸是脚本自动全量拼的**（把 `specialties` 的 `title` 用 `·` 连起来，你控制不了）——
所以"针对性"**全靠标题与文案两处承载**，别指望药丸帮你聚焦。

### 8.2 标题怎么写

**结构完全沿用 `counselor-note-spec.md` §1「发布标题三要素」**（姓名 + 能力 + 来访画像，
`心理咨询师-{姓名}，{陪你/带你 + 能力动词短语（嵌困扰词）}`）——那一节的三要素定义、
硬约束、站内数据、正反例**全部适用，不在这里重抄**，写之前去读一遍。

本节只补**路线② 末页卡的差异**，就一条：

> 🔑 **困扰词必须扣本文主题，不是扣他最出名的方向。**
> 三要素里的「来访画像」在推介笔记里可以取他的主打议题；但在**这一页**，画像的唯一合法来源是
> **这篇文字版讲的那个困扰**——因为读者是带着刚读完的问题翻到这一页的。

**长度**：目标 **≤20 字**（与发布标题同口径）。脚本 `>24 字` 才报 warning，
⛔ **别把 24 当目标**——卡片上超过 20 字就要折行，观感掉一档。

**✅ 好例**（本文 `body-02.md`「为什么我总是不敢拒绝别人？（下）」× 李宇 EMP20260114002）：

```text
心理咨询师-李宇，陪你练习开口拒绝        （17 字）
```

- 姓名 ✓「心理咨询师-李宇」（直呼其名，无「老师」）
- 能力 ✓「陪你练习开口拒绝」——出处：`methods` 图式疗法「通过新体验修复内在受伤部分，
  改善人际关系与自我评价」＋ `philosophy.styles` 「温暖坚定：在提供安全抱持环境的同时，
  保持专业的边界与引导力度」
- 画像 ✓「开口拒绝」——**正是本文的困扰词**，读者刚读完 9 页讲这个的文字版

**❌ 反例（最要命的那种：好标题，但不针对这篇）**：

```text
心理咨询师-李宇，陪你整合创伤与秩序      （18 字）
```

这条本身是**站内表现最好的推介标题**（1982 views，见 `counselor-note-spec.md` §1.3），
三要素齐全、出处也真实（`specialties` 确有「创伤应激」）。**但挂在这篇后面就是错的**——
读者读了一整篇「不敢拒绝」，翻到末页看见「整合创伤与秩序」，**桥断了**，
这一页从"原来是他能陪我看这件事"退化成"这是一张广告"。

> **判据一句话**：把标题里的困扰词，拿去和本文标题比一比——**对不上就是通用推介，返工。**

### 8.3 文案（`--counselor-blurb`）怎么写

**三段，总量 140–200 字**（上限是脚本的渲染余量，超了会报错，见 8.4）：

> ⚠️ **「三段」是写作结构，不是版面结构**。成图上它渲染成**一整块连续文字**——
> 卡片里的文案容器没开 `white-space`，你写的换行会被 CSS 折叠掉。所以：
> **别在文案里排空行**、别指望留白帮你分段，段与段必须靠**句子自身**衔接得读得通。
> 目标 **170–190 字**留渲染余量：专长药丸是脚本按 `specialties` 全量拼的，长度你控制不了，
> 卡到 200 字上限时它一变就可能触发溢出报错。

| 段 | 写什么 | 判据 |
|---|---|---|
| **① 接住本文的问题**（1–2 句） | 用本文读者刚建立的那个认识收个尾，把他**卡住的那一点**说出来 | 说的是**本文里的困扰**，不是"你是不是也常常……"的泛化开场 |
| **② 他的方法具体怎么对得上**（核心，占大半） | **点名方法/风格**（图式疗法、情绪障碍 UP、温暖坚定…）＋ 用一句话说清**这个方法在处理什么**，并**把它和本文说过的那件事对上** | **每个断言指到 `--emp` 输出的具体字段**；⛔ 只说"他很擅长这类问题"＝没写 |
| **③ 克制邀请**（1 句） | 怎么开始的**陈述句**：「目前接受预约」「主页可查预约方式」 | ⛔ 不催不促（「立即预约」「私信我」「限时」是投流拒审词）；⛔ 不承诺结果 |

⛔ **空话清单（出现即返工）**：「经验丰富」「专业可靠」「值得信赖」「用心倾听」「资深」
「懂你」「帮你走出困境」——这些词**不携带任何信息**，读者见过一万次。
**判据：把咨询师姓名换成任何一个别人，这段话还成立吗？成立 = 这段是废话，重写。**

**✅ 好例**（同上组合，198 字）：

```text
你可能已经看清了这套机制，但真到要开口的那一刻，那句「不」还是出不来。

李宇的工作方法里有图式疗法：探索早年经历怎么形成了今天这套固定模式，再通过新的关系
体验去修复。他也用情绪障碍UP，针对的正是「减少情绪回避」这类应对方式——本文说的
「把自己撤出现场」就是它。他自述的风格是温暖坚定：给安全的抱持，同时保持边界与引导力度。

本文最后说，改写靠的是新的关系经验——他工作的落点也在这里。目前接受预约。
```

**逐句出处核对**——**双向都要核，且必须落盘**：

> 这张表是"不编造"这条红线的**唯一执行闸门**，写在对话里等于没有。
> **落到 `{note_dir}/promo-sources.md`**（或 `00-overview.md` 的「末页推介」小节），
> 审查端按文件核；没有这张表，这一页不算完。
>
> 两列都要有，**只核咨询师那一侧是不够的**：
> - **咨询师侧**：每个关于他的断言 → `fetch_counselor.py --emp` 的**具体字段**
> - **本文侧**：每个"本文说的…"→ 本篇 `body.md` 的**行号**
>
> ⚠️ 漏核本文侧是**实际发生过的事故**：曾有一版把标题的画像词建立在「本文两次用『人际图式』
> 框定不敢拒绝」上——`grep` 实测本篇里「人际图式」出现 **0 次**，那两次在**系列上篇**。
> 跨篇取证 = 读者翻到末页撞见一个自己从没见过的术语，桥直接断。
> **指不到本篇行号的说法，一律不许进标题和文案。**

| 文案里的断言 | 出处（`fetch_counselor.py --emp EMP20260114002`） |
|---|---|
| 「有图式疗法：探索早年经历怎么形成了今天这套固定模式，再通过新的关系体验去修复」 | `profile_sections.methods` → `图式疗法`：「探索早年经历对当前固定心理模式的影响，通过新体验修复内在受伤部分」 |
| 「情绪障碍UP，针对的正是『减少情绪回避』」 | `profile_sections.methods` → `情绪障碍UP`：「减少情绪回避，建立灵活健康的应对方式」（**用后台原名「情绪障碍UP」，不擅自展开成「统一方案」**） |
| 「温暖坚定：给安全的抱持，同时保持边界与引导力度」 | `profile_sections.philosophy.styles` → `温暖坚定`：「在提供安全抱持环境的同时，保持专业的边界与引导力度」 |
| 「本文最后说，改写靠的是新的关系经验」 | **本文正文**：「图式不是靠明白改写的，它靠新的关系经验改写」——桥的另一头 |

注意这个例子里**桥接得最漂亮的一处**：本文结尾那句「图式不是靠明白改写的，它靠新的关系经验改写」
与李宇后台的「图式疗法 · 通过新体验修复」**几乎逐字对得上**。
**先找这种硬对应**，找到了这一页就自己写完了；找不到硬对应、只能靠形容词硬凑，
说明这篇挂他本来就勉强（见 8.5）。

### 8.4 素材只能来自 `fetch_counselor.py`

**取数复用 `fetch_counselor.py`，不另起口径**；姓名/职称/专长/头像全部来自官网公开资料。
⛔ **不编造任何咨询师信息**（铁律 1 在这一页同样适用）——**每一个断言都要能指到字段**，
指不到就删掉，不要"合理推测"。

| 字段 | 适合写进推介的什么位置 | 注意 |
|---|---|---|
| `profile_sections.methods`（name + desc） | **段②的主力**。方法名 = 具体落点，`desc` 直接给了"这个方法在处理什么" | 用**后台原名**（「情绪障碍UP」「聚焦创伤CBT」），别自行展开/翻译成更学术的说法 |
| `profile_sections.philosophy`（`styles` / `keywords` / `description`） | 段②补一句**他怎么在场**（「温暖坚定」「资源取向」） | 这是**他自述的风格**，写的时候带上「他自述的风格是…」，别写成客观评价 |
| `profile_sections.specialties`（title + desc） | 确认本文议题**在不在他的范围内**；`desc` 可给画像措辞 | 药丸已自动全量渲染，段②**别再复述一遍列表** |
| `profile_sections.experience`（`credentials` / `hours` / `work_history`） | 需要一句可信度锚点时用（「个体咨询 700+ 小时」） | **按后台事实原样**，⛔ 不升格（后台「中级心理治疗师」就不写「资深专家/权威」）；`hours` 是累计值，别换算成年限 |
| `profile_sections.training` | 段②里说明**某个方法是系统受训来的**（「2024 复杂创伤的 EMDR 微处理技术与程序培训」） | 培训 ≠ 资质，别把受训经历写成认证头衔 |
| `profile_sections.testimonials`（`peer` / `supervisor` / `client`） | **默认不用**。同行/督导评价属第三方评语，放进营销物料要走 G5 案例三律 | `client` 为空时更别编；引用前须运营确认可对外，一页 140–200 字通常也放不下 |
| `unsupported` | **不写进文案**，用来做**选人判据**（见 8.5） | 这是他明确不接的问题 |
| `title` / `avatar_url` | 脚本自动渲染，不用你写 | — |

### 8.5 红线（违反即作废）

1. ⛔ **不编造**：每个断言指到 `--emp` 输出的具体字段（逐句核对表见 8.3）。经历、疗效、案例、
   来访反馈，一个字都不许新增。
2. ⛔ **不承诺疗效**：禁「治愈 / 根治 / 一定 / 彻底 / 保证」；禁用医疗用语自我描述
   （治疗 / 诊断 / 患者）——**心理咨询不是医疗行为**。
3. ⛔ **不暗示"找他就能解决"**：只能说明**他的方法与这类困扰对得上**，不能说他能解决它。
   写法差别：「他的方法针对的正是这类模式」✅ ／「找他就能不再讨好」❌。
4. ⛔ **不加「老师」**：一律直呼其名（「心理咨询师-李宇」「李宇」），
   不写「李宇老师」（脚本 `check_headline` 会扫标题，但**文案里的「老师」脚本扫不到**，靠你自己）。
5. ⛔ **不升格**：后台写「中级心理治疗师」就只能这么写，不许写成「资深专家 / 权威 / 顶尖」。
6. ⛔ **默认不放价格**：小红书对价格敏感，一放整页就从"介绍人"变成"卖服务"。
   运营明确要求才写进 `--counselor-blurb`，且只能用实时值。
7. 🔴 **只给 `is_accepting=true` 的咨询师做这一页**：停单的人**引来了约不上**，体验最差
   （与 `counselor-note-spec.md` §6.2 同口径）。脚本已加硬闸门——`is_accepting=false` 直接报错、
   出不了图，别去绕它，换人或本篇不挂推介。
8. 🔴 **`unsupported` 是选人判据，不是文案素材**：
   > **本文主题若落在他的 `unsupported` 里，这一页就不该挂他——换人，或这篇不挂推介。**

   李宇的 `unsupported` = 「神经发育类问题（如注意力缺陷障碍）、精神病性症状（如幻觉、妄想）、
   自杀高风险（近1年内有自杀行为或计划）、物质依赖（如酗酒）」。
   所以一篇讲 ADHD 或讲成瘾的文字版，**再怎么会写标题也不能挂他**——把读者导向一个明确说了
   自己不接这类问题的人，是实打实的伤害，也会在预约环节被退回。
   **本文（不敢拒绝 / 讨好）不在其中，且正对 `methods` 的图式疗法 → 可挂。**

   ⚠️ 边界情况：本文议题**部分**触及 `unsupported`（如讲情绪困扰但顺带提了自伤）→
   **问运营**，别自己判。
9. 🔴 **找不到硬对应，也是选人判据**：本文主题不在 `unsupported` 里 **≠** 就能挂他。
   在 `methods` / `philosophy` / `specialties` 里**找不到一条正对本文困扰的落点**时，
   ⛔ **别用形容词硬凑**（"经验丰富、贴合你的困扰"就是硬凑）——回去问运营，给三个选项：
   换一位对口的 / 本篇不挂推介 / 运营坚持挂则由运营确认。
   （8.0 第 3 步与 8.3 结尾说的"接不上就别硬接"，指的就是**这一条**，不是第 8 条。）

### 8.6 其余口径（沿用，未变）

- ⛔ **不用 AI 合成这一页**（与路线① 的做法不同）：路线② 整套图都是排版渲染的，
  末页混一张 AI 图，字体、质感、色温全对不上，**风格必裂**。所以推介卡走同一套排版语言——
  同字体、同色系、同版心，是同一份 HTML 里的一层。
- **文案太长会被裁**：脚本渲染前会量，放不下**直接报错**并提示改短 `--counselor-blurb`
  （建议 ≤200 字，与 8.3 的 140–200 同一口径），**绝不静默出一张被裁掉半句话的图**。
- 🔴 **这一页不放危机声明**（2026-07-28 修正，原先放了，是错的）：G6
  （`xiaohongshu-spec.md` §1.5）要求**危机声明与商业 CTA 不同页/不同屏**，而这张卡上有品牌行
  与「目前接受预约」这类 CTA，把 12356 塞在同一页正好踩线。脚本已把它从推介卡移除。
  危机声明的位置是**发布正文**（见 §5），那一份 `check_compliance.py` 照常扫。
- **推介文案会被单独扫一遍违禁词**：脚本出图前把 headline + blurb 落成
  `{out}/promo-draft.md` 再跑 `check_compliance.py --no-crisis`，不过不出图。
  ⚠️ 这一步不能省——`check_compliance.py` 只接受**文件路径**，而这两段文字原本只以命令行字符串
  传入、从不落盘，等于**全套图里商业风险最高的一段（它带 CTA）绕过了违禁词扫描**。
  落盘同时留痕，审查端可直接复核 `promo-draft.md`。
- **选谁**：运营点名就用谁；没点名**别自己挑**——问一句。这一页等于把这条笔记的流量导给某个人，
  是运营的分配决策，不是 agent 的。
  （运营点了名、但本文主题落在那位的 `unsupported` 里 → **回去说明理由再确认**，见 8.5 第 7 条。）
- **系列篇（§7）每篇各写各的**：上/中/下三篇讲的侧重不同，**推介标题与文案要跟着那一篇改**，
  别三篇共用一套——同一位咨询师、三个针对性角度，恰好也让系列读起来不重复。
