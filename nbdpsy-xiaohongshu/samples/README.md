## 只摘了三节

每个文件只保留 **`## 标题` / `## 正文` / `## 话题`** 三节——按 `定稿配文/README.md` 自己的定义：「固定保存用户已确认的小红书标题、正文（含落款）和话题」。原文件里的确认日期行、`## 来源`、发布状态等元数据属于流程记录，不是样本内容，已去掉。**这三节与源文件逐字节一致。**

## 两条注意事项

1. **别把 02 当冒烟测试**。`scripts/check_text.py` 跑 `02-正念帮助我减了20斤.md` 会报一条 FAIL（正文有一句 `**我发现，自己这么急，是想让难受马上消失。**`）。这是**她定稿里真实存在的缺陷**——小红书的正文不渲染 Markdown，发布时加粗符会被剥掉。样本必须逐字保留，⛔ 不许替她改稿。这条正好是判例：我们自己旧 skill 的成品也犯过同一个错。
2. **三篇的体量不构成区间**。426 / 451 / 650 字，段数 6 / 7 / 5。字数是大纲里按篇给的场景化目标，⛔ 不是全局常量；`不要为了凑字数而说废话` 优先级高于任何字数指标。
