# 04 · 配图（画师工序）

> 适用范围：上游（切题 + 写故事）交出脚本之后，到成品图落盘、交给发布工序之前。
> 素材真源：`提取-03-视频制作.md` §2–§9、`提取-06-两侧产物对比.md` §3.11。括号里的 `提取-0X §Y` 是出处。
> 全部「」内为李牧阳原话，逐字未改。⛔ 不许改写措辞、不许润色、不许把判例改写成"建议"。

## 1. 接单契约

### 1.1 你收到的是两层结构，不是一段 prompt

上游交过来的东西长这样（原文照抄）：

> 请为「咨询师的论文」系列创作六张连续阅读的竖版插画，采用统一的极简漫画风格。人物造型、配色和构图由你设计，同一个人物跨页出现时保持一致。文字需要在手机上清楚可读。
>
> 以下“画面要求”供你理解和构思，只有“图中文字”需要出现在成图中。示意人物均为虚构，不是真实参与者或咨询师的肖像。

第二套把它压成一句：

> 通用要求：六张均为竖版 2:3。人物形象、画风和配色由画师确定，第一张定下后，后续保持一致。通过表情、动作和内心对白讲故事，中文清晰，适合手机阅读。只把指定的上图文字写进画面。

**这两段就是接单契约的全部**：页数与画布写死（2:3 竖版），叙事、情绪、图中文字由上游给，形象、构图、配色归你。`画面要求` 只是给你理解用的，**⛔ 一句都不许进图**；`图中文字` 才是唯一允许出现在成图里的东西（`提取-03 §3`）。

⚠️ 她的两套提示词口径不一致过：第一套 base 写 `aspect ratio 3:4`（出图 1086×1448），第二套写 2:3，导致同一套第七张滑动时比例跳一下（`提取-06 §3.8`）。**⛔ 不要照抄这个缺陷**——一套图从第一张到最后一张，画布只用一个比例。

### 1.2 单页脚本的五个槽位

```
**① 封面：对自己好一点，人会废掉吗？**     ← 页码 + 页型 + 页面主题（人读的，不入图）

画面要求：
  <叙事意图 / 主角此刻状态 / 为什么这样画 / 哪几维授权你自由定 / 哪几维不许画>

图中文字：
  > 第一行
  > 第二行

信纸上的字：        ← 特殊介质另开槽位（只写“亲爱的自己：”，其余留白）
页脚小字：          ← 合规/免责小字单列，避免被当成正文
```

五个槽位一个都不能少。缺 `页脚小字`，合规字会被模型并进正文；缺 `信纸上的字`，模型会自己编一段假字迹（`提取-03 §3.1`）。

### 1.3 「画面要求」里会出现六类内容，各自怎么用

| 类 | 原文例 | 你怎么用 |
|---|---|---|
| 主角此刻的状态 | `他已经累了，想对自己宽容一点，但心里马上冒出一句责备` | 翻译成身体姿势，不是表情形容词 |
| 读者该看出什么 | `让读者一眼认出这种纠结` | 这条是**验收判据**，出图后拿它自查 |
| 授权范围 | `具体场景和表现方式由你构思` / `具体动作由你设计` / `周围环境由你安排` / `不必逐一画出全部人数` | 授权的部分自己定，⛔ 不要反过来问上游 |
| 禁止方向（含替代） | `不要用病容、身体标记或刻板外貌表示他们的身份` / `不必把结局画成高兴起来` | 照抄进 prompt 的约束段 |
| 叙事事实 | 28 人、两组、六周、生活质量评价 | 必须画准，⛔ 不得自由发挥 |
| 敏感边界 | `不要画出未经核准的百分比、柱状图或“所有人都变好了”的画面` | 照抄进 prompt，并在出图后逐项核对 |

🔑 **授权 + 禁令 + 读者验收判据**三件套写在同一个 `画面要求` 块里。只给授权 → 跑偏；只给禁令 → 不敢画；没有验收判据 → 出图后无法判"对不对"（`提取-03 §3.2`）。

### 1.4 你不做的事

- **不写配文、不写标题、不改图中文字——一个字都不改**（`提取-03 §2.2`）。
- **不决定"做几张、每张讲什么"**。一张封面 + 四张故事 + 一张海报由战略官定（`提取-03 §2.2`）。她要加页时会明说：`然后第二章和第三张图中间应该有一个过渡吧`——她开口才加，加完要写明这一页承接哪两张（`提取-03 §8.2⑧`）。
- **不发布**。manifest 状态词写死 `…待用户验收；未发布`（`提取-03 §2.1`）。
- **不覆盖历史版本**。不同版本进 `历史版本/vN/`，⛔ 不静默覆盖（`提取-03 §2.2`）。

### 1.5 授权边界

上游只给**几张图 + 每张讲什么**，不给 prompt。具体形象、构图、配色由你定，写完一句回报定案即可。她第二套图没有再问"用哪种风格"，直接开工——因为上一套已经建立了默认风格，且她的原话就是：

> 「可以参考你之前的绘图 那个画风会更好一点」

⇒ **有先例就不问，没先例才定案**（`提取-03 §4` 表下注）。

## 2. prompt 四段式

每张图一个独立代码块（语言标记 `text`），四段，顺序固定。这不是建议格式，是 10/19 之后两套一致的定型结构（`提取-02 §10.2`）。

### 2.1 四段各写什么

| 段 | 内容 | 判据 |
|---|---|---|
| ① 绘制指令 | 张序 + 尺寸/比例 + 承接关系 | 让模型知道这是连续阅读里的第几张，不是一张独立海报 |
| ② 画面要求 | 情境与情绪，允许画师发挥；含**关系明确化**（`Two visually distinct THOUGHT bubbles both clearly originate from this SAME man` + `No second speaking person, no cruel outside critic`，防读者误以为有人在骂他）与**分区比例**（`Top third strong large headline, middle thought bubbles, lower half substantial clean illustration`） | 写"他纠结时身体是什么样"，⛔ 不写"他很纠结"；版面靠比例声明，⛔ 不写"排版好看点" |
| ③ 上图文字 | 逐条 `标签："原文"` | 逐字，⛔ 不缩写、不概括 |
| ④ 约束句 | 字号 / 可否分行 / 不画什么 / 不提前揭示什么 | 负向为主；纯否定模型不理，要给"不画 A，画 B"的替代 |

### 2.2 逐字样例 A（中文，`mied-squash-6000/绘图-prompts.md` 第 1 张全文）

```text
绘制竖版 2:3 漫画封面，标题完整保留"花6000块学打球，我却开始装忙"。

主角坐在家里，买来的壁球拍、球包和小黑球就在身边，手机却成为视线中心：壁球社团正在约球，主角停在输入框里，输入"最近有点忙"。让读者同时看见手边的装备和手机上的推辞，产生"钱都交了，为什么不去"的好奇。

上图文字：
标题："花6000块学打球，我却开始装忙"
手机群名："壁球社团"
收到的消息："这周有人来打壁球吗？"
输入框中的文字："最近有点忙"
角落标注："故事演绎"

标题醒目，"故事演绎"字号较小但清楚可读。手机文字应放大到能看清，输入框保留正在编辑的状态，不画成已发送。封面不解释退出原因或介绍 MIED。
```

对齐看：第 1 段 = ①；第 2 段 = ②（连"读者该产生什么好奇"都写进去了）；`上图文字` 块 = ③；最后一段 = ④（字号 + 编辑态 + 不提前解释）。

### 2.3 逐字样例 B（英文，PAGE 1 COVER 全文）

```text
PAGE 1 COVER. A quiet domestic room with a low couch. The protagonist has paused at its
edge, exhausted from an open laptop on a small nearby desk. He leans toward sitting back
but remains tense, one hand still braced on the seat, as if relaxing is a transgression.
Two visually distinct THOUGHT bubbles both clearly originate from this SAME man: a soft
round ivory/sage thought bubble expressing rest, and an angular pale brick-colored
intrusive thought bubble expressing self-blame. No second speaking person, no cruel
outside critic. The scene must convey ambivalence, not answer the title or resolve the
anxiety. Top third strong large headline, middle thought bubbles, lower half substantial
clean illustration. Exact visible text:
Headline: 对自己好一点，人会废掉吗？
Soft thought: “我想歇一会儿。”
Angular intrusive thought: “你就是这样一点点废掉的。”
No other text.
```

### 2.4 base 块五段（同一个人、同一个世界）

逐页 prompt = `base + "\n" + 单页段`。base 五段，缺一段就漂（`提取-03 §5.2`）：

1. **用例 + 画布 + 画风大类**：`Use case: illustration-story. Create one finished portrait page of a six-page Chinese minimal comic carousel, aspect ratio 3:4, high resolution, flat printed editorial illustration.` ← 先说清"这是一套里的第几张"（⚠️ 这段原文写的是 `aspect ratio 3:4`，属**第一套**口径；按 §1.1 一套图只用一个比例，本 skill 取 2:3，⛔ 别把这行照抄成 3:4）
2. **配色线条**：`Warm ivory background #F7F2E8, near-black charcoal clean slightly hand-drawn outlines, muted sage green #899C87 and restrained brick red #B66F5B, tiny ochre accents.` ← 配色给 hex，负面词紧跟正面词（`flat colors, no gradients, no photorealism, no 3D`）
3. **人物卡**：年龄 / 发型 / 脸型 / **眼型** / 无配饰 / 固定服装 / 体型，末尾必带 `NOT a real person's likeness`
4. **中文排版**：`Chinese typography must be impeccable simplified Chinese, large dark high-contrast clear editorial sans-serif, comfortable line spacing, entire copy legible on mobile. Headline large bold with intentional line breaks. Reserve generous space for the provided text, do not crowd it.` ← 简体无衬线 / 对比度 / 行距 / 手机可读 / 主动断行 / 预留空间
5. **文字唯一性**：见下，最硬的一段

第 ⑤ 段原文（整段照抄，别省）：

```text
Render ONLY the specified visible text, no extra branding, numbering, labels, captions,
speech, symbols as text, or watermarks. All text exactly as supplied, not paraphrased.
Do not put layout instructions in the image.
```

最后那句 `Do not put layout instructions in the image` 是防"Headline:"、"Upper third" 这类结构性说明被画进图——**没有这句，前面所有分区描述都会变成图上的字**（`提取-03 §5.2`）。

### 2.5 每页必须写死的五类约束（`提取-03 §5.4`，从其 14 次调用里归纳）

1. **只出现指定文字**：`Only exact visible text` / `No other text`
2. **每段只出现一次**：`each block shown once` / `Do not copy cover headline`
3. **人物一致性锚**：`SAME woman, hair, blue cardigan, dining table and noodles/dumplings as reference`
4. **不能用替代手法蒙混**：`No spiritual glow, magic, radiant halo or instant serenity` / `no devil/angel characters` / `no before-after body`
5. **合规事实不得越界**：`neither miracle recovery nor stopping medication` / `do not draw all 28` / `no percentage or chart`

## 3. 一致性五层

缺一层就会漂（`提取-03 §7`）。

| 层 | 机制 | 做法（原文） |
|---|---|---|
| L1 | 同一段 base 文本 | 每页 `base + 单页段`，⛔ 不是各写各的 |
| L2 | 首图锚 | 第 1 张独立生成、**不带参考图**，定人物与画风；第 2–N 张 `referenced_image_paths:[首图]` |
| L3 | 参考图分工声明 | `Use supplied reference only to keep consistent fictional character design and overall printed comic aesthetic; no copying the cover's text into this new page.` 以及 `Reference image is for character identity, linework, palette and typography only; create a completely DIFFERENT page layout.` |
| L4 | 跨套复用已验收成品 | 新系列同时喂「上一套已验收的角色图」+「本套封面的大字排版图」，逐张说明取哪一维 |
| L5 | 局部编辑协议 | 带被改图作参考，`Precisely edit the supplied finished Chinese comic page. ONLY adjust …` → 逐项 `Preserve …` → `This is a small … correction, NOT a redesign.`；落盘后其余页 `sha256` 校验未变 |

### 3.1 L4 的真正答案：参考图资产，不是文字描述

她的原话（10-19 11:24）：

> 「可以参考你之前的绘图 那个画风会更好一点」

> 🔑 **跨篇一致性的真正答案不是文字描述，是把已验收的成品当参考图资产。** 风格卡写十句，不如把上一套验收过的 `01.png` 喂进去（`提取-03 §7`）。⇒ **框架必须留的机制**：每套通过验收的成品图，要沉淀成下一套的 L4 输入。⛔ 不要每次从零写风格描述。

### 3.2 多参考图必须逐张声明"取哪一维"

这是重画第二套时的关键手法（两张参考图），原文：

```text
Input image 1 is the STYLE reference: use its simpler cartoon male drawing, flat colors
and restrained linework (but wear dusty-blue shirt). Image 2 is ONLY the approved big
headline typography reference: retain the huge dark-brown/orange headline and its
wording; DISCARD its woman, realism, food and detailed background.
```

> 🔑 一张参考图 + 一句 `same style` = 模型把你不想抄的也抄了。**参考图必须编号，并逐张写"取什么、丢什么"**（`提取-03 §5.5`）。

### 3.3 一致 ≠ 每页完全一样

她要求过：

> 「第二张图的人要比别的图里的小人胖一点」

⇒ 体型、表情、动作可以按叙事需要单张调整，但**必须由脚本显式指定**，画师不得自行漂移；prompt 里写量化（`approximately 10 percent rounder`）+ 否决夸张（`NOT a caricature of obesity, no huge belly, no double-chin`）（`提取-03 §7`、§8.2⑦）。

### 3.4 出图出口：本 skill 只产 prompt，不产图

到「把 prompt 变成成品 PNG」这一步，本 skill 的职责就结束了。**这里没有任何生图工具、模型名或命令**；§3 的 `referenced_image_paths:[首图]` 只是某个出图工具的参数写法，不是通用入口。出图是下游工序，按下面的顺序找出路：

1. **宿主自带生图**（Codex、带图像能力的 agent）：把 §2 的每个 `text` 代码块原样喂进去，一次一张。
2. **本仓已有的后端出图能力**（旧 skill 保留的脚本，仍在）：先看有没有——

   ```bash
   ls ~/.claude/skills/nbdpsy-xiaohongshu-creator/scripts/ | grep -i gen
   ```

   有 `gen_images.py` 就先读 `--help` 再照用：它走后端 gpt-image 锚点法，输入是含 `## 配图轮播`（页标题 `### P1…`）的 `post-NN.md`，`--cover-only` 出封面、`--anchor-url` 锚定其余页。**参数一律以 `--help` 为准**，⛔ 不要凭记忆写。
3. **人工出图**：把 `绘图-prompts.md` 里的代码块整块复制给任意画图模型，按页序存 `01.png`、`02.png`……

**硬要求：第 1 张先出、先验收，后面每一页都把第 1 张当参考图喂进去**（§3 L2）。首图没验收就批量出后面，等于把一处偏差复制 N 份。

## 4. 图内中文 12 条

老大难。以下 12 条是她的实际解法，逐条给原文依据（`提取-03 §6`）。

| # | 规则 | 原文依据 |
|---|---|---|
| 1 | 只画「图中文字」这一层，画面要求一句都不进图 | `以下“画面要求”供你理解和构思，只有“图中文字”需要出现在成图中。` |
| 2 | 每段只出现一次，内页不许复读封面标题 | `each block shown once` / `Do not copy cover headline` |
| 3 | 断行可以，改字不行 | `can break into 2 or 3 lines without changing characters` |
| 4 | 长段落给折行策略，不让模型自己排 | `paragraph broken into 5 to 7 short readable lines without changing any characters` |
| 5 | 字号用"同图内参照物"表达，光给 px 模型不懂 | `EXACTLY the same character height and weight as 八周线上团体 in the panel directly above (approximately 34 pixels tall at 1024px image width)` |
| 6 | 位置给坐标 + 宽度 | `Left-align the phrase at x=132px, approximately y=1350px, on a single line. The phrase should occupy only about 270px width` |
| 7 | 版式比例给百分比，不给"层次分明"这种形容词 | `Top title about 22% height. Largest section is 训练内容 about 44% height … Footer should occupy only about 5% of page` |
| 8 | 空白字段写"不许生成什么"，不是写"留空"两个字 | `不自行生成日期、价格、联系方式、链接或二维码` → prompt 里逐项列出日期/价格/二维码并 `Do not add` |
| 9 | 空白信纸要禁"假字迹" | `no handwriting lines suggesting text, no fictional testimony, no scribbled fake text` |
| 10 | markdown 符号不得上图 | `do NOT include asterisks` |
| 11 | 特殊介质单列（信纸 / 聊天气泡 / 手机屏幕） | `手机用聊天气泡表现正在发送消息即可，不编写朋友回复，不展示真实账号或联系方式` |
| 12 | 出图后逐页核对，不是"生成完就交" | 每轮回复都有"已逐页核对画面文字" |

**失败样本与修法（真实发生）**：海报的"感兴趣的私信"第一版被画成了大标题，原因是它落在"报名信息"面板标题位下、**没有参照物**。修法不是重掷，是给「参照物 + 坐标 + 宽度 + 明确禁大字」四段约束（上表 5/6）。她的原话：

> 「不是这样 报名信息的“感兴趣私信”不要这么明显的大字 改成正常的字体大小 要不然很丑很突兀啊」

**markdown 进图前的剥除**：`>` 引用块、`\` 软换行、`**` 加粗都是**给人看的标记，不是要画上去的字符**。他在改论文署名那页时专门补了一句兜底：`Set AIDS and Behavior in italic if practical, but do NOT include asterisks.`（`提取-03 §3.3`）

**出图后逐页核对**（`提取-03 §11 C`，逐页不是抽查）：
- 文字层：图上文字与脚本逐字相同、一个字不多不少 ／ 没把「画面要求」里的句子画成文字 ／ 无页码·标签·水印·品牌·道具上的字·音效字 ／ 简体无繁体异体、无 markdown 符号（`\` `**` `>` `*`）
- 画面层：遮住文字只看图能读出这一页在讲什么 ／ 这一页的动作与上一页接得上（因果桥） ／ 尺寸与同套其它页完全一致
- 合规层：无未经核准的百分比/图表、无"治愈/停药"、无真人肖像、无前后对比 ／ 该留空的字段真的空（不是被模型自己填了）

## 5. 否决清单 11 条

> 判据：她说"不好/平庸/不喜欢/重写"的地方，比说"好"的地方信息量大得多。
> 她的验收信号极短——整段里只有 `good` 一个词：`good 存进去吧 这个替换第七张图`。**⛔ 不能靠"她说好"来定标准，判准只能来自她否决过什么**（`提取-03 §8.3`）。

### ① 论文只写「Li 等」，读者找不到刘琼

- 她说（提取-03 §8.1①）：「可以 最后一张图稍微改一点点 就是论文列出完整的作者名单和标题 要不然读者一看 Li 是谁？没看到刘琼」
- 不满：引用不完整 + 被推介的人在图上不可辨认。她代入的是读者："Li 是谁？"
- 规则：引用文献必须**全标题 + 全作者（按原序）+ 目标人物中文名并列加粗 + DOI**；⛔ 禁用 `et al.` / "X 等"。
### ② 历史介绍图信息太薄

- 她说（提取-03 §8.1②）：「不要这张图 有没有信息密度更大一点的刘琼介绍图」
- 不满：头像 + 几句卖点式介绍卡，信息密度不足。
- 规则：**咨询师介绍图 = 简历卡不是名片**。必含教育与资质 / 咨询与督导时数 / 系统受训与执业 / 擅长方向；素材优先取历史已产出的完整简历卡，不新造。
### ③ 资质栏不分轻重

- 她说（提取-03 §8.1③）：「这张图稍微改一下 系统受训与执业那里 前两条是加分项 后两条不是 改成整合动力学流派 别的都不用改」
- 不满：把见习、热线接线这类非加分项与外体系受训平铺。
- 规则：**资质只放加分项**，不具加分性的删掉或合并成一个学派标签；`别的都不用改` = 局部编辑，⛔ 不许顺手重排。
### ④ 缺真人职业照

- 她说（提取-03 §8.1④）：「在这张图的最上方再加一个刘琼的职业照 刘琼两个大字的左边吧」
- 不满：顶部只有文字，没有人。
- 规则：介绍图顶部 = 圆形真人职业照（左）+ 姓名大字（中）+ 资质标签（右），同一行；真照片必须身份保真（`Preserve the EXACT real person's face … do not invent or redraw another person, beautify, cartoonize`），且**只用于介绍图，漫画里⛔ 不得凭空绘制真人肖像**。
### ⑤ 太像 AI 画的 / 不够卡通（最关键的一条）

- 她说（提取-03 §8.2⑤）：「我喜欢这个大字的风格 但是不太喜欢1）人物 太像 ai 画的了 主要问题在于可能还不够卡通 这个人物太写实了 可以参考你之前的绘图 那个画风会更好一点 而且学员是一个男的」
- 不满：三件分开——① 人物"太像 AI" ② 大字风格要保留 ③ 主角性别错了。她的诊断路径不是"重画"，是**指明病因（还不够卡通 / 太写实）并给参照物（你之前的绘图）**。
- 规则（反写实参数表，"太像 AI"的唯一可执行解）：

| 维度 | 要 | 不要 |
|---|---|---|
| 头身 | 头略大于身体 | 写实比例 / 幼儿化 |
| 眼 | 实心点状/椭圆眼 | 睫毛、水光眼、动漫大眼 |
| 脸 | 简化椭圆脸、细线鼻、线条嘴 | 立体结构、皮肤渲染、腮红渐变 |
| 阴影 | 极简 | 电影级打光、材质质感 |
| 背景 | 简单轮廓、大量留白 | 散景、写实家具布纹、装饰杂物 |
| 总体 | `flat colors` | `no gradients, no photorealism, no 3D` |
### ⑥ 食物不对，生活细节假

- 她说（提取-03 §8.2⑥）：「谁家好人暴饮暴食是吃饺子面条啊 都是爱吃点什么半熟芝士啦 火锅啦 这个人还爱吃稻香村的糕点 还爱吃黑芝麻糊」
- 不满：模型默认给你**最通用的那碗面**，不是这个人的食物。
- 规则：凡"吃什么/用什么"的细节，必须来自真实当事人（投稿/访谈/公开资料），prompt 里点名到品类（半熟芝士 / 稻香村中式糕点 / 黑芝麻糊 / 火锅），并显式禁掉通用替代（`NO DUMPLINGS, NO NOODLES`）。**通用食物 = 假。**
### ⑦ 体型要按叙事单张调

- 她说（提取-03 §8.2⑦）：「小细节 第二张图的人要比别的图里的小人胖一点」
- 不满：全局一致被理解成了每页一个样。
- 规则：一致性不等于每页相同；体型可单页调整，**但必须脚本指定**，prompt 写量化 + 否决夸张（见 §3.3）。
### ⑧ 页与页之间缺过渡

- 她说（提取-03 §8.2⑧）：「然后第二章和第三张图中间应该有一个过渡吧 就是和正念有点关系 类似这个小人开始观察到第二张图里的念头只是念头 小人开始正念 观念头观呼吸这样」
- 不满：**读者接不上**。上一页在吵架，下一页突然"发现自己急着让难受消失"。
- 规则：相邻两页必须有一条**可指认的动作因果桥**；缺了就**加一页**（页数服从叙事，六张可变七张），新增页要写明它在承接哪两张、补的是哪一步。
### ⑨ 关键动作看不出来（本套最狠的一条）

- 她说（提取-03 §8.2⑨）：「看不出来正念啊 为什么主人公在觉察念头的时候还在吃 而且看上去很困惑 这时候主角的动作应该是开始闭上眼睛正念」
- 不满：**用"内心活动"代替了"身体动作"**。文字说"我在觉察念头"，画面却在吃且皱眉，读者只能读出"困惑的吃货"。
- 规则：凡是页面的核心方法/关键动词，必须用**一个标志性、无歧义的姿态**画出来（正念 = 闭眼 + 双手放腿上 + 食物放到一边；觉察 = 停顿 + 手放胸口）。判据是**「遮住文字只看图，能不能读出这一页在讲什么」**。
- 配套修法（实际改法，不是重画整页）：`CRITICAL CHANGE: The main man in BOTH panels must now visibly be practicing eyes-closed mindfulness, not eating and not looking confused`，并逐条否决错误姿态 `No hand reaching food, no chewing, no holding food, no propping cheek, no puzzled or frowning expression`。
### ⑩ 商业信息不明写

- 她说（提取-03 §8.2⑩）：「最后一张海报还需要调整一下 报名信息你就写感兴趣的私信吧 价格 开营时间什么的不明写」
- 不满：未定的商业信息被模型自己填了。
- 规则：**未定信息一律不写**，用软 CTA 替代，⛔ 不得自行编造日期 / 价格 / 联系方式 / 二维码 / 链接。
### ⑪ CTA 抢了主标题（三轮才收敛）

- 她说（提取-03 §8.2⑪）——第二轮：「不是这样 报名信息的“感兴趣私信”不要这么明显的大字 改成正常的字体大小 要不然很丑很突兀啊」
- 第三轮：「海报还是要调整 你去查一查 MIED 的大纲 把训练内容写的详实一点 报名信息这一栏现在和其他三栏是一样大小 不要一样大小 变成一行小字 但是没有那么小 “感兴趣请私信”这样」
- 不满：**字号过大（丑、突兀）** + **四栏等权（没有主次）**。
- 规则（海报版式三条硬判据）：
  1. 主区块独占最大面积（训练内容 ≈ 44% 高），其余压缩；
  2. CTA = 一行、正文字号、约 32–35px@1024、不占独立面板；
  3. 装饰让位文字：`reduce decorative artwork to a small unobtrusive notebook/leaf, never squeeze text to accommodate pictures`。
- 附带一条方法论：`你去查一查 MIED 的大纲` ⇒ 海报的课程内容必须**查真实公开大纲**再写，不许用三句套话充数；查完在 manifest 留来源与口径限定（"依据公开八周主题归纳为六项…不称逐周原版课表"）。
