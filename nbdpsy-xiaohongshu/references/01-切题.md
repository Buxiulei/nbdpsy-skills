# 01 · 切题（战略官）

> 只管一件事：把「一个产品 / 一个话题」变成**一个让人点进去的角度**，落成标题、大纲、配图规划。
> 正文 → `02-讲故事.md`；审稿 → `03-审稿.md`；prompt → `04-配图.md`。
>
> ⚠️ **工序①的产物必须先落盘**到 `seo-geo/content/xiaohongshu/切题策略/YYYY-MM-DD-主题.md`，再交给工序②。
> 不落盘的话，「退回工序①重切」就没有可退的对象——事后补一份「选题阐释：为什么做这个 / 对谁有帮助 / 如何吸引人」
> 与真做过在证据上完全同形，大纲的因果链就成了事后合理化。路径与字段见 SKILL.md 交付契约。

## 一、定义与总闸门

### 选题是一个角度

2026-09-12 09:24〔原话〕：

> 「不对不对 还是不对 选题是什么？选题是一个角度 或者你可以想象 如果一句话概括 or 起个标题 会是什么标题 什么会让人点进去？」

三条，缺一条不成立：**① 选题 = 角度**，不是主题、不是知识点、不是一篇论文；**② 角度必须能压成一句话 / 一个标题**，压不出来就是还没成形；**③ 压出来以后必须能回答「什么会让人点进去？」**

反用：**写不出一个能让人点进去的标题，就说明这个角度不成立。** 标题不是大纲的附属品，是切题的检验器。

### 总闸门：我为啥要看？

2026-10-19 09:26〔原话 · 这条线最重要的一次否定〕：

> 「这个非常不好 非常的 怎么说 平庸 我觉得首先 如果让我来切题 我可能会写 "正念帮助我减了 20 斤" 然后写一个第一人称视角的故事 你的切题怎么说呢 就是 很平庸 你就在很平铺直叙地讲这个原理 我为啥要看？这有什么吸引人的地方？」

三个判决词：**平庸 / 平铺直叙地讲原理 / 我为啥要看**。她这一轮给的替代方案本身就是方法的形状：**一个具体结果 + 第一人称视角的故事**。

**闸门动作**：任何切题、标题、第一句，先问一遍「我为啥要看？这有什么吸引人的地方？」

- 答「因为讲清了这个原理 / 把机制说明白了」→ **不通过，退回重切**，不要改稿。
- 答「因为 X 和 Y 居然连在一起 / 她居然花了 6000 块学到这个」→ 过。

## 二、切题公式

### 公式

从两个被她接受的正例反推（她没写过公式，但两个都认了）：

**`[我] + [具体金额 / 具体数量] + [具体做过的一件事] + [一个和这件事不相干的结果]`**

- 正例 A：我 + 20 斤 + 练正念 + 减了 20 斤（正念和体重不相干）
- 正例 B：我 + 6000 块 + 学壁球 + 学会了装忙（学球和装忙不相干）

三要素缺一不可：**量化**（斤数 / 钱数，让「变没变」可判断）、**第一人称**（让它变成一段可以追问的经历）、**错位**（两个看似无关的东西被连起来，这一「连」就是全部吸引力）。

第四个要素她没写成字，但两个正例都命中：**羞耻感**——内核必须是「说不出口的那件事」（A 是控制不住吃，B 是花钱买了不去）。

### 正例 A：《正念帮助我减了20斤》〔她主动给出〕

她随后说「你按照这个切题 重新写一份大纲」，10-19 09:30 又补：「这就是一个虚拟的故事 小红书的字数不要太长吧」——**虚构的故事照样能用，但必须标注「故事演绎」（见 `02-讲故事.md`）**。

| 元素 | 值 |
|---|---|
| 人称 | 第一人称「我」 |
| 具体结果 | 减了 20 斤（**结果先行，不是过程先行**） |
| 反差 | 正念 ↔ 体重（两个不相干的东西被连起来） |
| 可追问 | 你以前什么样？做了什么？发生了什么变化？ |
| 情绪落点 | 「我一直在用食物让自己暂时舒服一点」 |

### 正例 B：《我花6000块学壁球，学会了装忙》〔她自己给的标题〕

2026-10-19 11:25〔原话〕：

> 「第一个不错 我的确就是这样的 这个很像我 可以换成打壁球的故事 因为我的确曾经报名打壁球的社团 结果我一直是最差的 我就不去了 报名费也白交了」

agent 原候选是《我花6000块学网球，学会了装忙》——**她换成壁球，并当场补了真实细节**（一直是最差的 / 不去了 / 报名费白交了）。

| 元素 | 值 |
|---|---|
| 人称 | 第一人称「我」 |
| 具体数字 | 6000 块（**钱**） |
| 具体事 | 学壁球（不是抽象的「学一项运动」） |
| 错位 | 花钱学球 → 学会的是「装忙」 |
| 羞耻内核 | 我一直是最差的，我就不去了 |
| 代价 | 报名费白交了 |

### ⚠️ 误读警告：知识密度 ≠ 知识量（最容易复发的错）

10-19 07:06 她说〔原话〕「你会发现很像 ai 写的 前面一开头知识密度太低了 我建议调整策略 重点放在 MIED 会如何帮助减肥 怎么样正念减肥的原理」→ agent 读成「原理讲得不够全」，产出四个机制各一段的原理课 → 09:26 她说「很平庸 你就在很平铺直叙地讲这个原理」。

真病灶：**前三段都在写同一个信息**（想减肥 / 但想吃 / 吃完自责），一句话能说完的事铺了三段。她要的是**每段推进一层**，不是**塞进更多原理**。正确形态：**先摆一个让人好奇的结果，再解释原理**——原理不是被压缩掉，是被挪到读者已经想要答案之后。

### 「再想几个」= 换故事原型，不是换措辞

11:20〔原话〕：「我觉得可以再想几个 这个我也不是特别喜欢」→ agent 一次给 5 个，她最终选了第 1 个。

《我花6000块学网球，学会了装忙》/《谈个恋爱，我每天都想分手》/《我能接受自己失败，接受不了朋友成功》/《我努力了，还是没考上。然后呢？》/《孩子的作业，把我送进正念班》

5 条 = 5 个**不同的人生处境**（金钱投入 / 亲密关系 / 同辈比较 / 落榜 / 亲子）。这条搞错，你会给 5 个同义标题然后被连否。

## 三、标题

### 她的红榜（1936 版，逐字）

2026-10-19 19:36〔原话〕：

> 「一、标题
> 红榜
> 直接用来访者的语气问问题，一个问句
> 包含具体数字，尤其是钱数
> 对仗、好听的标题
> 黑榜」

**黑榜是空的**——她还没写。「什么标题不好」只能从她的否决记录反推（见下节与 §五）。

| 红榜条目 | 验证状态 |
|---|---|
| 包含具体数字，尤其是钱数 | **已验证**：两个正例都命中（20 斤 / 6000 块） |
| 直接用来访者的语气问问题，一个问句 | **尚未被验证——她自己 4 分钟后就把它否了**（见下） |
| 对仗、好听的标题 | 从未被任何一次实测检验；她选中的标题没有一条是对仗的 |

### ⚠️ 红榜第一条的自我矛盾（必须写进脑子里）

- 19:36 她写下红榜第一条 =「直接用来访者的语气问问题，一个问句」
- 19:41（**4 分钟后**）她否掉三个照这条造的问句，选了一个**陈述句**

被否的三条：《我都交钱了，还不能打得差一点吗？》《为什么连花钱玩，我都觉得自己不配？》《钱都交了，为什么我还是不想去了？》

同一刻的判决〔原话〕（对话记录时刻是 UTC 11:41，即北京时间 19:41；本 skill 引对话一律用记录时刻，引 docx 用北京时间——同一个事件会出现两个时间标签）：

> 「这几个标题都不好 都不如我花 6000 块学壁球，学会了装忙 第一个标题也还行吧」

⇒ **checklist 是滞后的描述，不是前置的规格。** 红榜第一条是她在 19:36 那一刻以为对的，19:41 的实战把她自己的条目否了。
⇒ **⛔ 不要机械造问句。** 想问句，先看有没有「错位收尾」；没有就是这三条的下场。已发布的《对自己好一点，人会废掉吗？北大做了个实验》是问句但活下来了——它带恐惧感 + 权威背书，不是裸问句。

### 她否的三条 vs 她选的那一条

| 维度 | 被否的三条（问句组） | 她选的 |
|---|---|---|
| 句式 | 全部问句 | **陈述句** |
| 主语 | 隐含「我」但没出现 | 明写「我」 |
| 数字 | 没有具体金额（「交钱了」不是数字） | **6000 块** |
| 具体事 | 「花钱玩」「打得差一点」（抽象） | **学壁球**（具体活动） |
| 收尾 | 反问自己 → 停在情绪里 | **「学会了装忙」** → 反转 + 自嘲 + 画面 |
| 信息量 | 只有处境，没有故事 | 一句话就是一个完整的故事梗概 |

**决定性差异不是「问句 vs 陈述句」，是有没有「错位收尾」。** 三条问句都在问「我为什么会这样」（困惑）；她那条在说「我做了 X，结果得到 Y」，Y 与 X 毫不相干（故事）。

标题公式（从她的行为反推，不是她写的）：`我 + [具体金额] + [具体做的一件事] + [一个错位的结果]`。错位结果还必须**能被画出来**（「装忙」→ 一个人盯着手机编借口）。

其它被她选中 / 未否决的：《从腾冲农村到北大，我考了两年研》（她只给了三个碎片——农村、腾冲、考研两年；动作是**找出距离最远的两点再连起来**，和正例 A 同一个动作）；《才下午5点，我就开始等睡觉了》（具体时间 + 具体行为 + 矛盾）。

### 供给规格

默认 1 主推 + 2 备选 + 一句「我更推荐第一个」及理由；被否一次后给 5 个**不同故事原型**（不是同一故事的措辞变体）；她直接报标题就照做。⛔ 不要打分表、不要评分维度。

## 四、大纲

### 「一份策略」的三节定义

2026-09-12 09:14〔原话〕：

> 「我在想以后我们团队合作 你要交给写手什么内容 我觉得以文本（小红书配文）为例 你需要交给她 1）选题阐释 为什么做这个选题 会对哪些人有帮助 有可能如何吸引到别人  2）总的字数 3）每个段落的主题大纲 以刘琼这篇论文的推广为例 你给我写一个写作策略」

**① 选题阐释**（为什么做、对哪些人有帮助、**有可能如何吸引到别人**——第三问是灵魂）；**② 总的字数**；**③ 每个段落的主题大纲**。

10 月收敛后还会多出四块（她未否决，连续几篇都这么要）：标题（1 主推 + 2 备选 + 理由）、配图规划（几张 + 每张讲什么）、末页海报要素、效果口径。**三节是底，其余按当篇需要加。**

段落写法：`**第 N 段：<一句话概括这段要干什么>。约 XX 字。**` + 2—4 句说明这一段要让读者看见什么。

### 她的《写大纲 checklist》（1753 版，大纲节至今一字未改）

2026-10-19 17:53〔原话〕：

> 「有帮助：
> 1. 使用第一人称 讲一个第一视角的故事
> 没有帮助：
> 大量的前面的段落在说大众已经知道的东西 没有信息密度
> 非常论文式的、平铺直叙地讲一个心理学原理」

19:36 版只加了标题节，**大纲节一字未改** ⇒ 这三条是稳定的、已验证的；标题那节是刚起步的。⚠️「没有信息密度」的读法见 §二 的误读警告，⛔ 不要读成「多讲原理」。

### 故事五问（「缺少故事感」的机械定义）

2026-10-19 11:41〔原话〕：

> 「然后这个大纲也有问题 缺少故事感 不完整 不知道这个主人公为啥花了钱还要退出 没有体现主人公受挫折的过程」

大纲必须逐段回答五问，缺一个就是「不完整」：

| # | 问题 | 要求 |
|---|---|---|
| 1 | 他**原本想**得到什么？ | 初衷 |
| 2 | 他**为此付出了**什么？ | 努力，要有细节 |
| 3 | **哪一件事**让他受挫？ | 一个具体场景：有时间、有人、有对话 |
| 4 | 他**怎么退**的？退的时候**给自己找了什么理由**？ | 「受挫过程」的落点 |
| 5 | 后来**哪一个可看见的动作**证明他变了？ | 不是心态变了，是动作变了 |

「没有体现受挫折的过程」= 缺第 2、3 问：只有 1、4、5，中间是空的。

### 被否版 vs 修复版（逐段）

被否版（11:38）：① 我交了报名费，却因为打得太差不去了。 ② 我把参加社团，变成了证明自己够不够格。 ③ 道理明白了，但下一次失误，还是会难受。 ④ 我想练习的，也包括怎样继续留在场上。

修复版（11:42，她接受并成为定稿）：① 我本来真的想学会。 ② 后来，连比我晚来的新人也赢了我。 ③ 练习 MIED 后，我开始看见自己在逃开什么。 ④ 回到球场，我还是打得很差。 ⑤ 下一次约球，我回复："我来。"

对照：被否版 ① 直接给结论（读者不知道为啥花了钱还要退出），②③④ 全是内心活动、没有一个可看见的事件，结尾停在「可以试着练习」——缺第 2、3 问。修复版 ①=问1+问2、②=问3+问4、③=转折段、④=承接不逆袭、⑤=问5。

结尾形状：**结局 = 一个微小的、带着不适的行动**（回复「我来」/ 走回家 / 去了那家店），不是「我好了」。她没直接说过「不要逆袭」，但她通过的版本都这样。

### 字数与段落配额（收敛值）

演进：600—750 字 / 6 段（10-19 06:57、07:07）→ 300—400 / 4 段（09:30）→ 350—400 / 5 段（11:42）→ 350—450 / 5 段（10-28）。

⇒ 收敛到 **300—450 字 / 4—5 段**。每段 40—130 字，**转折段（第 3 或第 4 段）占最大篇幅，约 120—180 字**。600—750 那一版从没被采纳（09:30 她说「小红书的字数不要太长吧」）。⚠️ 这是**大纲里给写手的目标值，不是成稿闸门**：她从未因超字数打回，打球篇定稿 650 字（含标点）照样通过〔提取-02 §8〕；段数也不必卡死（减20斤：大纲 4 个部分 → 定稿 7 段）；超了先删段落、不压句子，冗余名句第 7 条优先。

## 五、否决清单（八条被否切法）

**① 原理课式切题**（《正念减肥，究竟在练什么？》——讲四个机制）
- 她说：「这个非常不好 非常的 怎么说 平庸 我觉得首先 如果让我来切题 我可能会写 "正念帮助我减了 20 斤" 然后写一个第一人称视角的故事 你的切题怎么说呢 就是 很平庸 你就在很平铺直叙地讲这个原理 我为啥要看？这有什么吸引人的地方？」
- 病灶：没有结果、没有故事、没有反差；那是课程介绍，不是笔记。
- 规则：⛔ 以「解释一个机制」当选题，必然平庸。

**② 纯情绪反应式切题**（《方案被打回，我连辞职信都写好了》——一次否定 → 想辞职）
- 她说：「这个切题不好 我感觉没有什么意思」
- 病灶：情绪夸张但没有代价；反转是内心戏，没有可看的行动。
- 规则：⛔ 反应再大，没有钱 / 时间 / 关系的实际损失，就不成立。

**③ 心理术语式切题**（《我不敢认真，怕认真了也就这样》——自我保护机制）
- 她说：「我觉得可以再想几个 这个我也不是特别喜欢」
- 病灶：心理洞察式、抽象；没有具体事件、没有金额、没有画面。
- 规则：⛔ 用机制名（「自我保护」「回避型」）当角度。

**④ 虚构一个读者没经历过的处境**（「练了两周没感觉 开始怀疑这个是矫情」）
- 她说：「让我觉得你一点都不了解人类 什么人会"练了两周没感觉"？ 根本没有练了两周这回事 中国有自我关怀的团体练习吗？大多数人听都没听过」
- 病灶：编造了一种并不存在的生活经验。
- 规则：⛔ 切题必须锚在读者真经历过、真会讲出口的处境上；说不出口的，就是编的。

**⑤ 拿研究命题当选题**（「没人回答有没有用」）
- 她说：「这个我觉得也不是很吸引人 首先这个实验只有 28 个人 不能回答有没有用 其次 大家并不感兴趣有没有用」
- 病灶：关心的是**研究的问题**，不是**读者的问题**。
- 规则：⛔ 别拿「这个研究能不能回答什么」当选题。

**⑥ 按搜索词切题**
- 她说：「我觉得非常不靠谱没有真实的人类会搜索'对自己好一点有用吗'」
- 病灶：用 SEO / 搜索词逻辑切题。
- 规则：⛔ 真实的人不会那样搜索，也不会那样想。

**⑦ 用情境铺陈冒充信息密度**（前三段反复写「想减肥 but 想吃」）
- 她说：「我觉得 123 段有点冗余……前面一开头知识密度太低了」
- 病灶：同一个信息写了三遍，一句话能说完的事铺了三段。
- 规则：⛔ 每段推进一层（见 §二 误读警告），不是塞进更多原理。

**⑧ 只有结论没有过程**（壁球大纲：从「我是最差的」直接跳到「不去了」）
- 她说：「缺少故事感 不完整 不知道这个主人公为啥花了钱还要退出 没有体现主人公受挫折的过程」
- 病灶：没有过程、因果断裂；只有「受挫」这个词，没有「受挫」的场景。
- 规则：⛔ 缺故事五问的第 2、3 问（见 §四），补过程，不换题。
